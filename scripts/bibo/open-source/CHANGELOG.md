# Changelog

## 0.1.0 — 2026-10-04

First standalone open-source release of Bibo.

- Conversations, notes, tasks, calendar, files and an attention inbox in one personal workspace.
- Real Linux sandbox for OS tools, acquired on demand; ordinary chat and workspace operations stay on the edge.
- R2 files shared between the agent, web UI and mounted sandbox directories.
- Private single-owner deployment with your own Cloudflare account and DeepSeek key; no hosted Bibo account required.
- Signed, expiring login sessions, password rotation, login limits and same-origin writes.
- Credential-free local UI preview, pinned public NextClaw packages, lockfile and CI checks.

This is an early release. The current UI is Chinese. The sandbox OS is temporary, runs are bounded to 10 minutes, and API/infrastructure usage is billed by your own providers. See the README for limits and deployment instructions.
