# 共享工作区文件浏览器 Implementation Plan

> 执行约束：先逐项对照设计原型与用户截图，再按本计划实施；未经用户明确要求不提交、不推送。

**Goal:** 在不改变现有会话工作台骨架的前提下，实现与确认原型一致的共享 Explorer，并补齐设计文档中的文件管理能力。

**Architecture:** 现有 ChatSessionWorkspacePanelContent 继续拥有工作台内容布局；项目文件树只挂载一次，在完整页、文件侧栏、窄屏抽屉和隐藏四种布局之间切换。文件系统仍是事实 owner，React Query 提供目录投影，useWorkspaceProjectFilesController 统一管理选择、创建、重命名、上传和删除意图。

**Tech Stack:** React、TypeScript、TanStack Query、Tailwind CSS、Vitest、Testing Library、Hono、NextClaw Client SDK。

---

## 0. 视觉锚点与禁止偏移

本节优先级高于实现便利性。任何结构不一致都先改结构，不能以“功能相同”解释。

### 用户截图锚点

1. Explorer 顶部只有一行：项目名、独立新建文件、新建文件夹、刷新、全部折叠、更多。
2. 文件预览顶部只有现有面包屑行；Explorer 展开/收起按钮是面包屑的 leading action。
3. Explorer 按钮与面包屑之间没有竖线、独立底色区或新增工具栏行，只用自然留白。
4. Explorer 与预览之间保留一条主栏边界；这是布局边界，不是按钮分组装饰。
5. 文件选中态使用浅色整行背景；不增加卡片、粗边框或独立浮层。
6. 文件右键菜单按五组排列：打开；添加到聊天/下载；Reveal/两种路径；重命名；删除。
7. 菜单危险项只有删除使用危险色；其他操作保持中性色。
8. 工作台原有 Tab、历史、刷新、最大化和关闭栏不新增第二层。

### 实现前撤回项

- 不保留任何位于面包屑上方的“项目文件”独立行。
- 不保留 Explorer 按钮右侧的 border-r 或单独背景块。
- 不为 Explorer 再增加一条工作台级导航。
- 不因实现侧栏而复制 ChatSessionWorkspaceDirectoryBrowser。

## 3. Task 2：实现不偏移的共享 Explorer 外壳

**Files**

- Modify: packages/nextclaw-ui/src/features/chat/features/workspace/components/chat-session-workspace-panel-content.tsx

- Modify: packages/nextclaw-ui/src/features/chat/features/workspace/components/chat-session-workspace-file-breadcrumbs.tsx
- Test: Task 1 中的结构测试

**Steps**

1. 保持 WorkspaceProjectFiles 只挂载一次。
2. activeSelection=project-files 时把它显示为完整内容页。
3. activeSelection=file 且 Explorer 展开时，把同一节点显示为左侧栏。
4. 其他 selection 隐藏但不卸载该节点。
5. 把 Explorer toggle 作为 breadcrumbLeading 传入现有面包屑。
6. toggle 和面包屑共享同一条 border-bottom；不增加 border-right。
7. 用 ResizeObserver 判断内容宽度，小于 560px 才切换覆盖抽屉，避免在可并列的宽度过早进入抽屉。
8. 窄屏点击文件、遮罩或 Escape 后收起；树状态不清理。
9. 宽屏侧栏默认 224px，允许 192–400px 拖动调整；树行 26px、层级缩进 12px、图标间距 4px。
10. Explorer 宽度使用现有 chat-thread store 的 versioned persist 合同，拖动结束后保存，页面刷新后恢复；非法旧值归一化到 192–400px。
11. 运行 Task 1 测试并确认通过。

## 9. 停止条件

- 任一截图结构与用户截图或原型不一致：停止继续扩功能，先修结构。
- 任一设计功能没有对应测试或真实验证证据：不得标记完成。
- 发现需要新增原型未表达的 UI 元素：先回到设计文档说明，不直接实现。
- 遇到无关工作区改动：不覆盖、不格式化、不混入。
