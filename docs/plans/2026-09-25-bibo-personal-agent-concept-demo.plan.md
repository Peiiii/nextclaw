# Bibo Personal Agent 界面概念演示交付计划

依据[设计方案](../designs/2026-09-25-bibo-personal-agent-interface-concepts.design.md)。目标是交付四套可比较的完整静态概念演示，并发布到独立 Cloudflare Worker。正式 Bibo 服务及官网不进入本批。

1. **冻结共同使用链路与样本状态**：四版共用同一组邮件、日程、待办、笔记和对话示例；从概览进入五个完整模块页，模块之间的引用、返回及代表操作保持一致。设计策略：复用上位设计。验证：逐条核对三条黄金链路，不以模块弹窗或按钮点击数代替。
2. **实现四套界面**：保留工作桌原稿，四版各有概览和对应视觉系统；所有概览卡片整卡进入完整页面，对话独立成 Tab。设计策略：复用上位设计；若某版视觉限制使模块不可用，先回设计收敛。验证：桌面与手机真实浏览器走完对话、收件箱、日程、待办和笔记的关键路径。
3. **验证、Review 与修正**：检查示例状态联动、浏览器返回、键盘焦点、窄屏、无虚假外部副作用；运行定向静态检查和 diff-only maintainability 检查。设计策略：复用上位设计；发现模型缺口返回设计。验证：四版黄金链路均有当前截图/浏览器证据。
4. **提交、推送与部署**：只 stage 本批演示、设计和计划；按用户授权提交并推送隔离分支，不合入主干；使用独立 Worker 部署静态演示，不触碰 `bibo.bot` 或 `app.bibo.bot`。验证：公开 URL 的首页、四版、工作桌原稿、资源、404 和手机入口；发布后交付可直接打开的链接。

恢复入口：先核对隔离 worktree `codex/bibo-personal-agent-concepts` 的状态、`concept-demos/bibo-personal-agent/README.md` 和设计文档；不从主工作区的其他未提交文件恢复。若公开部署失败，保留已验证源码与部署日志，定位当前 Worker 版本后重试，不重复创建同名资源。
