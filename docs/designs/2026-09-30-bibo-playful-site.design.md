## 当前有效设计：原版上的微小互动

用户看过首版后否定独立大首屏、角色大改和环绕装饰，认为粒子效果不足。以下首版方案与发布记录保留为历史，不再指导本轮实现。微改先按用户要求仅提供本地预览；用户随后明确说“发布吧”“上线合入吧”，授权将当前微改提交、合入主干并上线。后续审美迭代仍先预览。

保留首版前 `f3577e40e^` 的完整搭档相机 HTML/CSS：原版标题、角色形象/位置、四幕内容、导航、介绍与快门。仅在原角色右手旁增加一个约 50px 的锥形喷花筒，点击发出一次短促、明亮、有轨迹的喷花。由窄域 `fountain.controller.js` 拥有粒子与动效释放，`fountain.css` 仅负责该道具，不覆盖原页面布局。删除首版大舞台控制器和样式。

角色的点击通过原有 `advance()` 切到下一幕（第四幕循环回第一幕），原有 render 继续统一更新标题、屏幕和角色动作；不新增另一套状态或改变角色形象。喷花独立，不推动故事、不重写故事气泡；键盘按钮语义与手机触控一致。

用户再次指出筒方向错误、细火星不像微信效果，并要求先找参考。已查看[腾讯云社区文章中的微信 8.0 实际录屏](https://cloud.tencent.com/developer/article/1977757)，浏览器采样截图 `/tmp/wechat-effect-8s.png`、`/tmp/wechat-effect-12s.png` 显示“庆祝”是彩纸与卷曲彩带喷开、旋转飘落，区别于烟花放射状闪光。当前据此选择手持“庆祝”礼花筒：宽口朝上向外，尖端位于手里；用 SVG 宽口和握点的屏幕坐标确定发射轴，避免 CSS 旋转后喷向另一侧。点击有一次短促喷发、反冲，然后是多种大小的彩纸/卷曲彩带翻转飘落，约四秒消散；不持续烧细火星。小道具与原页面保持不变，只改筒形与瞬时动效。此次参考驱动修订已复核微改范围和动画退出合同，design-review: passed。

验收：刷新现有本地 4212，默认首屏与原版一致，仅多小喷花筒；点筒有可观察喷射且原故事不变，快速连点不无限积累；点角色四次循环回首幕，标题/内容同步；手机无溢出，介绍/快门/后退仍可操作，减少动态效果以短静态光和可访问提示反馈。AI 证明真实渲染与操作，喷花质感由用户确认。standard / L2，plan: not-required；针对用户修订独立复核，design-review: passed，覆盖微改、角色一致性、状态单 owner、动画生命周期与本地交付边界。

微改的实际验证：桌面 1440×1000、触控 390/360×844 无页面错误和横向溢出；礼花可见、连续六次点击后按时清空；单角色点击四幕循环与标题/计数同步；原快门、后退、介绍、键盘 Enter、减少动态效果和应用 href 通过。定位并修复手机道具被取景区域透明按钮挡住的问题；喷口与握点坐标共同决定发射方向，动画使用彩纸翻面和卷曲彩带。新控制器定向 ESLint、匹配 allowJs/noEmit tsc、node 语法、构建与 diff 检查通过；现有自动维护性检查排除静态 dist，人工复核该小控制器的单一状态 owner、240 粒子上限和隐藏/离开页面清理，无未关闭 finding。发布前已逐字节核对五份页面资源与 4212 预览一致。复盘增量回写原 thought/design，区分参考取证与用户偏好验收，不新增全局规则。

## 首版历史：目标与方案

来源：[可玩官网理念](../thoughts/2026-09-30-bibo-playable-homepage.thought.md)。官网仍说明个人 AI 搭档，互动帮助建立搭档性格和亲近感，与 NextClaw 长期搭档愿景一致。

比较三种方式：原相机加庆祝按钮改动小但仍是演示控件；独立小游戏有趣但偏离自然发现；采用首页活角色与散落道具的互动小世界，让访客从页面细节发现玩法。四幕相机保留在下面作为认真工作的一面，真实应用和介绍入口保留。

首屏左侧大标题“日常，多一个我。”，右侧紫色角色、柔和轨道与手绘贴纸，道具自然分布。点角色回应并弹跳；点锥形喷花筒，角色拿起它，短时间喷出彩色粒子；点星星进入庆祝、点月亮进入安静、点花朵进入灵感状态。三种道具都体验后触发隐藏彩蛋。状态可随时切换，不累计积分、不展示游戏面板、不要求“开始游戏”。

用户补充后的设计约束：首屏明确写“你的个人 AI 搭档”，说明“懂你的全局、主动接着做、从经验里改进”。道具回应关联搭档场景：陪你庆祝完成、尊重休息不打扰、陪你展开想法。下方四幕是详细展开，不能承担首屏遗漏的产品定位。此修订重新按原输入审查通过，产品解释与互动共存。

## 单一 owner 与边界

现官网 README 明确 `dist` 是手工静态源码，托管 app 的 React/Vite 规则只约束 app。保留相机控制器，新增 `playground.controller.js` 只拥有新角色的心情、彩蛋集合和粒子生命周期，`playground.css` 只作用于新舞台及明确页面编排。CSS 角色、inline SVG 道具无需新媒体服务、后端、模型或依赖；不用公共 UI 包承载一次性品牌插画。

粒子使用固定顶层 canvas、pointer-events:none、requestAnimationFrame，粒子数量有上限；仅点击触发短时喷花，不自动循环。角色眼睛跟随鼠标；减少动态效果禁用粒子和自动摆动，保留文案和状态变化。离开、页面隐藏清理动画；恢复可继续点击。原相机状态不受影响。

## 黄金验收

1. 桌面或手机进入首页 → 看懂定位和进入入口 → 点击角色 → 角色、气泡即时回应 → 点喷花筒 → 角色持筒、星星从筒口喷出 → 重复点击效果可重触发且不遮住导航。
2. 点月亮／花朵／星星 → 心情、道具和短文案一致变化 → 三种都发现时获得一次惊喜 → 再切换仍正常；键盘 Tab + Enter/Space 完成同样操作。
3. 向下看四幕相机 → 前进、后退、重播和介绍抽屉仍正常 → “进入 Bibo”真实 href 指向 app.bibo.bot；减少动态效果时所有动作有静态反馈。

AI 验证真实桌面与 390/360 手机渲染、触控可达、无横向溢出、粒子释放和上限、快速重复操作、键盘与介绍 Esc、旧相机、减少动态效果与构建资源。美术偏好和趣味程度由用户看上线效果判断。
