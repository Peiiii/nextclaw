# Bibo 趣味官网：一个有生命的小世界

## 目标与方案

来源：[可玩官网理念](../thoughts/2026-09-30-bibo-playable-homepage.thought.md)。官网仍说明个人 AI 搭档，互动帮助建立搭档性格和亲近感，与 NextClaw 长期搭档愿景一致。

比较三种方式：原相机加庆祝按钮改动小但仍是演示控件；独立小游戏有趣但偏离自然发现；采用首页活角色与散落道具的互动小世界，让访客从页面细节发现玩法。四幕相机保留在下面作为认真工作的一面，真实应用和介绍入口保留。

首屏左侧大标题“日常，多一个我。”，右侧紫色角色、柔和轨道与手绘贴纸，道具自然分布。点角色回应并弹跳；点锥形喷花筒，角色拿起它，短时间喷出彩色粒子；点星星进入庆祝、点月亮进入安静、点花朵进入灵感状态。三种道具都体验后触发隐藏彩蛋。状态可随时切换，不累计积分、不展示游戏面板、不要求“开始游戏”。

用户补充后的设计约束：首屏明确写“你的个人 AI 搭档”，说明“懂你的全局、主动接着做、从经验里改进”。道具回应关联搭档场景：陪你庆祝完成、尊重休息不打扰、陪你展开想法。下方四幕是详细展开，不能承担首屏遗漏的产品定位。此修订重新按原输入审查通过，产品解释与互动共存。

## 单一 owner 与边界

现官网 README 明确 `dist` 是手工静态源码，托管 app 的 React/Vite 规则只约束 app。保留相机控制器，新增 `playground.controller.js` 只拥有新角色的心情、彩蛋集合和粒子生命周期，`playground.css` 只作用于新舞台及明确页面编排。CSS 角色、inline SVG 道具无需新媒体服务、后端、模型或依赖；不用公共 UI 包承载一次性品牌插画。

粒子使用固定顶层 canvas、pointer-events:none、requestAnimationFrame，粒子数量有上限；仅点击触发短时喷花，不自动循环。角色眼睛跟随鼠标；减少动态效果禁用粒子和自动摆动，保留文案和状态变化。离开、页面隐藏清理动画；恢复可继续点击。原相机状态不受影响。

## 黄金验收

1. 桌面或手机进入首页 → 看懂定位和进入入口 → 点击角色 → 角色、气泡即时回应 → 点喷花筒 → 角色持筒、星星从筒口喷出 → 重复点击效果可重触发且不遮住导航。
2. 点月亮／花朵／星星 → 心情、道具和短文案一致变化 → 三种都发现时获得一次惊喜 → 再切换仍正常；键盘 Tab + Enter/Space 完成同样操作。
3. 向下看四幕相机 → 前进、后退、重播和介绍抽屉仍正常 → “进入 Bibo”真实 href 指向 app.bibo.bot；减少动态效果时所有动作有静态反馈。

AI 验证真实桌面与 390/360 手机渲染、触控可达、无横向溢出、粒子释放和上限、快速重复操作、键盘与介绍 Esc、旧相机、减少动态效果与构建资源。美术偏好和趣味程度由用户看上线效果判断。

## 实现验证与复盘

本地标准入口 `http://127.0.0.1:4212/`，Playwright 真实浏览器完成桌面 1440×1000、触控 390/360×844；首屏定位、三个心情、一次性彩蛋、喷花像素、连续八次触发后的粒子清空、键盘 Enter、介绍 Esc 与焦点返回、相机四幕循环/后退/补充面板、减少动态效果、六个旧概念路径均通过，无页面异常。截图与验证脚本属于本地证据，置于 `/tmp/bibo-playful-*`，不进入产品源码。

新增控制器通过定向 ESLint（静态源码目录需 `--no-ignore`、显式浏览器 globals），现有与新控制器通过匹配范围的 tsc `allowJs/noEmit` 检查与 node 语法检查。构建、diff whitespace、文件治理和 backlog ratchet 通过。现有 diff-only maintainability 脚本排除 `dist`，返回不适用，因此人工复核了状态 owner、快速切换、动画清理、180 粒子上限、减少动效、道具克隆和原相机隔离，无未关闭 finding；不将脚本不适用报告为自动审查通过。

复盘增量已回写原理念：首屏必须承担产品定位，互动需与搭档性格有关，不能靠下面的产品故事弥补首屏语义缺失。实现据此调整文案、三种道具回应并清除原相机驱动的全站变色，避免下方翻幕影响新首屏与导航。原相机旁的重复定位文案删除，消除与角色重叠。此为产品方向沉淀，不上升成全局流程或新增规则。用户尚未确认美术偏好。
