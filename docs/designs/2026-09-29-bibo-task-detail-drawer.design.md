# Bibo 任务详情抽屉

## 目标与现状

用户从任务列表或看板点击任务后，希望在当前工作上下文中阅读和编辑详情。现状是居中 `Dialog` 承载整个 `TaskForm`，正文与属性在同一竖列且属性默认折叠；长内容需要在较窄弹窗中连续滚动。任务选择、草稿、保存与失败恢复已由 `bibo-space.store` 和 `TaskForm` 负责。

## 方案

沿用任务行的选择入口与现有 `TaskForm`，详情改用从右侧进入的宽 `Sheet`。公共 `Sheet` 扩展可选方向和宽度，左侧导航保持原默认值。详情内以标题、说明、子任务为阅读主列，状态、优先级、项目和日期成为始终可见的属性区；窄屏将两列顺序叠成一列，抽屉覆盖整个视口和底部导航，保留独立滚动及底部保存操作。新建任务继续使用现有弹窗与属性展开方式，不改变创建行为。关闭详情保留未提交草稿；保存成功关闭抽屉并刷新列表，失败保留详情和错误提示；删除继续经确认弹窗。

选择右侧抽屉是因为它保留任务列表的空间位置，符合列表到详情的阅读方向。居中宽弹窗仍会遮挡列表；固定分栏会持续压缩看板和列表，因此不采用。仅扩展共享抽屉的几何参数，不新增业务状态或数据路径。

## 验收

从 `/tasks` 列表和看板点击任务，右侧打开对应详情，列表位置仍可辨认；标题、说明、子任务和属性可直接找到。编辑后保存，列表与重新打开的详情显示新值。失败时错误与草稿保留；关闭后再次打开能继续编辑；Esc、关闭按钮及删除确认的焦点行为正常。桌面和手机视口均能滚动到所有内容及保存按钮，长任务标题和长说明不遮挡操作。导航抽屉仍从左侧打开。
