# 会话复制 ID 与更多操作入口

## 背景

当前会话头部已有“更多操作”，但侧栏会话项只有置顶/改名快捷操作，子会话管理卡片只有整卡打开。用户需要在任意会话入口拿到稳定的会话 ID，尤其是子会话，便于诊断、引用和后续操作。

## 用户任务与成功条件

用户从当前会话头部、侧栏任意会话项或子会话管理页进入“更多操作”，选择“复制会话 ID”；剪贴板得到该入口对应的完整 `sessionKey`，并看到成功或失败反馈。

## 设计结论

- 在会话 feature 内新增统一的 `ChatSessionMoreActionsMenu` 组件，统一触发按钮、浮层层级、菜单项样式和复制反馈。
- 菜单始终提供“复制会话 ID”。当前会话头部继续承载项目、元数据和删除；侧栏保留置顶/改名快捷操作并增加更多入口；子会话卡片和工作区顶部子会话 tab 增加独立更多按钮。
- 子会话卡片从整卡 `button` 调整为可访问的打开按钮与独立菜单按钮，避免交互元素嵌套；菜单点击不触发打开会话。
- `session.key` 与 `tab.sessionKey` 是唯一复制来源，不新增状态、接口或持久化字段。

## 失败与边界

复制沿已有 `copyText` 能力，成功/失败通过 toast 反馈。草稿没有稳定会话 ID，因此不显示会话更多菜单；当前会话、侧栏已物化会话和子会话均必须显示。

## 非目标

本次不调整会话 ID 生成规则、后端协议、删除确认、侧栏分组、子会话导航或其它对象的更多菜单。

## 验证标准

- 三类入口均能打开更多菜单并复制对应 ID。
- 复制失败有错误反馈，成功有成功反馈。
- 子会话卡片的打开与更多按钮互不触发，键盘可聚焦且无嵌套按钮。
- 受影响 `@nextclaw/ui` 测试、TypeScript 检查和必要的 diff-only maintainability 检查通过。
