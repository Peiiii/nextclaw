# 近期问题统一交付设计

日期：2026-09-09。状态：NC-173 因用户实测失败返工，其它切片保留有效证据。

## 用户结果与交付边界

官网在弱网也能清楚展示截图，聊天和文件预览正确排版四种公式，语音权限失败后用户能找到恢复路径。复核历史 WASI 闭环后，统一交付实际环境验收。

## NC-172

聊天与 workspace 文件预览共用公开的 ChatMessageMarkdown。当前 remark-math 仅识别美元定界符；不能以已经发布数学渲染推断反斜杠定界符可用。

在同一 Markdown 解析链增加反斜杠数学语法，输出既有 math/inlineMath 节点并复用 KaTeX 与 streaming 处理。语法必须在 Markdown 转义处理之前识别，代码块、行内代码保持原文；拒绝用全局正则替换全文，因为会改写代码和链接。不新增第二渲染器。

验收：行内/块级两套定界符、代码、双反斜杠、未闭合流式内容、正文相邻 Markdown、刷新静态文档。

## NC-173

2026-09-09 用户体验修订：退出默认保存，不提供录音撤销叉号。Esc 在输入框或浮层均由 hook 的捕获监听路由到 manager.saveAndClose，避免 Lexical 原有 Escape 撤销先执行；快捷键绑定设置仍自行处理 Escape。manager 唯一拥有退出意图：录音中先 stop，等最终结果或8秒收尾上限，显式退出的失败路径提交当前可见草稿并关闭；启动中退出不启动迟到请求。停止按钮、工具栏和 Escape 共用该路径；录音/错误面板没有取消叉号，设置面板关闭按钮不涉及撤销。验收覆盖真实输入框 Escape、无取消按钮、最后句尾、重复 Escape、收尾失败保留可见文字、不自动发送。方案 Review：范围限于显式退出，不吞掉未请求退出时的真实错误，不新增转写服务。

现有 ChatVoiceInputManager 拥有 recognition 生命周期，panel 展示错误并调用同一 start 重试。沿用该 owner；浏览器权限由系统实时决定，不缓存到持久 store。

浏览器 SpeechRecognition 的 not-allowed 不能可靠区分浏览器拒绝和系统拒绝。恢复界面应准确说明已知事实，给出浏览器与当前系统可执行检查路径，不虚构具体拒绝层级。设备不存在/不可读可通过显式麦克风检查区分；检查得到的 track 必须立即 stop，取消和迟到结果不能重启录音。首次申请展示用途说明，恢复操作重新检测后通过原 recognition 主链开始。

验收：允许、拒绝、永久拒绝、无设备、设备不可读、缺少 API、取消正在检测、重试、重进不沿用旧授权。

用户实测返工（21:36 起）：starting 包含授权等待，不能把 window blur 直接当作录音中断。hook 仅在非 starting 时按原策略响应 blur；document hidden、pagehide、上下文切换和取消仍立即终止待启动请求，迟到授权不能重启。实际首次权限弹窗又复现了15秒计时先于授权结束的问题，因此首次与重试统一经过显式麦克风检查；用户授权等待不计入语音服务15秒deadline，检查成功并释放track后才启动识别和deadline。没有第二套权限缓存或识别fallback。

补充验收：首次弹窗停留超过15秒仍等待；允许后实际进入聆听；拒绝后具体引导；窗口失焦不取消授权，真正离开页面仍取消，取消后迟到授权不开始录音。自动测试只证明编排，浏览器原生事件须单独验证。该窄方案 Review 检查了计时owner、取消竞争与隐私边界，允许实施。

## NC-171

保留高质量源图，以可复现构建生成 AVIF/WebP 多尺寸内容指纹资源。统一 picture renderer 负责候选、sizes、intrinsic 尺寸；图片资源通过 URL 按需请求。默认 lazy/async，只有首页 Hero eager/high；原图链接只点击后请求。公开源图不作为默认 img src。

验收包括文件预算与浏览器实际选择；以同一源码基线、视口、DPR 和网络条件比较，不能用文件压缩率替代 LCP/CLS 测量。正式线上响应头复核属于用户验收后的部署门，本地先验证构建产物和缓存规则。

## 结构与审查

三个能力独立，集成共享一个验收环境。没有新产品平台、全局状态或自动化框架。每项开始实现前补全具体路径并执行方案 Review；该审查和最终实现 Review 分开。

方案 Review：passed（语音以以上返工修订为准）。公式扩展注册于 micromark text construct，复用 remark-math token 与共享 renderer；不改写代码字符串。语音 manager 继续拥有识别生命周期，首次与显式重试都检测授权，取消后迟到结果不能启动录音。图片以 manifest 为单一 URL/尺寸事实源，不在业务模板各自拼写候选。

实现中补齐的审查项：首屏以下视频接近视口后加载；权限面板的重试按钮固定可见、说明区独立滚动；浏览器明确返回 NotSupportedError 时才归为能力不支持，绝不把 not-allowed 当不支持。官网入口原有中英文大配置机械迁至两个语言 config，内容相同（仅截图源 URL 按方案变化），媒体 observer 归原展示模块，避免入口继续膨胀。

验收边界：本批是合并/发布前的真实环境交付。线上缓存头和正式包/部署仍在用户验收后的发布门执行；本批不声称完成跨操作系统的物理麦克风授权认证。
