# Island 主题设计

## 背景与目标

用户希望把 Wim Cools 展示的 Thymer 编辑器主题所传达的审美气质带入 NextClaw。参考版本固定为 2026-08-27 发布的 [编辑器演示](https://x.com/wcools/status/2093081211090403391)：暖纸画布、热带绿意、低噪声工具栏、克制边界、打字机式秩序和只在操作点亮起的翠绿反馈。

本次目标不是复制 Thymer 的品牌、棕榈素材或编辑器结构，而是在 NextClaw 已有应用壳与真实任务工作流中新增一套可持久选择的 `Island` / `岛屿` 主题。用户从“设置 → 外观 → 主题”选择后，应立即看到整个应用壳、会话、设置、列表、输入与弹层进入同一种安静、温暖、有生命力的视觉语言；刷新后仍保持选择。

## 当前事实与约束

- 主题值、持久化、根节点属性和设置入口由 `packages/nextclaw-ui/src/shared/lib/theme/index.ts` 单一拥有。
- 共享颜色、阴影和排版 token 由设计系统消费，现有 `charcoal-theme.css` 证明独立主题文件可以在不分叉组件的前提下补充主题专属配方。
- 应用壳、会话区、侧栏和 SideDock 大量使用语义化 Tailwind token，但部分表面是完全不透明的 `bg-background` / `bg-secondary`，只增加底层壁纸不会穿透到真实页面。
- 主题是纯视觉能力，不改变任务、会话、运行时、持久化协议或 CLI 语义；CLI 入口不适用。
- 参考产品尚未公开发布，演示中的图像资产不可复用。本主题使用原创生成的纸张材质与手绘棕榈，不下载、不嵌入参考品牌资产。
- 原始环境画为 `1536×1024 / 164KB WebP`。像素尺寸与全屏桌面显示相匹配，不应为减小传输而降采样；但当前稳定 `/themes/` 路径被 UI server 按 `no-store` 返回，刷新会重复传输，且页面没有根据已保存主题提前预取背景。

## 方案比较

### A. 只增加颜色 token

实现最小、覆盖天然完整，但最终只会像现有 `warm` / `probe` 的绿色变体。它无法表达参考中的环境感、纸张层次与“工具退后、内容浮现”的空间关系，不能满足用户所说的“灵魂”。

### B. 全局 token + 主题专属语义表面（采用）

保留现有主题 owner；新增独立主题 CSS，以暖纸、深墨、海绿 token 统一共享组件，并用受控选择器为应用画布、侧栏、内容区、卡片、输入和弹层提供轻量材质、透明度与边界配方。顶部氛围和纸张纹理由 CSS 生成，右上使用为 NextClaw 原创生成的棕榈树位图，不复制外部资产。

这条路径能覆盖真实页面，同时不改变组件结构和交互合同。代价是需要对少量语义表面进行主题限定覆盖，并通过真实页面截图防止宽泛 selector 错配。

### C. 为主题新增专属布局和插画组件

表现力最高，但会让一个可选皮肤开始拥有页面结构，形成主题与产品行为的平行路径；真实数据密度、窄屏和后续页面维护成本也会显著上升。本次不采用。

## 冻结设计

### 视觉语法

1. **材质**：主画布由应用壳拥有的一张连续原创环境画承载：顶部海水绿水彩、下部偏奶油旧纸自然溶接，纸纤维、云雾与水彩曝光属于同一张画，不由页面区块分别拼接。侧栏、工作区、设置区和工具栏不得重铺主题底色，区域关系只用细边界、留白和局部控件表面表达。
2. **环境**：手绘棕榈从画面右上之外进入，并被顶部和右侧自然裁切；树、天空与纸雾共同构成环境。环境底板移除树并保持固定，树使用透明循环动画层：静止约两秒，阵风推动树冠，随后叶片回弹并再次安静。动画由静风与受风两个原创绘画关键帧插值生成，只改变树，不对天空或纸面施加位移滤镜。系统要求减少动态时改用静态树帧。
3. **墨色**：正文使用略带绿色的深墨，不使用纯黑；辅助文字保持足够对比度，不以“褪色”为理由牺牲可读性。
4. **强调**：翠绿只用于主动作、选中、焦点、链接和成功反馈；普通导航保持低饱和。
5. **空间**：弱化卡片阴影与边框，主要依靠半透明纸面和细线分区；不改变现有布局尺寸，避免主题成为另一套产品。
6. **排版**：Island 使用系统自带的 `American Typewriter` 优先栈表达厚重的打字机骨架；标题、按钮、标签和导航中的中文由手札体、翩翩体或楷体承接，长正文和代码回到清晰的现有阅读字体。不引入网络字体，避免中英文覆盖与加载抖动。
7. **动效**：流式 Markdown 在同一个稳定 DOM 上投射三相短促墨迹残影，输入焦点提供轻微套色感；不拦截编辑器事件、不改变 selection、组件类型、父节点或 key。循环动效只保留低幅度树冠风感，并尊重减少动态设置。
8. **右侧工作区**：会话工作区、全局 Doc Browser 与最右 SideDock 都属于同一张连续应用画布。三者的大容器保持透明且不对背景施加模糊，让同一片树景和纸面从左到右完整贯通；文件树只保留极淡纸面，工具栏、应用卡片等真正承载内容的局部表面再按信息密度增加浓度，结构边界使用细线而非整栏底色表达。
9. **文件与代码预览**：文件预览不能重新铺一张不透明编辑器白纸。代码画布、普通代码行和空白填充区保持透明，行号栏仅使用极淡纸面分区；当前行与 diff 增删行继续保留低饱和语义色，兼顾背景连续性和代码定位。
10. **浮层与菜单**：Popover、菜单、Select 和 Tooltip 使用较主画布更浓的半透明纸张与柔和阴影，Dialog 和 Sheet 再提高一档不透明度并配合低饱和遮罩，保证浮层关系清晰但不跳回现代纯白面板。默认、悬停、聚焦、选中、危险与禁用状态沿用各自交互语义。
11. **过程信息**：会话中的思考、读取、执行等普通过程图标取消实心白色方块，作为墨色线稿直接融入内容流；展开后的思考正文同样不使用整块便签底色，只用淡墨色竖线表达从属关系。仅运行中、失败和需注意状态允许使用更明显的语义底色。
12. **手绘字感**：标题、按钮、标签与导航的拉丁文字继续使用 `American Typewriter`，中文优先使用系统手札体，并以翩翩体、楷体回退。长正文、文件内容和代码不强制手绘字体，避免牺牲长时间阅读和字符辨识。
13. **背景加载性能**：保持环境画 `1536×1024` 的显示分辨率，使用更合适的 WebP 编码降低传输体积。正式文件名必须包含内容哈希，UI server 对带内容哈希的静态资源统一返回一年 `immutable` 缓存；已保存为 Island 时，HTML 启动脚本在应用模块执行前条件预取该图片，其他主题不下载。高分辨率图片尚未就绪时继续显示与画面协调的暖纸底色，不新增第二套资源状态或 React 加载组件。

### 主链路与 owner

```text
设置页主题选择
  -> 现有 UiThemeOwner 持久化 island
  -> html[data-theme="island"]
  -> island-theme.css 提供 token、画布和语义表面配方
  -> HTML 条件 preload 提前请求内容哈希环境画
  -> UI server 为内容哈希静态资源提供 immutable 缓存
  -> 现有应用壳与共享组件消费同一 contract
```

只新增一个主题值和一个 CSS owner。禁止新增主题 store、页面级开关、Island 专属 React 组件或复制现有页面结构。

### 覆盖台账

- 基础：正文、标题、辅助文案、链接、图标、分隔、badge、头像。
- 操作：主次按钮、icon button、tabs/segment、dropdown、选中、hover、focus-visible、disabled。
- 表单：composer、input、select、checkbox、radio、switch、校验状态。
- 数据与导航：应用壳、会话列表、项目分组、卡片、工具卡、左右栏、空态和错误态。
- 会话：用户/助手消息、Markdown、代码、工具活动、附件、流式区域、composer。
- 弹层：select、dropdown、popover、tooltip、dialog、toast 和 overlay。
- 页面证据：空首页、真实会话、设置页，以及至少一个窄视口。

未在真实运行状态中出现的异步或危险状态，以共享 token 和现有组件测试作为有限证据，最终不得宣称逐项视觉全覆盖。

## 文档、兼容与非目标

- 在中英文配置手册说明主题入口和 Island 的定位。
- 现有保存值继续有效；默认主题不变，不需要迁移或 fallback。
- 新增用户可见主题需要 `@nextclaw/ui` changeset。
- 不修改 NextClaw 信息架构、会话布局、编辑器能力、主题同步范围或 CLI。
- 不复制 Thymer 的素材、品牌、文案、具体像素布局或交互实现。

## 最小验证标准

1. `island` 能被规范化、识别为 light appearance、出现在主题选项并持久恢复。
2. 设置页可以选择 Island，现有主题切换测试继续通过。
3. `@nextclaw/ui` 定向测试与 TypeScript 检查通过。
4. 稳定本地预览中，空首页、真实会话、设置/弹层和窄屏不存在可读性失败、遮挡或横向溢出。
5. 对照参考视频，最终差异明确：保留 NextClaw 结构，提炼其暖纸、热带绿意、低噪声和轻盈反馈，不声称像素级复刻。
6. 构建产物只引用带内容哈希的环境画路径；该路径响应 `public, max-age=31536000, immutable`，页面仍为 `no-store`。
7. 已保存 Island 时在主应用脚本前出现 image preload，其他主题不触发；环境画体积相较原资源显著下降且保持 `1536×1024`。

## 设计决定

- `design-document: required`，本文是后续实现依据。
- `plan: not-required`，改动由现有主题 owner 单批闭环，不新增跨层状态或运行时合同。
