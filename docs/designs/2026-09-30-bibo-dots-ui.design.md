# Bibo 对齐 dots 界面与交互设计

## 来源与目标

2026-09-30 用户提供五张 ChatGPT dots / Work 截图，明确希望精准复刻 UI、交互细节与动效，保留 Bibo 配色和独有功能。参考原件路径见本批日志。使命价值是减少用户在对话、笔记和生活工作上下文之间的操作负担。

## 现状与选择

实际 React 页面在 1512px 桌面观察：44px 外部顶栏、所有模块常驻会话侧栏，笔记再嵌套 280px 列表，文件 Tab / 路径 / 格式工具三层常驻。现有 Zustand 是会话、文件草稿和布局唯一 owner；Tiptap 已有插入、选区工具与块操作，Radix 已有菜单焦点与避让。复用这些能力。

选择修改现有应用壳和公共控件配方。单纯 CSS 换色无法消除嵌套侧栏；重建编辑器增加事务、保存与回归风险，无需采用。应用布局留在 Bibo；几何、气泡、输入器与浮层动效归 personal-agent-ui。主题只改变颜色。

## 用户链路

1. 打开 Bibo → 窄图标栏与当前场景侧栏 → 进入对话 → 输入框从一行随文字增长 → 发送与停止保留原状态 owner → 阅读滚动或切换会话 → 切回后草稿与回复仍归原会话。
2. 进入笔记 → 集合页搜索或新建 → 打开笔记 → 列表让位于居中的正文画布 → 编辑、选中文字、插入块 → 保存 → 切换阅读与源码、刷新 → 内容与保存错误恢复保留 → 返回全部笔记继续选择。
3. 展开/收起侧栏、菜单和手机抽屉 → 短过渡、可反向打断 → Escape 关闭当前浮层并恢复焦点 → 减少动态效果设置下直接完成。主题切换不重建编辑器与输入节点。

## 视觉与行为

- 参考截图的逻辑像素：约52px 图标栏、独立内容侧栏、圆角画布。用户复看后明确授权「好像去掉更好看？按照你的思路优化吧」：保留 Bibo 60px 图标栏与240px会话栏，顶部44px工具栏收入白色画布，外围仅8px轻留白，取消整条44px底色外框。几何不因主题改变。
- 对话隐藏重复身份行；按最新反馈，AI 回复保留轻中性卡片，背景由主题 surface 与 ink 派生；代码、引用与表格使用协调的纸面底色及较轻边界，复制动作位于左下。等待首段回复用紧凑浅灰三点气泡。辅助动作 hover/focus 显示，触屏可发现。输入器单行起步，保持发送44px触控命中。
- 模块导航仅保留图标栏一套；普通场景保留最近会话，笔记场景显示全部笔记、新笔记和最近笔记，复用原文件/草稿 owner。缩小品牌、创建入口与最近列表之间的留白。
- 笔记打开后隐藏集合；文件 Tab 与图标操作合成单行顶栏，不重复路径。格式、预览、保存、目录、更多入口使用共享 IconButton/ActionMenu；格式、插入、撤销重做与查找放入菜单，选区与块工具按需出现。下载/源码保留在更多。手机工具换行，保持触控命中。右侧窄工作区单独缩小正文边距。
- 概览已有日期和问候标题，桌面移除重复模块顶栏；正文直接承载画布四角，侧栏收起后仍实测裁切。手机保留菜单入口。
- 已打开的右工作区在跨模块返回时直接恢复；只有对话中开关状态变化才允许列宽过渡。
- 公共过渡使用短时 opacity / transform；侧栏宽度可逆，关闭后 inert 防止键盘访问隐藏内容。减少动态效果禁用过渡。

## 验证与证据边界

对照截图与真实页面的壳、聊天、集合、笔记及菜单；覆盖桌面、390px / 320px、两主题、hover、focus、触控、滚动、保存刷新、失败恢复、运行中切换与草稿身份。复用现有 product / composer / Markdown editor smoke，不添加镜像实现的测试。三个 Bibo TypeScript 检查、组件 tsc、Vite 构建、diff-only maintainability 与治理检查后直接按 Bibo 授权合入并发布。

原件是静态截图，未展示 dots 的动画曲线、时长和完整编辑行为；动效采用成熟范式并实测，不能声称已测得与 dots 完全一致。没有对应功能的任务/日程/收件箱保持能力并应用相同视觉语言；不伪造语音、分享或通知功能。
