# 纸墨主题与默认别名

## 用户结果

设置 → 外观 → 主题选择“默认”或“纸墨”，得到相同的暖纸与墨绿画面；刷新后保留所选语义。选择“素白”可恢复旧默认，纸暖、自然、简白保持可选。

## 方案

采用 standard / L2，单批实现，不另建计划。UiThemeOwner 保留选择值 `default`，在渲染边界解析为具体主题 `paper-ink`。旧 `work` 保持原有样式与持久值，显示名改为素白；不能判断历史 work 是主动选择还是启动写入，因此保留它，不强制迁移。

复用纸暖表面 token，纸墨覆盖品牌色、文字、消息及 Markdown 表格色。用户反馈首版浅绿偏冷、缺乏古朴感，因此改用接近墨黑的松烟绿主按钮与用户气泡、米白文字；正文与表格统一暖灰，去掉冷蓝色。相较直接覆盖旧主题，该方案保留用户选择；相较复制默认配色，别名解析保证两入口严格等价。默认指向只归主题模块；启动页复用初始化与 PWA 同步，移除其重复主题清单。

纯设备视觉偏好不新增 CLI。主题选项、存储校验、DOM 属性、PWA 背景、启动页及中英文标签覆盖新增值；没有服务端协议和安装迁移。

## 验收与审查

真实设置页切换默认、纸墨、素白、纸暖及深色主题，检查画面和刷新；默认与纸墨 DOM 主题一致而持久值不同。检查聊天用户消息、按钮、窄屏以及前背景对比。AI 验证功能与渲染，用户判断配色喜好。交付现有本地开发入口，不提交或发布。

方案 Review：通过。保留现有唯一 owner，无新状态层；启动与运行时须共用解析，避免默认在刷新时被固定为具体名称。用户原目标全部覆盖。

## 反馈与交付证据

用户确认目标是古朴感，并要求新任务入口协调。暖灰大面积填充显灰蒙，深绿大面积填充又抢走输入区注意力，亮米白底仍像独立胶囊。最终采用贴近侧栏的纸色（39 25% 93%）、4px 小圆角、400 字重，松烟绿仅用于文字和加号；悬停略加深纸色（39 25% 90%），点击面积不变。判断必须结合色块面积、形状、字重和整页注意力层级，不能仅让按钮与气泡同色。组件消费主题 token，其余主题保持原有样式。颜色偏好留在本文，不扩为全局设计规则。

欢迎语先后出现暖灰偏黄、纯黑偏硬的反馈：问题同时涉及色相、明度与字重。最终改用低饱和烟墨灰（105 4% 32%）与 500 字重，减少标题与柔和纸色界面的重量差。token 限定欢迎标题，其它主题仍跟随原 foreground 与 600 字重。偏好只记录于本设计，不扩为通用规则。

已通过 UI tsc、定向 ESLint、22 项主题/PWA/设置测试、最终构建和 diff-only 维护性检查。真实 5174 页面验证默认/纸墨等价、默认刷新保持、素白/纸暖/暗夜切换；桌面与 390px 会话验证深绿气泡、米白文字，真实新任务点击与悬停已检查。最终颜色为气泡 rgb(51,66,53)、文字 rgb(245,242,234)、正文 rgb(50,48,42)。暂未发布、未提交，已交付本地页面待用户确认配色。

## 最终视觉收敛（后续反馈）

按用户要求自主检查整页与长消息：标准为入口边界可辨、注意力不压过内容、纸色与绿色协调、文字清晰。过淡按钮改为 40 32% 96% 纸底、6px 圆角与 1px 内描边（36 18% 82%），悬停 39 28% 92%。此前仅缩小色差仍不足，实际计算样式检查还发现任意 shadow 类未生效，改为明确 box-shadow 属性后已确认渲染。

用户进一步要求绿色更暖、更轻，品牌主色最终为 86 14% 32%，带橄榄色的暖墨绿，米白前景保持不变；该值替代前文松烟深绿的阶段记录。已查看真实长气泡和整页截图，边界、主次与配色已达到本轮自评标准，不再为迭代而继续修改；古雅程度仍属个人偏好。

用户随后澄清仅有轻微违和，保留整体方向。最终按钮收掉描边，采用 38 27% 90% 暖纸填充、8px 圆角，悬停 38 25% 87%；暖墨绿和轻字重不变。整页复查可见入口，视觉层次与侧栏填充统一；此项替代上一节描边方案。

## 素笺：新的默认主题

用户要求保留纸墨，并自主设计非绿色、更舒适的新默认。采用素笺 plain-paper：纸暖表面、浅茶灰气泡、深灰褐正文与暖灰控件，头像也用浅中性色，避免深气泡与深头像叠加重量。不采用另一种高饱和强调色，因为当前问题是长对话中颜色割裂。

复用主题 owner 和 default 指针，只增加具体主题定义；纸墨样式保持不变。启动、PWA、选项、持久化、中英文标签同步。方案复核通过：默认与素笺等价，具体纸墨可选且刷新保留；首页、长对话和设置页为真实验收路径。沿用本设计与单批执行，不另建计划。

素笺验证：23 项主题/PWA/外观测试、UI tsc、定向 ESLint、构建和维护性检查通过。真实设置页验证默认解析为 plain-paper、素笺独立选项等价、纸墨刷新仍保持；已查看首页、桌面长对话与 390px 手机长对话截图。用户气泡 rgb(237,233,227)，正文 rgb(59,56,53)。本轮不改纸墨，默认设备入口已切换，未提交/未发布，交付待审美验收。

头像反馈：用户指出素笺用户头像的灰褐圆底显笨重。移除该主题用户头像的填充与阴影，保留暖灰人物线条及原尺寸、对齐；其它主题不变。

用户明确建议不展示自己的头像：素笺主题用户头像最终 display:none，移除占位，消息继续靠右区分身份。替代上一版仅去除圆底的处理，其余主题不变。

用户纠正范围：不显示用户头像是所有主题的统一聊天规则。改由共享 ChatMessageAvatar 对 user 返回 null，删除素笺样式特例；卡片与平铺测试验证用户头像不存在、助手头像保留。
