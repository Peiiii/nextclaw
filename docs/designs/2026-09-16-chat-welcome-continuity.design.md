# 欢迎页：开始与继续

## 范围与约束

2026-09-16，standard / L2。保留输入面板结构与工作区、Agent、运行方式三个直达选择器；用户明确指出每次会话都可能切换，不合并进设置。下方支持开始讨论与返回历史，保持简约。

## 选择

采用上下文相关的起步建议与单条真实历史入口。相比固定功能菜单，减少用户重新组织背景的负担；相比模型生成的待办推荐，不新增推断、请求和虚构状态。历史仅称“接着聊”，不判断任务是否完成。没有合适历史时显示起步建议。

用户补充要求：以人为中心的长期搭档感优先于任务入口。最终视觉收敛为“今天，想从哪里开始？”，删除重复副标题，开放表达留在输入提示中。标题桌面字号由 32px 收至 28px；三个独立上下文选择器整体居中；起步建议去掉图标与常驻描边，缩短组间距，保留悬停和键盘焦点反馈。三项起步方式为聊聊近况、一起想想、一起做点事，选择显式项目时第三项改为推进这个项目。点击仅填入草稿，不发送。已有文字、附件或技能选择时隐藏建议但保留占位，避免输入框跳动；清空后恢复。

起步建议始终可见（空草稿时）；历史作为下方独立轻量续接行，不用卡片，也不挤掉新话题的入口。相比“历史/起步二选一”，这让用户无需先关闭历史才能开始新话题。忽略只隐藏续接行，保留布局空间。暂不添加昵称问候、情绪推断、虚构记忆和完成状态。真正的长期主动理解需要独立能力支撑，本版只交付有证据的历史连续性。

## Owner 与数据链路

### 视觉验收纠偏

最终起步文案改为完整短句：“聊聊我最近的状态”“帮我理清一个想法”“一起开始做一件事”。背景按钮单行高度收至 32px（20px 行高、上下各 6px），水平内边距 12px，圆角 8px，正常字重；保留前景强度与浅底色。手机允许自然换行，不缩小文字强行挤进一排。此项覆盖早期短标签和较厚按钮的设计。

用户实际截图表明纯文字建议过淡、与其它控件不协调。起步入口最终采用轻柔主题底色、13px 中等字重和较深前景，不增加图标或描边；居中布局、短标题与输入面板保持。此反馈修正本页视觉决策，不扩展为全局规则。原有点击与草稿合同不变。

后续整页对比确认：问题还包括上下文栏在输入面板与起步按钮之间过小、过浅，形成额外的弱信息层。三个选择器提升至 14px、中等字重，文字使用与起步按钮相同的前景强度；保留原头像与运行方式标识。撤回把问题误判为图标内部差异的调整。验收须以整页比例为准，不仅检查局部图标是否一致。

已有 sessionsQuery → 既有 session adapter → welcome continuation 纯派生函数 → 欢迎页。仅使用当前列表内、同工作目录、同 Agent、有消息与标题的非子会话，按最后消息时间择一。无显式项目的旧会话归默认工作区。不同运行方式不参与过滤：返回原会话保留其自身配置，不把新会话配置应用到历史。入口明确说明返回原会话，使用现有 buildSessionPath 与 Router。查询未成功时不展示历史。

输入有内容由已有 inputSnapshot 派生后传入；不复制草稿状态。忽略只影响当前欢迎页展示，不删历史、不持久化推荐状态。无新服务或配置；此为 UI 导航与引导，不新增 CLI。

## 验收

1. 新任务 → 三个选择器可直接操作 → 无匹配历史时出现相关起步建议 → 点击填入可编辑草稿且不发送 → 建议隐藏但输入框位置稳定 → 清空恢复。
2. 新任务 → 同目录同 Agent 有历史 → 单条接着聊显示真实标题 → 点击进入原会话并能读取原消息；返回后可继续创建新任务。忽略入口后看到起步建议。
3. 切换项目/Agent → 不推荐不匹配会话；空列表、空会话、子会话、无标题数据均不伪造推荐。手机与明暗主题检查控件可达、文字截断及无横向溢出。
