# Bibo 概览品牌形象

日期：2026-09-27。来源：用户要求把官网形象带入应用概览，增强趣味与品牌辨识度，并明确要求落地上线。

## 现状与方案

现网 `https://bibo.bot/` 使用紫色大眼睛、圆润身体和搭边双手的角色；源为 `apps/bibo-camera-site/dist/index.html` 与 `styles.css`。应用 `https://app.bibo.bot/` 的概览由 `Overview` 展示，摘要来自现有 space store，当前仅用星号作标记。本地主工作区版本较旧，以已拉取的远程 master 为基线，隔离工作区实现，不改其它任务草稿。

选择把角色融入现有摘要卡，配官网「日常，多一个我。」：比仅替换小图标更容易识别，又比增加整屏欢迎页更节制。保留日期问候、真实摘要和全部下方卡片。角色使用应用内 SVG 表达官网相同造型及颜色，不依赖外站请求。只在悬停或键盘焦点时轻微倾身，尊重减少动态效果；不添加循环动画、虚构在线状态或后台能力。

品牌和文案归 Bibo 应用，领域数据仍归 space store；摘要导航使用 Router Link，保留真实 href 与既有目标选择。角色无独立操作，不增加按钮或状态。桌面角色在摘要右侧；手机缩小到右上角，摘要与操作可换行。经典和简约主题沿用各自表面及文字 token，紫色保留为固定品牌资产色。

## 用户链路与验收

1. 登录打开 `/`，看到官网同款角色、日期问候、真实未读或任务摘要。按摘要入口进入原收件箱／任务／对话；返回概览，原数据与卡片仍可用。
2. 空空间进入概览，也能看到角色和开始对话入口；不显示虚构任务、记忆或运行状态。加载与失败继续使用现有反馈。
3. 桌面、390px 和 320px 手机宽度检查卡片、角色、文字、键盘焦点和入口，没有横向溢出；两种主题及减少动态效果可用。

运行应用三个 tsc、客户端构建、既有桌面／手机产品冒烟；对概览补实际截图和入口检查。发布走现有 `deploy:client`，不滚动未变容器；冻结远程 master 后发布，并核验部署版本、线上角色、真实账号概览与导航。此次是纯展示改动，无存储迁移、NPM 或 Desktop 发布，也不增加 CLI。

## 方案 Review

design-review: passed。原始要求在概览直接满足；复用唯一 overview 数据源和路由，静态角色不引入状态或跨包抽象；手机可读性、主题与减弱动画列入验证。plan: not-required，单批闭环；审美偏好留用户确认，不影响 AI 完成渲染与功能验证。
