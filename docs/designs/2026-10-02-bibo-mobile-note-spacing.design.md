# Bibo 移动笔记编辑间距

## 目标与证据

用户要求统一优化移动端笔记编辑页的间距。服务长期搭档的连续记录体验，减少手机上进入正文前的空耗空间。

2026-10-02，最初本地主干 feaa9aabe：实际浏览器 320/390/760px 触控视口打开「笔记 → 想法」，顶栏均为 115px，笔记覆写正文顶部留白 80px，标题起点 y=195px。390px 正文左右留白为 32/16px；760px 为 50/28px。桌面顶栏 44px、正文顶部 80px 是既有宽屏排版。

交付前对账远程主干 a1f251be6：上游已将笔记 Tab 与预览操作改为单行文档标题菜单及正文/源码切换。本任务安全快进到该基线，保留新模型；原两行顶栏方案退出。剩余缺口是重复路径行、80px 顶部留白及窄屏排版不一致。

## 方案与 owner

- Bibo 壳沿用上游 56px 单行文档顶栏；移动笔记隐藏重复路径行，返回全部笔记仍由文档标题菜单承载。保存出现时不挤掉正文或操作。桌面路径行保持原样，文件与会话工作区继续保留目录浏览。
- Bibo 笔记布局通过现有 document token 设置移动正文顶部 24px、左右 24px、底部 48px，编辑与阅读共用。桌面排版不变。
- shared Markdown document 负责窄容器默认排版：24px 左右边距、24px 顶部、48px 底部，一级标题 1.85em、标题后间隔 16px。窄屏块手柄用 24px 宽度容纳原有 20px 控件及 4px 间隔，不与正文重叠。源码编辑保留 16px 顶部，横向统一 24px，底部 48px。
- 不新增状态、布局模式或控件；保存、草稿、版本冲突及格式操作沿用现有 owner。状态栏维持单独反馈，正文滚动由现有编辑/预览容器拥有。

复用上游文档标题菜单，避免恢复已退出的 Tab、预览与双行工具栏；手机笔记的路径返回与标题菜单重复，隐藏它可减少纵向占用。局部排版修复，不改变产品动作、持久化或公共 API。

## 验收与交付

1. 320/390/760px 从笔记列表打开笔记，首屏正文距顶栏 24px，左右留白 24px，顶栏保持 56px。正文和源码均无整页横向溢出，格式/保存/更多与返回可达，触控目标维持 44px。
2. 编辑长文 → 保存 → 从源码切正文 → 滚动到末尾 → 刷新：内容保存、模式切换、滚动及底部状态可见；模拟保存失败后仍可继续编辑并重试。长标题不推高工具栏；主题切换保持草稿。共享阅读与编辑排版由同一 owner 消费，不恢复上游已退出的笔记预览入口。
3. 桌面与文件/会话工作区抽查，宽屏排版不退化；Bibo Worker/客户端/脚本及组件库 tsc、Vite 构建、现有 product smoke。发布仅 Worker/UI，冻结远程 master，不 rollout 容器，线上笔记创建/编辑/保存/刷新并仅清理自己的测试笔记。

design-document: required（跨应用与共享排版 owner）；plan: not-required（单批可闭环）。风险 L2；部署按既有 Bibo 授权与发布合同执行。用户在 app.bibo.bot/notes 登录常用账号打开笔记，确认密度偏好；功能正确性由 AI 先验。
