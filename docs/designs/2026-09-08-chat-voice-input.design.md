# 聊天语音输入

## 范围与用户确认

基于贡献 PR #43 的识别能力自行补丁，原 PR 保留。L2 feature；design-document: required；plan: not-required（单批，沿贡献 PR 台账）。用户已批准本轮“输入框内实时转录”的设计及实现，产品效果仍需本人体验，未批准合并。CLI 不适用直接麦克风编辑，不新增云服务或系统全局快捷键。

本轮替代上一版独立转录卡片和结束追加文本方案。语音从开始时的光标或选区位置录入，在原输入框中实时修正；暂定文字以点状下划线标记，最终片段恢复正常样式。结束后等待最终识别，完成去除下划线，不自动发送。

## 用户路径与边界

常驻麦克风点击开始、再次点击结束；输入框上方悬浮胶囊仅显示状态、时长、结束和取消，不重复展示转录。等待时显示加载指示，不伪造音量波形。设置仅在主动打开时展示。2026-09-08 用户进一步确认：录音及设置使用 Portal 浮层，完全脱离文档流，不推动页面；输入工具栏移除常驻设置按钮。桌面录音浮层最右侧提供齿轮，点击后先结束并等待最终转写，再展示设置；应用设置 → 快捷键中的语音输入区复用同一 ChatVoiceShortcutControl 与 store。关闭设置不自动重录，手机隐藏两个键盘配置入口。权限、设备、网络和不支持错误有明确说明与重试入口，浏览器识别可能联网的说明保留在用户文档中。悬停提示只展示当前操作名称，不承载长篇功能说明；关闭设置使用完整的中英文翻译。外层 Portal 只负责定位且无圆角裁切，内层面板统一拥有圆角、边框、阴影和可用高度内的滚动。

桌面可选绑定按住说话、松开结束；默认未绑定。单字母/F6–F10 只在非编辑区域触发，Ctrl/⌘ + Alt/⌥ 组合可在输入框使用，避免常见编辑快捷键冲突。IME、重复按键、已消费事件不启动识别；修改、禁用绑定可用。移动布局不显示或注册快捷键。

点击取消或输入框中 Esc：撤回本次语音、还原原选区和引用。开始打字、粘贴、剪切、输入法、拖放或点击移动光标：提交当前可见文字并停止识别，随后交还编辑控制；迟到结果不再修改草稿。录音时输入框 Enter 只结束语音不发送；显式点击发送则采用当前可见草稿并停止识别，再执行原发送动作。

窗口失焦、页面隐藏或识别错误：停止识别，保留已确认文字，撤回暂定片段。切换会话/项目/模型或卸载取消。最长录音 60 秒；启动 15 秒、停止 8 秒超时。启动阶段快速松开直接取消，避免权限确认后意外继续。

## Owner 与数据链

ChatVoiceInputManager 独占浏览器识别实例、计时器与状态；hook 仅订阅和同步按键、页面及上下文事件。Web Speech 累计 results 每次替换当前快照，支持修正/缩短；onend 提交最终文字。每轮识别检查实例身份并在释放时摘除回调。

共享 composer 通过公共 beginDictation 返回一次性 ChatComposerDictationSession。ChatComposerDictationOwner 持有原始文档/选区、当前语音和清理函数，使用既有 Lexical owner 的选区替换与同步链路。更新只作用于编辑器临时预览，不提前发布到业务草稿，所以暂时覆盖引用不会触发附件清理；commit 才走原 onNodesChange，cancel 恢复原内容。下划线为 Lexical 显示样式，不加入持久化节点模型。结束后的 session 实例忽略迟到调用。

外部草稿替换时放弃当前临时编辑，避免旧快照覆盖新会话；用户直接编辑前提交可见文字并解除识别控制。共享组件仅提供编辑事务和 floatingSlot，不依赖浏览器语音业务。

定向覆盖：累计结果/最终尾段、临时文字修正缩短、光标/选区插入、仅暂定段下划线、取消恢复引用、不在预览期发布业务节点、外部草稿替换、用户编辑接管、迟到事件、快捷键与 IME、错误/超时。类型检查覆盖共享 UI 与产品 UI，运行真实输入组件回归及浏览器布局冒烟。真实音频服务、权限和识别准确率需用户宿主体验；模拟识别仅证明 UI/状态链路。

2026-09-08 实际验收纠偏：浮层锚点改为输入框上方水平居中，仍通过 Portal 避免布局位移并处理视口碰撞。录音与设置使用互斥视图，设置页头及入口均使用齿轮图标。结束录音后转入设置时清除录音状态，无语音/no-speech 不得渗透为设置错误、重试按钮或转写说明；配置只显示绑定和禁用。固定入口独立路由 /keyboard-shortcuts，外观页移除配置，移动设置导航不展示键盘入口。
