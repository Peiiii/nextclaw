## 方案与 owner

- Bibo 保留 `@nextclaw/personal-agent-ui` 公共入口；其 Markdown 使用 `@nextclaw/agent-chat-ui` 根入口公开的 `ChatMessageMarkdown`。公式、Mermaid 流式节流和预览、脚注、图片共用原 owner；代码展示槽保留 personal-agent-ui 成熟的复制按钮、高亮和源码切换。删除重复 Mermaid 实现。Bibo 保留 HTTPS 图片和安全外链策略，原始 HTML 不执行；用户输入仍按原合同显示纯文本。
- 样式 owner 是 personal-agent-ui 的 `theme.css`，保留现代 Tailwind 4 配置；补充共享组件 utilities 的扫描源，以语义类适配主题。Tailwind preflight 已清除浏览器列表默认值，因此显式恢复普通、嵌套和有序标记，仅任务项取消圆点。同时改善六级标题、行内代码、长表格换行与最小列宽，代码和长公式保留局部滚动。
- 消息状态仍归聊天 store；为已保存/临时消息分配浏览器展示 ID，提交后沿用临时 ID。同一行在统一列表位置展示，避免生成完成时重建图表/预览。稳定行组件隔离历史 Markdown 与草稿/delta 更新。
- 共享渲染器若有直接影响本链路的容器或脚注缺陷，在其原 owner 修正并加定向回归；不创建 Bibo 特例解析器。
- 使用公开包入口与正式依赖；禁止从 shared 源文件 subpath 导入。包的默认产物需先构建，开发模式使用 package 的 development 条件。

选择共享组件而不是在 Bibo 增加一套插件，原因是同一语法、异步图表、错误处理和安全净化应只有一个 owner。Bibo 保留品牌外观；不引入 NextClaw 全站 CSS。单批交付，`plan: not-required`。

## 2026-09-28 文件链接补充设计

用户给出的 `[搭档启动卡.md](/data/workspace/搭档启动卡.md)` 来自 Bibo 刚保存的文档，期望在回答中看到有链接线索的文件名，点击后在现有工作区阅读，刷新仍可从回答重新打开。当前 shared Markdown 已把语法解析为 `<a>`；Bibo host 将非 Web URL 交给 `workspaceResources.href`，但该映射拒绝绝对路径，使链接变为无下划线的禁用态。服务端 `BiboSpaceService.file.get` 已支持位于该账号个人空间根内的绝对路径，并按索引、真实路径和符号链接检查拒绝越界；无需新文件读取接口。

沿用 NextClaw「语法成立的链接保留链接语义，资源动作交给产品 owner」的设计，但不把 NextClaw 桌面文件访问权限搬到托管网页。Bibo 资源 manager 统一将个人空间相对路径、绝对路径和本地 `file:` URI 转成现有 `/files/path/:filePath` 路由；文件是否属于当前账号、是否已保存，仍由现有服务端 owner 判定。Bibo 聊天里的用户消息目前绕过 Markdown 组件显示纯文本，无法使用同一链接合同；改为让消息组件按角色传入已复用的 Markdown renderer，保持角色样式和 HTML 禁用策略。收件箱正文与文件预览已消费相同 renderer 和资源映射。外部 HTTP(S)、邮件、电话、页内锚点走原浏览器路径；危险或远端 `file://host` URI 保持禁用。文件 URI 仅允许本机或 localhost，解码失败禁用。查询和片段不作为文件名；当前工作区没有行号定位合同，本次不声称支持行号跳转。继续复用现有点击拦截、加载／失败提示和文件预览，不增加平行组件或状态。

另一候选是仅特判 `/data/workspace/` 前缀，能覆盖这条消息，却把当前容器目录写死在浏览器，换 `NEXTCLAW_HOME` 即失效，也漏掉标准 `file:` URI；因此选择服务端继续拥有根目录授权，浏览器只做语法和目标转换。若路径越界或文件未登记，点击在既有工作区显示错误，不读取宿主其它文件。

## 2026-09-28 排版比例补充

用户进一步要求 Bibo Markdown 的标题／正文比例和间距与 NextClaw 一致。以当前 `packages/nextclaw-ui/src/index.css` 的 `.chat-markdown` 规则为事实源：正文 `0.925rem/1.72`，标题 h1/h2/h3/h4–h6 为 `1.22/1.12/1.02/0.96rem`、行高 `1.35`；块间距 `0.75rem`，标题前 `1.25rem`、后 `0.5rem`，列表项间 `0.25rem`。Bibo 目前正文 14px、h1 24px、h2 20px 且每类块各自持有 margin；收件箱另有一套 compact 密度，因而比例与间距不一致。
