# 侧栏搜索与共享交互反馈

## 用户结果

会话列表顶部左侧切换时间/项目，右侧搜索，项目创建位于搜索左侧。点击搜索在下一行展开并聚焦；关闭或 Esc 清空查询并恢复焦点。搜索继续由现有会话列表 manager 筛选，不新增业务状态 owner；展开状态属于工具栏。

## 复现与根因

2026-09-13 在本地真实页面、默认主题复现：搜索按钮 `:hover=true`，`::before` 背景与侧栏均为 `rgb(242, 242, 242)`。链路为主题 `--interaction-hover = --muted = --gray-100` → `ACTION_FEEDBACK.icon` → `IconActionButton::before` → 同为 `--gray-100` 的侧栏。新增项目消费同一链路。

此前验收检查了样式类和展开截图，没有触发 hover；类名测试把“引用正确”当成“结果正确”，不能捕捉主题与承载背景重合。交互规范已存在且已加载，故不是缺少 hover 要求。

## 方案与审查

共享主题反馈色改为前景色 8% 的半透明叠加，使浅色表面略变深、深色表面略变亮；主题不再用 muted 实体底色覆盖此 token。保留共享按钮和菜单主链路，不给搜索/项目添加局部颜色或新 tone。

放弃仅对两个按钮补 class：相同 token 仍会在其它 muted 表面失效。也不新增治理脚本或全局强制视觉审计；新增的是针对实际产品入口和主题的浏览器回归测试。

design-review: passed。风险 L2，共享主题影响图标和中性操作反馈；原选中态、危险态、输入焦点、业务数据与 CLI 不变。CLI 不适用：仅直接操作界面体验。单批完成，plan: not-required。

## 验收

1. 真实侧栏切项目模式：新增项目、搜索依次右对齐；逐个 hover，图标背景相对承载面有可见变化，提示文字可见。
2. 搜索展开、输入无匹配查询、关闭及 Esc：恢复列表和触发按钮焦点，不保留隐藏筛选。
3. 浏览器回归覆盖全部主题，读取真实伪元素尺寸、透明度和颜色，合成承载背景后检查实际色差；抽查普通内容面和暗色面，避免仅通过 class 断言。

## 开发体系修正

唯一规则落点为交互质量 Skill：把末尾“组件、DOM、浏览器或截图任一证据”改为与断言匹配的证据；视觉反馈必须触发真实状态并检查最终渲染。Validation 仅增加条件路由，避免局部组件测试被通用低成本证据原则误当作视觉证明。普通逻辑、文案改动不触发浏览器检查。

不增加 AGENTS、Skill 发现入口、命令或 baseline。按已有规则资产生命周期试用；未来模型/工具能稳定自行选择同等证据时可删补丁，回归测试继续保护颜色合同。

## 补充：统一选中态与标签栏边界


工作台标签栏为 40px，内部标签内容只有 36px，选中边线下产生 4px 空隙。收件箱筛选已使用 interaction-selection，但该 token 固定为蓝色；侧栏、文档标签和设置列表又各自覆盖灰色、白色或主题色，导致同级入口反馈不一致。

本次恢复稳定、一致的界面反馈，减少用户辨认当前选择的负担，服务长期搭档的统一体验。不改变业务状态、路由、持久化或 CLI；纯视觉能力不需要 CLI 入口。

## 唯一 owner 与边界

- 主题在 design-system.css 定义中性反馈：根据用户本轮“颜色太重”的纠偏，hover 为 foreground 的 4% 透明叠加，selection 为 7%，selection-border 为 12%。各主题通过 foreground 适配明暗与色温，不另行覆盖选择色；替代前文第一批 hover 8% 的强度。
- 普通按钮、列表、筛选和标签消费上述 token；按下与键盘高亮使用 hover，持久选中使用 selection。选中后 hover 不降级。历史调查确认 9 月 9 日 f50a3c022 与 9 月 11 日 ea57bd263 会话采用 background 65% hover / 90% 选中，9 月 13 日 2c4546427 改为 gray-200。用户最终指定 VPS 为准，因此桌面会话与导航按实际 VPS v0.54.2 的 gray-200 60%/80%、分段 70% 对齐；移动会话保留独立的 background 65%/90% token。
- ACTION_FEEDBACK、Tabs、CompactTabStrip、ConfigSelectionCard 和侧栏样式 owner 承载可复用状态。业务层仅保留布局、内容与状态选择，不新建平行主题系统。
- CompactTabStrip 的滚动容器使用伸展布局；工作台标签填满可用高度，文档浏览器显式居中的胶囊标签保留其布局意图。横向溢出仍可滚动。
- 例外包含上述有明确依据的侧栏设计、市场页以底线表达选择的标签，以及主 CTA、危险操作、成功/警告/错误状态、开关/复选标记、拖拽目标、品牌/内容预览及系统窗口关闭行为；新增专门设计必须有场景、理由、共享 owner 与验收证据，不能以“更好看”临时配色。
- 会话行置顶、编辑、更多与项目行操作的 tooltip 优先上方，由 primitive 处理边缘避让；独立纵向图标栏仍可侧向显示。

## 实现与检查

先修共享 token 和 primitives，再迁移源码里普通 hover 与选中覆盖，移除主题对导航选中态的反向覆盖。沿用已有交互质量 Skill owner 增补明确 token 与例外合同，不增加常驻规则或新 Skill。

新增定向回归检查，阻止普通背景 hover 重新使用 gray/muted/card/background，并核对中性选择 token 没有主题覆盖。检查不替代实际渲染或新增例外的主观审查。

## 黄金验收

1. 会话工作台：切换概览、子会话、定时任务，切换停靠/悬浮/最大化；tab 底边与容器底边贴齐，窄容器仍可访问标签和工具栏。
2. 收件箱：切换未读/全部/已归档并选择列表项；筛选与列表选中均为同色系反馈，hover 不使选中态丢失。
3. 左侧导航、文档侧栏和设置页：普通入口 hover、选中与菜单键盘高亮共用主题反馈；抽查浅色、深色与岛屿主题，检查相邻入口和窄布局。

执行 UI tsc、定向 ESLint、共享组件及主题回归测试、diff-only maintainability 和规则渐进加载检查。未逐个交互的页面明确披露，用户审美偏好待确认。本次不提交或发布。

## 方案审查

采用已有 token 与组件是唯一必要路径；新增主题映射、全局 DOM 覆盖或逐页补色都会增加重复 owner。风险为局部视觉扩展，保留语义例外与文档标签居中合同；无状态或协议变化。设计审查通过，单批实施，无独立执行计划。
