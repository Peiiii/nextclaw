# 定时任务会话视图

## 迭代完成说明

用户希望在已有“时间、项目”会话视图中增加“定时任务”，置顶修复合入后要求继续。本批按原始需求实现第三视图，设计和 SCH-01 至 SCH-05 验收合同见[设计记录](../../designs/2026-10-02-scheduled-session-view.design.md)。

kernel 公共分页筛选增加 scheduledOnly，SQLite 在计数和分页前识别 cron 来源、非空文本任务 ID 及历史 cron: 会话；与 peerId、搜索、置顶排序共用查询。HTTP、SDK 与前端消费同一合同，定时范围缓存独立且实时摘要重新查询；桌面、手机和标题切换器可进入第三视图，刷新保留选择。

范围是定时任务创建的专属会话。已有普通会话不会因任务绑定而改分类，同一任务复用一条会话；任务配置仍在原管理页。同步更新中英文会话使用说明及四个包的 patch changeset。Cloudflare 适配器保持公共存储合同兼容，Bibo 当前页面没有新参数消费者，不改变其产品体验。

## 测试、验证与验收

- kernel 最终定向回归 20 项、HTTP 真实持久化筛选回归 1 项，以及原 HTTP 定向回归 10 项通过；生产 cron handler 4 项、SDK 21 项、Cloudflare 适配器 4 项通过。
- UI 的视图持久化、手机菜单、空态、实时缓存及查询隔离回归通过；修正异步查询测试等待条件后单独复验。扩展侧栏回归 15 项通过、10 项失败，干净基线同样 15 项通过、同名 10 项失败，不宣称修复既有测试问题。
- kernel、server、client-sdk、UI 与 Cloudflare 应用匹配范围 tsc 通过；前四包构建通过。触达文件定向 ESLint、diff governance 与 diff-only maintainability 检查通过。
- 源码预览先用 136 条边界数据验证两页共 106 条定时会话、范围内搜索、打开消息、普通视图切换及置顶后刷新。最终切换到真实历史副本，API 定时总数和返回数均为 23，普通视图共 33 条；打开晚间日报后读取历史助手结果，刷新仍选定时视图。
- 390×844 手机实测、桌面标题切换器及中英文/默认和暗色主题检查完成。发现并修正英文项目模式中第三按钮挤占搜索入口，最终控件宽度 189.4px、父级与 scrollWidth 均为 256px。

## 用户体验入口

预览：`http://127.0.0.1:19885/chat`。选择会话列表的“定时任务”，可搜索、打开历史会话并阅读结果；切换时间或项目返回原范围。手机通过顶部视图菜单进入，配置任务使用“管理定时任务”。

最终预览使用独立 HOME 的真实历史副本，不复制模型、渠道凭据或任务配置。只监听本机，原实例与历史未修改；该实例不能直接发起新的模型请求。历史读取与本次列表功能已验证，新模型请求和新任务执行不在本批验证范围。截图保存在隔离 worktree 的 `.local/scheduled-session-preview/real-history.jpg`，不提交历史或截图。
