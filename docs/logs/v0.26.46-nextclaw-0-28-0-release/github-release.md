## English Version

NextClaw 0.28.0 brings background results back to you through completion notifications and a persistent AI Inbox.

![NextClaw showing a clickable result notification after a background session completes](https://docs.nextclaw.io/release-notes/nextclaw-v0.28.0-background-results-en.png)

- Get a lightweight notification when a final reply completes in another conversation.
- Let Agents deliver Markdown or safe static HTML reports to a persistent Inbox.
- Manage unread, archived, and historical deliveries, then continue in a linked conversation with the report already in context.
- NextClaw Desktop 0.0.237 packages runtime 0.28.0 for macOS, Windows, and Linux; the minimum launcher version remains 0.0.141.

![A daily AI and technology briefing created by a background Agent and displayed in the Inbox](https://docs.nextclaw.io/release-notes/nextclaw-v0.28.0-ai-delivery-html-en.png)

Full release notes: https://docs.nextclaw.io/en/notes/2026-08-06-nextclaw-v0-28-0

Full changelog: https://github.com/Peiiii/nextclaw/compare/v0.27.7-desktop.1...nextclaw@0.28.0

## 中文版

NextClaw 0.28.0 让后台结果主动回到你身边：其他会话完成时即时提醒，重要报告则进入可持久管理的 AI 收件箱。

![后台会话完成后，NextClaw 在右上角显示可点击的结果通知](https://docs.nextclaw.io/release-notes/nextclaw-v0.28.0-background-results-cn.png)

- 其他会话里的最终回复完成后，右上角显示轻量通知。
- Agent 可以把 Markdown 或安全静态 HTML 报告主动送到持久化收件箱。
- 管理未读、已归档和历史送达内容，并从报告直接“继续聊”，无需重新粘贴上下文。
- NextClaw Desktop 0.0.237 已为 macOS、Windows 和 Linux 打包 runtime 0.28.0，最低 launcher 版本保持 0.0.141。

![后台 Agent 生成的每日 AI 与科技简报在收件箱阅读窗中展示](https://docs.nextclaw.io/release-notes/nextclaw-v0.28.0-ai-delivery-html-cn.png)
