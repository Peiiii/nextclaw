# 第二轮：像翻照片一样看故事

- 状态：保留；基于第 1 轮最佳。
- 观察：手机只有点击前进，回退要寻找小按钮；源码和实际入口均无手势监听。横向故事已有方向动效，可以复用。
- 假设：画面左滑前进、右滑回看能减少手部移动，与角色拨片方向一致；属于待验证的体验判断，不声称访客偏好已证实。
- 方案：仅画面按钮处理触控 pointer 事件，水平位移至少 40px 且超过垂直位移 1.3 倍，700ms 内视为翻帧；保留 pan-y 和 pinch-zoom，取消手势不翻帧。手势后的兼容 click 不得再推进；鼠标与键盘仍走原入口。
- 成功：真实移动触控输入左滑/右滑各一帧；首帧右滑不动；点击仍前进；纵向滚动不误翻，快速重复手势不重入；减少动态效果立即呈现。
- 放弃条件：滑动与滚动冲突或双重翻帧，允许一次返工；不引入拖拽物理引擎。
- design-review: passed；单控制器复用 moveTo 和角色拨片，产品设计同步后实现。

结果：Chromium 移动触控环境通过 CDP touchStart/move/end 输入，验证左右滑、首帧边界、轻点、纵向滑动不翻帧、减少动态效果及末帧重播。没有双跳。补充手机可见提示“轻点或左滑”，未增加界面模块。未实测真实 iPhone/Safari，手势喜好仍属主观待验。

决策：保留，无返工。单轮 Token 不可测；账户检查仍为 62%。下一步第 3 轮结果表达。
