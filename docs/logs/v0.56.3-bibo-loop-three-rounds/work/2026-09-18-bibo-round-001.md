# 第一轮：连续键盘操作

- 状态：保留；基于批次初始候选。
- 问题：控制器在换帧时将快门设为 disabled，浏览器会移走焦点；第一帧 Enter 后，再按方向键不能继续。首次 Tab 进入故事的用户必须重新寻找控件。
- 假设：用 aria-disabled 表达暂时忙碌，由已有 exposing 状态阻止重入，可以保留焦点、允许下一次键盘操作。
- 最小范围：原 controller 的换帧按钮锁定；上一帧在首帧仍使用原生 disabled。
- 成功：快门与画面按钮 Enter 换帧后保留焦点，方向键继续；快速重复输入不跳帧；首帧回退禁用；减少动态效果可用。
- 失败：动画重入、移除原生禁用后越界或焦点跳走。
- Review：复用唯一 exposing 状态；不另加事件队列，design-review: passed。行为修复附既有产品设计。

结果：修前真实浏览器 Enter 后 activeElement.id 为空，后续方向键停在第 2 帧。修后快门及画面按钮都保留焦点，继续方向键进入第 3 帧；快速重复输入只推进一次；减少动态效果和首帧回退边界通过。未改变场景或动画，免重复视觉截图。没有返工。

成本：批次起点 62%，单 Agent；精确单轮 Token 不可测。下一步进入第 2 轮手机手势实验。
