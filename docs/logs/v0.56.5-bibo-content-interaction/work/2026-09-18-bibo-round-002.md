# 第二轮：让“记得你”有可见的差别

问题：第一轮角色说记得走不远，但访客看不见这个背景真正改变了什么。假设：让访客拖动“普通清单→记得妈妈”的连续对照，路线收拢、步行从1.8km变400m，站点转向能坐下的安排，能把记忆价值变成可观察证据。

内容/交互因果：妈妈走不远→缩短路线并增加休息→拖动比较尺→路线和说明一起变化；不是选择题，不需要回答才能继续。数据均示意。成功：键盘/触控/鼠标可操作，操作不误触翻页，终态和后续安排一致；失败：只换数字、拖动控制无法发现、手机遮挡。design-review: passed，复用frame；比较值仅为当前演示局部状态，离开后重置个性化终态。

结果：加入原生对照滑杆，热门清单与轻松安排的站点、距离和路线展开程度一起变化；初始显示个性化结果，避免强迫操作。1280/360真实键盘Home/End验证1800→400米且不误翻页，离开当前帧控件隐藏。手机截图可读。保留，但是否一眼理解比较意图仍待用户；第三轮将结果从一句总结变为可带走的安排，并纳入群友提出的动效僵硬反馈。
