# v0.26.31 项目上下文引用

## 迭代完成说明

- 在聊天输入框的 `@` 统一引用入口中，新增与“文件与文件夹”并列的“项目”入口。
- 项目列表复用 `ProjectManager` 的已登记项目数据，展示项目名称和路径；选择后插入独立的项目令牌，不改变当前会话绑定的工作目录。
- 项目令牌随消息元数据传递。Kernel 只接受仍在项目注册表中的路径，并向 Agent 提供项目名称、规范路径和受限目录概览；不存在、非目录或未登记项目会返回可观察状态，不读取任意绝对路径。
- 复用了现有输入选择器、令牌协议、项目查询和目录扫描 owner，没有新增平行项目注册表或隐式切换会话项目的链路。

## 用户/产品视角的验收步骤

1. 在聊天输入框输入 `@`。
2. 确认根菜单同时显示“文件与文件夹”和“项目”。
3. 进入“项目”，确认已登记项目按名称列出。
4. 选中一个项目，确认详情区展示项目名称、项目路径和作为本次消息上下文的说明。
5. 回车添加，确认输入框出现项目令牌，且当前会话工作目录没有被切换。
6. 发送消息后，确认 Agent 能获得该项目的名称、路径和受限目录概览。
