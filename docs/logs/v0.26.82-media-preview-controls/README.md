# v0.26.82 通用媒体预览与 Mermaid 操作完善

## 迭代完成说明

本次把聊天图片与 Mermaid 图表的全屏查看收敛到同一个共享媒体预览 owner，并修复 Mermaid 放大后图形反而缩小、复制与放大图标错位、成功渲染后无法复制源码的问题。

根因有三项：原 Lightbox 只提供遮罩和内容插槽，没有明确的媒体画布尺寸与变换状态；Mermaid SVG 使用相对宽度，在无确定宽高的弹层内容中触发 shrink-to-fit；复制与放大按钮分别锚定外层 `figure` 和内层按钮，属于不同坐标系。源码调查、用户截图与本地源码页面的真实渲染共同确认了这些问题。

修复由 `ChatMessageLightbox` 统一拥有缩放比例、平移位置、滚轮锚点、拖拽、双击、键盘快捷键、显式复位和工具栏布局。图片与 Mermaid 只提供媒体内容与业务动作；Mermaid 的复制、放大以及全屏复制共用对齐的预览工具栏。共享预览器已经从 `@nextclaw/agent-chat-ui` 公共入口导出，供后续功能复用。

## 用户/产品视角的验收步骤

1. 在会话中打开一个成功渲染的 Mermaid 图表，确认复制与放大图标处于同一工具栏，尺寸和基线一致。
2. 点击复制，确认原始 Mermaid 源码写入剪贴板，并出现“已复制”反馈。
3. 打开 Mermaid 或普通图片的全屏预览，确认内容按可视区域最大化显示。
4. 使用底部缩小、放大和重置按钮，确认比例显示同步更新；使用滚轮、双击、`+`、`-`、`0` 和放大后拖拽验证对应操作。
5. 使用右上角关闭、遮罩点击或 Escape 退出预览。
