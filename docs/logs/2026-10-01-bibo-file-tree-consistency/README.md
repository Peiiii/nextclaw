# Bibo 文件目录闪现根因与修复

## 迭代完成说明

进行中，待提交部署与线上复验。用户 2026-09-30 提供线上目录截图并要求定位根因、掌握架构；设计与链路地图见[目录稳定性设计](../../designs/2026-09-30-bibo-file-tree-consistency.design.md)。

线上只读核对 150 个条目，前 100 项都属于 `.config`、`.gh-log`、`.local`，正在编辑的笔记排第 142 项且文件仍存在。故障生成链路是全空间分页第一页替换目录集合，而打开笔记又把该笔记及祖先合并进去；后续刷新覆写造成闪现/消失。files/notes 的请求版本分离而写同一 files，放大覆盖风险。

修复在真实 owner：服务端复用 R2 delimiter 直接子项列表，目录 manager 独占读取、展开、搜索、分页与请求版本；store 保存状态，树和面包屑直接消费。全空间笔记/搜索不再替换目录集合。未清理或隐藏用户文件，不改变存储归属；隐藏目录具体生成者尚无审计证据，不猜测。

## 测试/验证/验收方式

- Bibo 全套 146 项测试通过；包含真实 R2 store/service 装配的 140 个工具子文件、根目录笔记、目录 opaque cursor、空目录和路径隔离。
- Store 回归覆盖多页刷新、原故障形态、迟到响应、删除目录后响应不可复活、账号切换和读失败保留。
- Worker、client、scripts 三份 tsc、定向 ESLint 与 Vite 构建通过；构建保留现有大 chunk 警告。
- CUA 在独立源码实例 `http://127.0.0.1:5399/files` 验收桌面和 390×844 手机：目录 100→140 后无更多按钮，笔记持续可见；桌面连续两次笔记/文件切换保留 140 项；冷刷新恢复展开目录的第一页与笔记，面包屑可进入笔记子目录。
- 本地预览采用既有文件领域 adapter（工具目录为 A-tools），生产 R2 隐藏路径通过装配测试和线上只读证据另证；两者不混称同一环境。

## 发布/部署方式

按 Bibo 默认完整交付授权精确提交、推送远程 master，从冻结远程主干部署 Worker 和静态资源。Sandbox/runner 未改，使用 `deploy:worker --containers-rollout=none` 的现有入口，不发布 NPM、桌面或 NextClaw 文档站。冻结 SHA、Worker 版本与线上复验待补。

## 用户/产品视角的验收步骤

打开 https://app.bibo.bot/files，根目录应稳定显示笔记目录与其他根文件。展开笔记目录，打开原笔记，切换笔记/文件页和刷新；笔记仍可发现与打开。展开含超过 100 项的工具目录，在该目录内加载更多，根笔记不应消失。面包屑“个人空间”可进入笔记目录。

## 可维护性总结汇总

目录请求从混合职责的 space store 分离到 FileDirectoryManager（树与面包屑两个真实消费者）；移除全空间列表对目录状态的替换与同名转发。原 store 从 415 行降至 406 行，仍有既存超预算警告但本轮净减 9 行；自动检查 0 error/1 warning。主观复核确认新 owner 维护真实请求生命周期、分页和账号隔离，不是空 wrapper。目录/文件 preflight 通过。

## NPM 包发布记录

不涉及 NPM 包发布。私有托管应用的用户可见修复添加自身 patch changeset，按 Worker 部署交付。

## 复盘决定

将“分页窗口不能代表整棵目录树”的具体合同落实到原文件列表 owner、目录 manager 和回归测试；架构事实更新在设计和应用 README。没有证据需要新增全局规则或治理脚本。
