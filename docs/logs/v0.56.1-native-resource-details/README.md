# 资源链接与原生详情统一

## 迭代完成说明

本批修复会话及对象资源链接，统一管理入口和聊天链接的资源展示。完整范围与验收账本见[设计与验收记录](../../designs/2026-09-16-resource-link-contract.design.md)。

- 会话工具原先没有返回资源 URI，而提示要求可点击标题，模型遂猜测协议；共享层现在生成 `nextclaw://sessions/<原始会话 ID>`，工具返回可直接使用的链接，兼容旧输入。
- 对象链接原先把供 AI 阅读的 Markdown 快照作为用户详情。现在复用各领域原生界面，定时任务全局列表、会话工作台和聊天链接使用同一打开器。技能与文件保留正文预览。
- 修复已有资源重复开标签、资源选段未接入输入框、引用来源被当成本地路径，以及选段按钮悬停背景透明。
- 多类资源同时 pending 的环境故障根因未完全定位：后端与命令行请求正常，重启开发前端后恢复；未将连接数等假设写成根因。确认存在的无限等待路径已补默认超时与失败重试，保留调用方取消语义。若环境故障复发，应保留浏览器网络与代理连接证据继续定位。

## 测试/验证/验收方式

共享层、kernel、UI、聊天 UI 的匹配范围类型检查及定向回归已通过；最终原生详情两组测试分别为 82 项及 80 项（有重叠），后续公共入口与引用分支调整分别补跑 10 项和 4 项。定向 ESLint、模块治理、维护性检查及提交前 backlog ratchet 通过。

真实浏览器验证覆盖：会话 URI 与真实 AI 返回链接、八类资源打开、定时任务三个入口一致、Agent 编辑打开并取消、选段及整页引用、失效资源提示、刷新恢复、窄侧栏排版。项目工作项无真实实例，仅自动测试覆盖。未执行、启停或删除真实定时任务，未发送验收草稿。

## 用户/产品视角的验收步骤

1. 打开本地验收会话 `/chat/smoke-native-mu3fx31v-xnqz6xmj`，点击 Agent、定时任务、项目、应用等链接，应显示对应原生详情。
2. 从定时任务管理和绑定会话工作台打开同一任务，核对计划、提示词与最近运行结果一致。
3. 在 Agent 详情打开编辑再取消；选中文字添加到聊天，核对输入框引用及来源；刷新后已有资源标签仍正常显示。
4. 会话链接采用原始 ID，旧链接继续兼容；失效资源显示明确提示。
