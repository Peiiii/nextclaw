# 聊天内实时语音输入交付

## 迭代完成说明

基于 suantea 的 PR #43 保留原始识别探索，并补齐可实际使用的交互：在光标或选区实时转录、暂定文字下划线、完成留在草稿、取消恢复、用户编辑接管、桌面可配置按住说话。录音浮层与快捷键设置互斥且居中，不推动页面；设置 → 快捷键与浮层复用同一控件。原作者提交保留，维护侧以独立补丁补充。

识别累计结果原先会重复追加，现按累计快照替换；临时编辑不发布业务节点，避免引用附件提前清理；会话切换和迟到回调按实例生命周期隔离。无语音结束时的错误曾进入设置视图，现清空识别状态并切换独立设置视图。两层不同圆角及外层 overflow 裁切导致缺角，浏览器样式检查证实后由内层统一拥有边框、圆角和滚动。

## 测试/验证/验收方式

共享编辑器 17 项回归、产品语音/输入/设置/导航 36 项定向测试通过；两包 TypeScript 检查通过。真实 Chrome 以模拟识别事件验证实时修正、取消恢复、设置等待最终结果、无语音进入设置、零布局位移、居中、跨入口绑定、中英文 hover 和紧凑视口边界。真实音频链路由用户在 macOS 体验并完成产品验收；自动化模拟不代表跨浏览器音频服务可用性。

## 发布/部署方式

本批仅将原 PR 及维护补丁合入 master 并同步本地主线，不发布 NPM、不部署、不重启运行实例。

## 用户/产品视角的验收步骤

1. 点击聊天麦克风，确认实时文字出现在光标处且暂定文字带下划线；结束后保留草稿，不自动发送。
2. 取消确认原草稿恢复；打字或移动光标后确认迟到识别不覆盖编辑。
3. 打开录音浮层齿轮，确认只展示快捷键配置；在设置 → 快捷键确认同一绑定，手机不显示键盘配置。
4. 确认浮层居中且不推动输入框，边框圆角完整，中英文悬停提示简短正确。

## 可维护性总结汇总

语音 manager 独占识别生命周期；共享 composer 的一次性 dictation owner 独占可逆编辑；hook 连接外部事件，视图展示状态。复用现有编辑器选区和业务提交链，删除原始 hook 中混杂的绑定与识别实现。diff-only 检查无错误，已有大型文件/函数及接近预算警告保留，不扩大为无关重构。
