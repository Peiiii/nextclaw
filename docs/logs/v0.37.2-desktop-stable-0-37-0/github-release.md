# NextClaw Desktop 0.0.252

## 中文

NextClaw Desktop 0.0.252 正式发布，内置 NextClaw 0.37.0。

- 全新的会话工作台让新建、切换和管理会话更顺手。
- 支持子会话、会话命名与命令耗时展示，复杂任务的进展更清晰。
- CLI 运行中可以继续输入指令，交互不再被长任务阻塞。
- 修复网络恢复、浏览器标签状态等稳定性问题。

[下载 NextClaw Desktop](https://nextclaw.io/zh/download/) · [完整中文更新说明](https://docs.nextclaw.io/zh/notes/2026-08-15-nextclaw-v0-37-0)

## English

NextClaw Desktop 0.0.252 is now available with NextClaw 0.37.0 bundled in.

- A redesigned session workspace makes it easier to create, switch, and manage sessions.
- Sub-sessions, session naming, and command duration indicators make complex work easier to follow.
- You can keep entering instructions while a CLI task is running.
- This release also fixes network recovery and browser tab state issues.
