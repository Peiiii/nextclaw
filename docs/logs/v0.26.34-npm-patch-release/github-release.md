# English Version

NextClaw v0.27.6 gives Codex and Claude Code Agent Runtimes useful NextClaw context without replacing their native instructions. It also improves rich content inspection, proactive visual presentation, and queued-message clarity.

## Highlights

- Configure NextClaw context injection independently for each Agent Runtime.
- Pass structured runtime data to Panel Apps and HTML content through `window.nextclaw.params`.
- Open Mermaid diagrams in a full-screen preview.
- Keep queued messages out of the conversation until execution begins.
- Use compact tables or Mermaid diagrams more proactively when they materially improve clarity.

Full release notes: https://docs.nextclaw.io/en/notes/2026-07-29-nextclaw-v0-27-6

# 中文版

NextClaw v0.27.6 让 Codex 与 Claude Code Agent Runtime 在保留原生指令的同时获得有用的 NextClaw 上下文，并改进富内容查看、主动可视化与排队消息体验。

## 主要变化

- 可以按 Agent Runtime 分别配置 NextClaw 上下文注入。
- Panel App 与 HTML 内容可以通过 `window.nextclaw.params` 获取结构化运行参数。
- Mermaid 图表支持全屏预览。
- 排队消息会等到真正开始执行后再进入会话记录。
- 当表格或 Mermaid 能明显降低理解成本时，Agent 会更主动地选择合适的视觉表达。

完整更新说明：https://docs.nextclaw.io/zh/notes/2026-07-29-nextclaw-v0-27-6
