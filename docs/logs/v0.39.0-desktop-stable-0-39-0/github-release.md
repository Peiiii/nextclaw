# NextClaw Desktop 0.0.255

## 中文

NextClaw Desktop 0.0.255 正式发布，内置 NextClaw 0.39.0。

- 改进空闲 NCP 流的建立与恢复，降低聊天回复在连接切换后停留在旧状态的概率。
- 修正 OpenAI Responses 多轮历史与函数工具协议，提升连续会话的可用性。
- “关闭思考”会在不同模型能力下保持稳定，不再被其它推理等级覆盖。
- 原生 App 现在可以按 macOS、Linux 和 Windows 平台发布，安装时只下载与当前设备匹配的构建。

[下载 NextClaw Desktop](https://nextclaw.io/zh/download/) · [完整中文更新说明](https://docs.nextclaw.io/zh/notes/2026-08-18-nextclaw-v0-39-0)

## English

NextClaw Desktop 0.0.255 is now available with NextClaw 0.39.0 bundled in.

- Improves idle NCP stream startup and recovery, reducing stale chat state after connection changes.
- Corrects OpenAI Responses multi-turn history and function-tool schemas for more reliable continued conversations.
- Keeps the thinking-off preference stable across different model capability declarations.
- Native Apps can now publish macOS, Linux, and Windows builds, while installation downloads only the artifact matching the current device.
