### 必须不发生与架构不变量

BIBO-09 / BIBO-12 补充：统一可复用 Dialog、Sheet、图标操作及反馈语义，业务入口实际消费；逐模块对照成熟产品的交互与功能，覆盖日程、任务、文件、笔记、收件箱、对话/产物和概览。独立检查项及证据维护于工作记录 UI-00～07。借鉴交互原则并保持 Studio 风格；完整模块仍为独立工作区，短命名/创建与确认使用适当弹层。新增功能必须服务现有用户目标，不等于复制竞品全部能力。

最终交付补充 **BIBO-13**：本批正式产品实现合入 `master` 并推送，使用冻结的远程主干部署至 `app.bibo.bot`；上线后实际验证关键用户与 Agent 链路，记录源码 SHA、部署版本及证据，运行主线回收。本地预览、概念站或仅提交代码均不满足本项。来源为用户本轮明确上线要求。

- NextClaw 通用 Agent 内核不吸收 Bibo 的任务、日程、笔记领域模型；Bibo 领域模块可独立注册或移除。
- 结构化任务/日程操作不能依赖模型手改 JSON；网页和 Agent 不能各有一份独立写入规则。
- 不为尚不存在的 Bibo 老用户造兼容、迁移、双写；不破坏仓库中其他 NextClaw 应用的存量数据。
- 浏览器本地缓存不是正式内容真源；不可把拟议中的动作冒充已执行。

### 代表性场景

BIBO-02 / BIBO-09 / BIBO-12 最新细化：重复点击新会话不发起创建请求、不产生空记录，首次发送才创建会话；会话更多和账号辅助操作使用共用菜单；可点击元素具有统一 hover，并提供键盘焦点/按下/禁用反馈。验收同时核对网络请求和可见会话列表，不能只隐藏空记录。

1. 新建两个会话，在其中一个会话生成文件，右侧工作区与文件树查看、编辑同一对象；切换/刷新/重启仍可恢复。
2. 从笔记新建 Markdown，文件树定位与改名/移动，再回笔记编辑；多标签、侧栏收放和窄屏均能继续工作。
3. 创建任务及子任务、推进状态，概览同步；创建/修改日程，概览同步；Bibo 将需关注内容送达收件箱并能处理。
4. Agent 不先加载全部动作 Schema，按需发现某领域动作并完成结构化操作；输入无效、并发版本冲突或远端保存失败时清楚报错且无假成功。

- 默认一个交付阶段，包含设计、底座、业务、界面、集成和验证等工作项；工作项完成不等于整体完成。

- 最终交付必须包含 Bibo 产品的 commit、合入主干并 push、从冻结远程主干部署，以及真实线上黄金链路验证；仅本地开发或预览不构成交付。
- 当前方案选择进程内 Bibo 领域模块及一个统一 Agent 工具；这属于授权内技术判断，可据测量更改，但不得降低 BIBO-07 或数据真源要求。
