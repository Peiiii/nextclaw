从一件事开始

Bibo 是基于 NextClaw 运行的早期托管个人 AI 搭档。你可以告诉它目标、材料和希望交付的结果，继续原来的对话，并决定要不要保留个人背景。

开始使用

  1. 用邮箱验证码注册并登录。验证码邮件来自 NextClaw 账号基础服务。
  2. 告诉 Bibo 一件具体的事，例如“帮我整理今天要完成的三件事，先问我缺少的信息”。
  3. 回答会逐步显示；只有保存完成才会进入对话记录。生成时可点“停止生成”，也可以切换到其他会话阅读和编辑草稿，后台回复仍留在原会话；当前每个账号同时处理一条生成请求。如果连接中断，本轮未保存，输入会保留供重试。
  4. 检查回答，需要修改就继续说。刷新网页后，可继续已保存的对话。长对话滚动时输入区保持可见。

外观与导航

桌面顶部与左侧图标栏形成连续外框，会话与正文位于内侧圆角区域；右侧工作区标题与顶栏对齐，内容独立阅读。图标栏进入各模块，会话栏可独立收起；手机从左上角打开导航；对话页收起底部快捷栏，为阅读和输入留出更多空间，其他模块保留底部入口。普通界面文字、聊天正文和 Markdown 文件预览统一使用 14px 字号，桌面输入框保留两行书写空间；手机输入框与发送按钮同处一行，随内容增长，清空后恢复一行。账号菜单的「外观主题」提供「Bibo 经典」与「简约」，默认经典保留暖白和绿色；两主题共用布局和控件尺寸。选择保存在当前浏览器，刷新后继续生效。无文字图标提示用途，截断标签补全名称；文字筛选、按钮和内容条目不重复显示提示。

你的工作空间

默认概览展示近期日程、任务、收件箱消息和笔记。对话是独立入口，可创建、切换、重命名和删除会话；右侧工作区可与对话并排查看文件。收件箱汇集第一方提醒、待决定事项及 Agent 送达内容。桌面收件箱用紧凑列表与居中的正文阅读区，标题、摘要、状态和日期分层展示；标记已读、处理和查看来源位于顶部，阅读长文时保持可见。手机可从顶部返回列表。正文开头完全相同的一级或二级标题仅在阅读时去重，原文不变。日程默认月视图，支持日／周切换及每天的安排；任务支持项目、优先级、开始／截止时间、四种状态、子任务和搜索；笔记和 Bibo 产物共用文件空间。文件页与对话工作区共用两行顶部：第一行文件标签，第二行路径与操作，下面直接阅读或编辑。点击路径段或目录图标可浏览目录、进入子目录、返回上级并打开文件；目录尚未加载完整时可加载更多，读取失败可重试。切换标签保留草稿，关闭未保存文件可选择保存、放弃或取消；正常已保存时不占用一格保存按钮，有修改后显示保存。文件页保留目录树、搜索与新建；目录、文件、笔记和搜索结果的每行都有「更多」，可移动、重命名或确认删除。手机可从顶部返回目录或笔记列表，长路径横向阅读，标签保留省略与关闭操作。日程详情在桌面月历旁展开，手机可返回月历；任务详情独立滚动，保存操作保持可见。

待办列表可输入名称并按 Enter 连续添加。保存成功后列表立即更新，输入框可继续添加；失败保留草稿供重试。刷新或运行环境重启后，已保存的待办仍会保留。已有空间首次升级可能需要一次装载等待；通过对话创建仍需等待 Bibo 处理。

点击新对话只打开空白页，首次发送消息才创建会话。会话更多菜单提供改名和删除；账号菜单集中提供帮助、退出及清空操作。桌面侧栏的收起和展开入口位于顶部。文件、笔记和项目的命名使用弹窗，失败保留输入。

可以在对话中说“创建一份报告，并在右侧预览”。Bibo 保存文件并请求展示后会自动打开右侧工作区，支持预览与源码编辑；也可请求展示已有文件。仅展示本账号个人空间中已保存的文件，停止生成或保存失败不会打开本轮产物。手机也可自动打开、关闭和重新查看。

阅读公式、代码和图表

对话回复、文件预览与收件箱共用 Markdown 阅读组件，支持标题、圆点和编号列表、嵌套列表、任务复选框、表格和脚注。代码带语法高亮，可单独复制；长代码和宽表格在正文内滚动。

公式支持 $…$、$…$、\(…\) 和 \[…\]。标记为 mermaid 的代码块会绘制图表，可展开、缩放或查看源码；生成中不完整的内容等待后续增量，无效图表保留原文。HTTPS 图片可展开，加载失败显示替代文字。

当前范围

每小时最多 100 次对话请求，每次最多 4000 字；结构化空间数据和压缩空间快照上限分别为 32 MiB。收件箱并不表示已接入你的外部邮箱。外部邮箱和日历账号、后台定时任务及主动通知尚未接入此托管服务。重要结果请自行核对。

网络搜索

Bibo 支持 Exa 网络搜索。直接说“搜索 Cloudflare AI Search 的最新官方说明，并附来源链接”即可；无需自行配置密钥。Bibo 使用搜索返回的相关片段回答并引用来源，请打开链接核对重要信息。搜索词会发送给 Exa，完整会话不会交给搜索服务。

每个账号每 UTC 日最多 100 次搜索，全站每日最多 1000 次、每 UTC 月最多 10000 次，每次最多返回 10 个结果。一次问题可能需要多次搜索，失败请求也计入额度。搜索任务通常在搜索前、结果返回后各调用一次模型，均计入模型额度。额度用完或搜索不可用时，Bibo 会说明情况。

账号、模型与数据

账号验证使用现有 NextClaw 平台身份服务。Bibo 提供独立的免费模型试用额度：每个账号每天最多 250 次模型调用，首发服务每天最多 2000 次。每个账号拥有独立的运行环境；个人空间快照保存在 Cloudflare R2，任务、项目、日程及最近对话显示记录保存在该账号对应的 Cloudflare Durable Object。发送的消息会交给 DeepSeek 模型服务生成回答。

在左下角账号菜单点击“清空个人空间”，可删除 Bibo 保存的对话、结构化空间数据和空间快照。退出登录只清除当前浏览器的登录会话，不删除账号。当前页面尚不提供 NextClaw 平台账号注销；你可以在 NextClaw 账号页面 查看账号信息。

Bibo 处于早期公开阶段。请不要上传无需分享的密码、密钥或敏感材料。
