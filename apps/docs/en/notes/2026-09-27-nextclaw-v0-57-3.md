# NextClaw v0.57.3

Normal message sends no longer display a receipt confirmation card inside the composer. The message text is no longer repeated, and the confirmation card no longer expands the input area.

Draft protection and recovery after send failures remain available. After upgrading, send a message to see the steadier composer.

This Desktop update includes the published Runtime 0.57.3, with macOS, Windows and Linux installers and update channels. It also includes the v0.57.2 fix for sending messages over plain HTTP; see the [previous release notes](./2026-09-26-nextclaw-v0-57-2). Existing configuration and conversations require no migration.
