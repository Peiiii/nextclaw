# NextClaw v0.57.0

This release turns the new-task page into a more natural starting point for a long-term companion. Share an update, think through an idea or begin a concrete action, then return to a relevant recent conversation when work continues. Project, Agent and runtime choices remain available below the composer.

![The NextClaw new-task page offers starting points for updates, ideas, actions and recent conversations](/release-notes/nextclaw-companion-welcome-cn.png)

## Start and continue naturally

- The new-task page offers complete, open-ended suggestions and clears them once you begin drafting, reducing visual layers.
- Relevant recent conversations stay near the starting point so unfinished work is easy to resume.
- Conversation titles begin generating as soon as a message is durably received, using the selected model while preserving manual names and discarding stale results.

## A calmer, more consistent workspace

- New Plain Paper and Ink Paper themes join the renamed Pure White theme. Your own avatar is hidden across themes for quieter message reading.
- The app marketplace is now a dedicated tab that preserves search and browsing position, with inline details, installed-app location and clearer failure feedback.
- Chat headers, dialogs, action menus, workspace panels, file previews and sidebar controls now share more consistent spacing, color and keyboard feedback.

## Continuous reading and input

- Expanding thinking and tool details preserves the reading position. Long groups stay within half the screen and use edge fades to reveal more content.
- Markdown previews support animated `details` sections, local file-type icons and concise guidance for LaTeX formulas.
- Fixes prevent sent Chinese IME text from returning to the draft and hide the down arrow when the latest content is already visible.
- Mobile reports now fill the screen. Continue chatting returns to the source conversation and inserts the report reference.

This version ships across NPM, Runtime and five Desktop platforms. Existing configuration and local data require no migration.
