# NextClaw v0.55.0

This release helps NextClaw understand where it is installed, how data is stored and what is currently running, while making local collaboration feel more continuous, calm and controllable.

## Features

- Native Agents now query current installation, storage, identity, runtime and session facts before answering self-management questions, reducing answers that mistake defaults for live state.
- Local collaboration gains an optional GitHub webhook relay with signature verification, persistent task bindings and connection health. You can explicitly switch back to polling at any time.

## Conversation and sidebar experience

- Sending a message reserves reading space while browsing history keeps its position. Thinking, tool groups, details, and pinned/date groups expand and collapse smoothly while respecting reduced-motion preferences.
- Deferred process details show immediate loading feedback, support inline retry on failure and preserve an explicit choice to collapse them.
- Conversation search, project creation, menus, tabs and sidebar controls now share a tighter layout with clearer hover, pressed and keyboard-focus feedback.

## Fixes and recovery

- New conversations generate a real model-authored title after the reply, including simple greetings, while user-edited titles remain protected.
- CLI self-restart and running-version checks continue to work with web password protection enabled, without requesting browser credentials or disabling protection.

This version ships across NPM, Runtime and Desktop. Existing configuration and local data require no migration.
