# NextClaw v0.57.2

Chat messages can now be sent when accessing NextClaw through a LAN IP address or a plain HTTP URL. Previously, the browser could throw `crypto.randomUUID is not a function` before the message reached the server.

The fix covers the send button, keyboard sends, and preset messages from menus. Acceptance tracking and idempotent retries remain intact: retries reuse the original message identity to avoid duplicate submissions.

Reload the chat page after upgrading. Existing configuration and conversations require no migration. This release is available through NPM and Runtime updates.
