# 2026-08-13 · NextClaw v0.33.1

Published: 2026-08-13
Tags: `release` `npm` `patch`

NextClaw v0.33.1 fixes in-app updates on Linux servers. After an update is downloaded and applied, the service restarts into the new version instead of remaining at “restart required.”

## Fixes

- Older systemd installations now restart into the downloaded version after an in-app update instead of stopping.
- Servers that still use the earlier restart configuration can apply this update without editing the service file first.

## Defaults and compatibility

- NextClaw started manually in a terminal keeps its existing manual-restart behavior.
- Servers already using the current systemd configuration continue to update without migration.
