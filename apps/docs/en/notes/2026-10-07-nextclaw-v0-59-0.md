# NextClaw v0.59.0

This stable release brings recent beta improvements to conversation management, making important discussions and scheduled task results easier to find.

## Persistent session pins

Pins are saved in the instance and survive page refreshes, instance restarts, and browser changes. Pinned conversations appear before regular conversation pagination, so older important discussions stay visible. Existing browser pins migrate without overriding a saved unpin. Failed saves restore the previous state and show an error.

The CLI supports `nextclaw sessions pin <key>` and `nextclaw sessions unpin <key>`.

## A dedicated Scheduled view

The conversation list now offers a Scheduled view for dedicated task conversations, with search, pagination, and persistent view selection. On mobile, open it from the top view menu. Tasks bound to existing regular conversations keep their original classification. Task configuration remains on the scheduled task management page.

## Smaller conversation journals

Adjacent streaming deltas are coalesced as they are recorded, reducing journal size. Preview maintenance of an existing journal with `nextclaw sessions compact-journal <session ID>`. A normal upgrade does not rewrite existing journals.

Stop every instance using the same `NEXTCLAW_HOME` before applying or restoring maintenance. Use `--apply --writers-stopped` after confirming this condition; the command retains a backup and verifies replay. See [CLI commands](/en/guide/commands) for restore conditions and full usage.

## Chat and panel refinements

- Asynchronous questions stay at their original position in assistant messages.
- Ordinary line breaks in user messages display correctly after sending and reopening a conversation.
- Refresh Panel Apps from the host tab's additional actions without closing the app, while retaining app data and permissions.

## Install or upgrade

```bash
npm install -g nextclaw@latest
```

Existing configuration and conversations are retained. This release includes stable NPM packages and the Runtime update channel. Desktop installers follow a separate release.
