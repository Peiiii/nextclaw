# NextClaw v0.59.1

This patch improves task continuity after native Agent context compaction.

## Preserve completed work more clearly

Summaries receive tool names, arguments, call associations and results, and distinguish completed, ongoing, failed and blocked work. Long histories are processed in order without silently skipping intermediate execution records. Repeated compactions carry completed work forward and update the next step.

Complete recent tool rounds retain their original content within the available budget. Parts appended to an existing assistant message after compaction enter the model exactly once, reducing repeated operations and unnecessary investigation.

## Keep progress when compaction fails

A failed compaction preserves the last successful checkpoint. If generation falls back to recent records, the Agent receives an explicit warning that earlier execution status is incomplete and should recover existing results before repeating side effects.

## Install or update

```bash
npm install -g nextclaw@latest
```

Existing configuration and sessions remain compatible; older journals require no migration. This fix ships through stable NPM, Runtime and Desktop update channels. Desktop users can also check for updates in the app or download an installer from [GitHub Releases](https://github.com/Peiiii/nextclaw/releases).
