# 2026-09-01 · NextClaw v0.47.1

Published: 2026-09-01
Tags: `release` `desktop` `patch`

NextClaw v0.47.1 fixes a desktop persistence failure that prevented session lists from loading and messages from being sent reliably. After upgrading, sessions appear normally and accepted messages are saved before processing continues.

## Fixes

- **Session lists load again**: Session summaries are written correctly to the local database, so both new and existing sessions appear in the list.
- **Messages send reliably**: Accepted messages complete persistence instead of appearing successful in the interface while the background write fails.
- **Sessions survive restarts**: Sessions and messages use the same durable storage path and remain available after restarting the desktop app.

## What you need to do

Update to the latest desktop release. The update does not remove existing session data.
