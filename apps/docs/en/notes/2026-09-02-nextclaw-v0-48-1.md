# NextClaw v0.48.1

Released: 2026-09-02  
Tags: Windows, Desktop, session recovery

NextClaw v0.48.1 fixes runtime startup and session recovery after a Windows Desktop upgrade. If you upgraded directly from around v0.44 or another older release to v0.48.0 and sessions would not load, messages could not be sent, or existing sessions remained missing, this update restores runtime startup and rebuilds the session list and messages from durable local history.

## What is fixed

- Fixes a missing compatibility asset that prevented the v0.48.0 runtime from starting under older Windows Desktop launchers.
- Restores session-list entries and existing messages lost from view after an upgrade.
- Preserves sessions you intentionally deleted instead of showing them again.
- Continues writing new messages to the same local history so they remain available after a restart.

## What you need to do

Update to v0.48.1 and restart the desktop app. You do not need to delete local data, reinstall the app, or import sessions manually.
