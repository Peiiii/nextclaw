# 2026-07-28 · NextClaw v0.27.5

Published: 2026-07-28
Tags: `release` `npm` `patch`

NextClaw v0.27.5 is an npm stable patch release. New chats remember the most recently selected model for each Agent Runtime, manual context compaction now shows immediate progress, and missed messages are recovered after a realtime reconnect.

## Enhancements

- Switching Agent Runtimes in a new chat now restores the model most recently selected for that runtime, without overwriting preferences for other runtimes.
- Manually compacting context now shows immediate in-progress feedback and clears it correctly after completion or failure.

## Fixes

- Sent messages appear in the current chat immediately, and content missed during a realtime disconnect is recovered after reconnection.

## Defaults and Compatibility

- Existing `nextclaw@0.27.4` installations can update through the stable channel or reinstall `nextclaw@latest`.
- No configuration, session, or file migration is required.
- This patch does not include a new desktop installer.
