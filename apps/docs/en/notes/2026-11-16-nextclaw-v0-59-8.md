# NextClaw v0.59.8

This release fixes two availability regressions newly reported in [Issue #73](https://github.com/Peiiii/nextclaw/issues/73): archived conversations rejecting tool calls, and new conversations failing with `contentItems.filter is not a function` after large tool results.

## Continue using tools in existing conversations

Archived history or an incomplete summary no longer blocks ordinary tools or requires blanket reconfirmation. Agents can continue the current explicit request, checking history or asking a specific question when a necessary earlier condition or action outcome is missing. Read-only recovery notices saved in older checkpoints are updated when read, without deleting conversations or manually editing files.

## Continue after large tool results

Tool-result previews preserve their structure instead of replacing content arrays with strings. Malformed preview fields already produced by older versions are also handled without rewriting original conversation content.

Actual storage write failures still stop the affected run and report an error, preventing replies that exist only in memory. The original 0.59.1 journal failure trigger remains under investigation and the issue stays open. This release cannot recover content that was never saved.

Upgrade the CLI with `npm install -g nextclaw@latest`, or use this release's desktop update. See [long tasks and context compaction](/en/guide/chat#long-tasks-and-context-compaction).
