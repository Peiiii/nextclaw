# 2026-08-07 · NextClaw v0.28.2

Published: 2026-08-07
Tags: `release` `npm` `patch`

NextClaw v0.28.2 closes the final gap in zero-key onboarding. Fresh installations now create the packaged workspace templates correctly and immediately explain that the built-in OpenCode Zen free-trial model can be used without an API key.

## Fixes

- Fresh installations now create workspace templates such as `AGENTS.md`, `SOUL.md`, and `MEMORY.md` from the correct location in the npm package, without a missing-template warning.
- Initialization no longer tells users to add an API key first. The default OpenCode Zen free-trial model is ready, so `nextclaw agent -m "Hello!"` can run immediately.

## Defaults and Compatibility

- The default remains `OpenCode Zen Free Trial / big-pickle`, with the same seven free-trial models and ordering introduced in v0.28.1.
- Existing configuration and workspaces are preserved. OpenCode Zen free trials use a public gateway, so models, quotas, and availability may change; do not send sensitive or confidential information.
