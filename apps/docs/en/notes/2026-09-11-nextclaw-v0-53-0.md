# NextClaw v0.53.0

Released: 2026-09-11

Tags: workbench, conversations, self-management, mobile, reliability

NextClaw v0.53.0 brings more objects into one workbench. Conversations, files, apps, and object snapshots can open in the main area, right sidebar, or floating windows while retaining content and reading position when the presentation changes. This release also resumes eligible conversations after a controlled restart, reducing disruption when the runtime maintains itself.

## New features

- Open conversations, files, apps, and object snapshots in the unified workbench. Choose the main area, right sidebar, or a floating window, and pin supported resources.
- Discover real skills, scheduled tasks, inbox deliveries, agents, projects, and apps through the NextClaw Resource Protocol. `nextclaw resources list` and `resolve` use the same object URIs and read-only snapshots.
- Resume every eligible active conversation after a controlled restart without restoring or replaying interrupted tool processes.

## Conversation and mobile experience

- Open an existing conversation in a floating window or the global right sidebar while sharing its draft and content state with the main view.
- Use a more compact mobile conversation list with on-demand search and touch-accessible actions. Message details stay concise in narrow containers.
- Generate short conversation titles from the actual topic after a completed reply while preserving manually assigned names.
- See live status for each child session and aggregate activity in workspace overviews and tabs.

## Reliability

- Stop resident timer ingress at the dead-letter boundary and isolate oversized inboxes before they exhaust host memory or disk I/O.
- Claim each restart handoff once; completed tasks and ordinary failures are not mistaken for runs that need recovery.

## Boundaries

Restart recovery currently applies to background services and foreground hosts that support the local runtime API. Desktop and system-supervisor exits, crash recovery, and durable scheduling for arbitrary queued work remain outside this release. Read [Pick up where you left off after a restart](/en/blog/2026-09-11-self-management-restart-continuity) for the complete behavior and evidence.
