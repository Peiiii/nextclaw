# NextClaw v0.59.0-beta.2

This beta makes important conversations easier to find and keeps scheduled task results together.

## Persistent session pins

Session pins are now stored in the instance. Pinned conversations remain at the top after a refresh, instance restart, or browser change. Older pinned conversations also stay visible as more recent conversations arrive.

Existing browser pins migrate automatically. A pin already removed in the instance is not restored from an old browser cache. Failed saves restore the previous state and show an error.

The CLI also supports `nextclaw sessions pin <key>` and `nextclaw sessions unpin <key>`.

## A dedicated Scheduled view

Select Scheduled alongside Time and Project in the conversation list to browse conversations created by scheduled tasks, search their results, and read their history. Filtering and pagination happen on the server, and the selected view survives refreshes. On mobile, use the view menu at the top.

This view contains dedicated conversations created by tasks. Binding a task to an existing regular conversation keeps its original classification. Task configuration remains in scheduled task management.

## Install the beta

```bash
npm install -g nextclaw@beta
```

Existing configuration and conversations carry over. The beta Runtime update channel uses the same version.
