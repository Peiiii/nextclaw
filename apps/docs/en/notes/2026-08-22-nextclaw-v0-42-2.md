# 2026-08-22 · NextClaw v0.42.2

Published: 2026-08-22
Tags: `release` `npm` `patch`

NextClaw v0.42.2 fixes built-in apps that could fail while calling their data service on Windows Desktop. Favorites and Calendar now complete reads and writes with the runtime shipped by NextClaw in installed, unpacked, and portable editions.

## Fixes

- **More reliable Windows built-in app requests**: Favorites and Calendar complete data reads and writes in the actual desktop runtime without requiring a separately installed Node.js.
- **Clearer errors**: classified Service App runtime errors keep their specific error type instead of always appearing as a generic retry message.

## Compatibility

This patch does not change app protocols or existing user data.
