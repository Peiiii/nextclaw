# NextClaw v0.59.6

This release delivers the fix for [Issue #73](https://github.com/Peiiii/nextclaw/issues/73) through stable NPM, the Runtime update channel, and Desktop installers.

## Stop when conversation history cannot be saved

It includes the 0.59.5 fix: a write failure stops the affected run, reports the original cause, and clears pending inputs without repeated log flooding. Permission and I/O read failures are no longer treated as missing sessions. Saved history is retained; content that was never successfully written cannot be recovered by this fix.

## Include history resources for older Desktop hosts

Runtime bundles now include the platform libSQL native resource so older Desktop hosts without built-in SQLite can prepare and read history indexes. Desktop installation and cold-start upgrades undergo automated validation.

Upgrade the CLI with `npm install -g nextclaw@latest`. See [When conversation history cannot be saved](/en/guide/chat#when-conversation-history-cannot-be-saved) for storage recovery steps.
