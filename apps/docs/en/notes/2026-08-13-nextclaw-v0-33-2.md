# 2026-08-13 · NextClaw v0.33.2

Published: 2026-08-13
Tags: `release` `apps` `patch`

NextClaw v0.33.2 focuses on a reliable app update path and a more useful built-in Personal Space. Todos and Calendar now cover the complete everyday flow while keeping personal data in a stable local directory.

## Personal Space

- Todos support quick capture, priorities, due dates, completion, editing, deletion, and undo.
- Calendar supports a month view, local event editing, and public ICS source management.
- Both Mini Apps add responsive layouts, dark mode, clear empty and error states, and keyboard focus behavior.

## App updates

- Fixes the Registry contract error that caused update checks to report `name must be a non-empty string`.
- A successful retry no longer leaves an older failed operation visible; install, update, and uninstall progress remains explicit and asynchronous.
- Local Service App debugging now supplies an isolated data directory, so `app dev` and `app call` work for services that require persistent storage.

## App marketplace

- Discovery only lists current-protocol apps that are explicitly published, while legacy apps remain available through direct install and historical update paths.
- Wide-screen app details and covers now use controlled dimensions instead of growing with the viewport.
