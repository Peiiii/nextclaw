# 2026-08-26 · NextClaw v0.44.0

Published: 2026-08-26
Tags: `release` `npm` `minor`

NextClaw v0.44.0 improves long-document previews, session context in the sidebar, and mid-run steering while making product activity metrics anonymous and free of stable device identifiers.

## Features

- **Navigate Markdown from an outline**: When a Markdown file contains headings, its path bar now exposes the full heading hierarchy and lets you jump directly to a section. Long documents no longer require repeated scrolling to find your place.
- **Inspect session and project context on hover**: Hover over a session or project in the sidebar to see its project, child sessions, scheduled tasks, and other related context in one compact card. Counts and expand controls appear only when needed.

## Enhancements

- **More room for session titles**: Action buttons reserve space only while the row is hovered, leaving more width for titles at rest.
- **Consistent direct and queued steering**: Both steering paths now share the same state transitions and message presentation. Steered messages keep their overflow actions after completion and no longer appear as ordinary chat messages.
- **Broader Desktop beta update checks**: The beta channel now checks both preview and stable releases and offers whichever update has the newer version.

## Fixes

- **Stale queue errors clear automatically**: If a queued message has already started when you steer again, the interface refreshes the queue and removes the obsolete “item not found” error.

## Defaults and compatibility

- **Anonymous activity summaries are on by default**: NextClaw creates separate one-time receipts for the current day, week, and month to summarize active and successful use. It does not upload or store a stable installation ID, account, token, IP address, User-Agent, message content, or tool parameters. Local delivery status remains visible in privacy settings.
- This release is backward compatible. Existing sessions, projects, and update-channel settings require no migration.
