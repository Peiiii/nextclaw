# NextClaw v0.59.11

Manual compaction can advance a long conversation when long source fields were shortened, the model returned a usable summary, and the new checkpoint fits the context budget. Original history stays available, and the checkpoint flags archived details that may still need verification.

Compaction diagnostics include the candidate checkpoint, previous coverage boundary, input budget, and available model usage to help explain failures.
