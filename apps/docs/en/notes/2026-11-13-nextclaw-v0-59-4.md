# NextClaw v0.59.4

This release fixes compaction feedback and recovery progress in long conversations while preserving existing configuration and original session history.

## Visible, persistent failure causes

Manual `/compact` reports an error when a summary is unusable, the provider connection fails, or no new checkpoint is installed. The failure and its cause are saved before the result is returned, so they remain available after reopening the conversation. A failed attempt preserves the last successful checkpoint. Retry after fixing the provider connection.

## Keep long conversations moving

When message count, content structure, or the hard input budget requires compaction, an unavailable summary can still produce a recovery checkpoint backed by source evidence. Already-covered history no longer counts as active structural pressure, reducing repeated requests to compact the same history.

Original history remains readable. Agents must read the source or obtain explicit clarification of necessary conditions before resuming side effects. Under soft token pressure alone, unusable summaries remain deferred to avoid repeated requests on every turn.

Upgrade through the stable Runtime channel, or run `npm install -g nextclaw@latest`. See [Long tasks and context compaction](/en/guide/chat#long-tasks-and-context-compaction) for details. This release does not include a new desktop installer.
