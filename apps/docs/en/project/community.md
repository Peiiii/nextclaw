# Community

If you want to track the project, file feedback, read longer essays, or follow public progress, this is the unified entry point.

## Main Entry Points

- GitHub repository: [Peiiii/nextclaw](https://github.com/Peiiii/nextclaw)
- Report a bug: [Bug Report](https://github.com/Peiiii/nextclaw/issues/new?template=bug_report.yml)
- Propose an idea or improvement: [Idea / Feature Proposal](https://github.com/Peiiii/nextclaw/issues/new?template=feature_request.yml)
- Browse claimable work: [help wanted](https://github.com/Peiiii/nextclaw/issues?q=is%3Aissue%20is%3Aopen%20label%3A%22help%20wanted%22)
- Contribution process: [CONTRIBUTING.md](https://github.com/Peiiii/nextclaw/blob/master/CONTRIBUTING.md)
- Product Notes: [Product Notes](/en/notes/)
- Blog: [Blog](/en/blog/)
- Roadmap: [Roadmap](/en/project/roadmap)
- Public shipping dashboard: [Project Pulse](/en/project/project-pulse)

Submit suggestions and bugs through GitHub Issues. The Roadmap is maintainer planning, not an open task list. Start implementation only when an Issue has `help wanted` and a maintainer explicitly confirms or assigns your scope.

## When to come here

- you want to file issues or follow repository activity
- you want to see what changed recently
- you want to understand the reasoning behind a design decision
