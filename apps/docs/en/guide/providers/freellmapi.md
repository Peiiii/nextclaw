# Connect freellmapi

> **Disclaimer**: freellmapi is a third-party self-hosted free LLM aggregation service, not maintained by NextClaw.
> The author uses it for personal experimentation only, with no SLA. Model catalogs depend on a remote feed whose availability is not guaranteed.
> NextClaw does not endorse it and makes no long-term compatibility promises.

## Quick setup

1. Deploy freellmapi (see [freellmapi repository](https://github.com/tashfeenahmed/freellmapi))
2. In NextClaw settings → Providers → Add custom provider
3. Fill in:
   - **Name**: freellmapi
   - **API Base**: `http://localhost:3001/v1` (or your deployed address)
   - **API Key**: your unified API key
   - **Model discovery**: enable "OpenAI-compatible catalog fetch"
4. Click "Fetch model list" to bulk-import

## Notes

- The default `localhost` address requires freellmapi running locally; replace with your actual address for remote deployments
- Model catalogs are dynamically generated by freellmapi's remote feed and may change at any time
- No SLA is provided; NextClaw cannot guarantee availability if the service is down
