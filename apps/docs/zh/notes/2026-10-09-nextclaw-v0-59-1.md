# NextClaw v0.59.1

这次 patch 改善原生 Agent 在上下文压缩后的任务连续性。

## 更清楚地保留已经做过的事

压缩摘要能看到工具名称、参数、调用关联和结果，并区分已完成、进行中、失败和阻塞事项。长历史按顺序处理，避免中间的执行记录被直接跳过；连续压缩时继承已完成事项并更新下一步。

最近完整工具轮次会在预算允许时保留原文。压缩后同一条助手消息新追加的内容只进入模型一次，减少重复操作和重新摸索当前状态。

## 失败时保留已有进展

压缩失败不会覆盖上一次成功的检查点。无法完整生成摘要而降级保留近期记录时，Agent 会收到执行状态不完整的提示，并应先核对已有结果再重复有副作用的操作。

## 安装或升级

```bash
npm install -g nextclaw@latest
```

已有配置和会话继续沿用，旧日志无需迁移。本次修复通过 stable NPM、Runtime 和桌面更新通道交付。桌面端也可在应用内检查更新；安装包见 [GitHub Releases](https://github.com/Peiiii/nextclaw/releases)。

完整使用说明见[任务与会话](/zh/guide/chat#长任务与上下文压缩)。
