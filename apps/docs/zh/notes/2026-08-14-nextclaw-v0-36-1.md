# 2026-08-14 · NextClaw v0.36.1

发布时间：2026-08-14
标签：`release` `npm` `patch`

NextClaw v0.36.1 修复了更新后仍可能调用旧版命令的问题。通过页面完成更新并自动重连后，Agent、服务重启和新打开的 `nextclaw` 命令都会使用当前 runtime，不再出现页面已经更新、命令行仍显示旧版本的情况。

## 修复

- **更新后的命令保持一致**：Agent 在任务中运行 `nextclaw` 时，会和当前页面使用同一版本。
- **服务重启不再回到旧版**：后台服务、自启动和更新后的生命周期操作会从当前 runtime 继续运行。
- **一次更新即可生效**：仍然从页面下载并应用更新，重连完成后不需要再手动安装一次全局命令。

## 默认行为与兼容性

- 稳定 launcher 仍负责更新选择、回滚和不兼容版本保护；本次更新不改变已有更新入口。
- 全局 npm 包的版本可以低于当前 runtime；`nextclaw --version` 现在报告并执行当前 runtime 的版本。
