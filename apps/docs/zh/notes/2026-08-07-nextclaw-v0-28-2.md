# 2026-08-07 · NextClaw v0.28.2

发布时间：2026-08-07
标签：`release` `npm` `patch`

NextClaw v0.28.2 完成了零密钥开箱体验的最后一段：全新安装不仅默认准备好 OpenCode Zen 免费试用模型，还会正确创建工作区模板，并在初始化完成后直接告诉你无需 API Key 即可开始聊天。

## 修复

- 全新安装现在会从 NPM 发布包的正确位置创建 `AGENTS.md`、`SOUL.md`、`MEMORY.md` 等工作区模板，不再显示“找不到模板目录”的警告。
- 初始化提示不再要求先填写 API Key；默认 OpenCode Zen 免费试用模型已可用，可以直接运行 `nextclaw agent -m "Hello!"`。

## 默认行为与兼容性

- 默认模型仍为 `OpenCode Zen Free Trial / big-pickle`，七个免费试用模型的顺序与 v0.28.1 保持一致。
- 已有配置和工作区不会被覆盖。OpenCode Zen 免费试用通过公共网关提供，模型、额度和可用时间可能变化；请勿发送敏感或机密信息。
