# NextClaw v0.59.0-beta.2

本次 beta 更新让重要会话更容易找回，也让定时任务的历史结果更集中。

## 会话置顶更持久

会话置顶现在保存在实例中。刷新页面、重启实例或换浏览器后，已置顶会话仍会优先显示；较旧的置顶会话也不会因为最近会话变多而被挤出首页。

已有浏览器置顶会自动迁移。实例中已经取消的置顶不会被旧缓存恢复；保存失败时，会恢复之前的状态并提示错误。

CLI 同步支持 `nextclaw sessions pin <key>` 和 `nextclaw sessions unpin <key>`。

## 定时任务会话独立查看

在会话列表的“时间、项目”旁，可以切换到“定时任务”，集中查看定时任务创建的会话、搜索历史结果并继续阅读。筛选和分页都在服务端完成，刷新后保留所选视图；手机端从顶部视图菜单进入。

此视图展示任务创建的专属会话。任务绑定到已有普通会话时，该会话仍保留原来的分类。任务配置继续在定时任务管理页维护。

## 安装 beta

```bash
npm install -g nextclaw@beta
```

现有配置和会话继续沿用。beta 通道的 Runtime 更新包与本版本同步。
