# 2026-08-21 · NextClaw v0.42.0

发布时间：2026-08-21
标签：`release` `npm` `minor`

NextClaw v0.42.0 带来更高可用的服务类应用体验：市场安装页会准确提示当前设备是否支持，并保留可见历史；侧边栏入口也支持可折叠固定分组；同时对 UI 静态资源在发布包中预先生成 gzip 副本，避免部署侧静态服务切换后性能回退。

## 功能

- **主侧栏固定应用分组**：可固定的 Panel App 支持进入“主侧栏”并按分组展示，窄栏下也可快速命中常用入口。
- **应用市场兼容性提示**：市场列表会基于 `target` 命中规则显示不可安装原因，避免错误点击后再试。
- **内置应用兼容 Node 运行时**：声明 `node` 或 `node.exe` 的桌面 Service App 统一使用 NextClaw 内置 Node Runtime，降低系统环境依赖。
- **会话首屏恢复更快**：工具调用会话在加载时先展示受保护的近期上下文，再补齐最近历史，减少重复 hydrate。

## 修复

- **安装/重试行为更一致**：不再把与平台不兼容的应用安装失败持久化为界面全局错误；错误将与该应用条目绑定，返回后可重新尝试。
- **UI 资源发布打包更稳**：`nextclaw` 发布产物会持续附带可校验的 gzip 侧car，外部静态代理可直接复用静态压缩路径。
- **固定侧栏入口一致性**：新增/移除的主侧栏入口不再只在局部列表出现，返回路径与管理动作保持一致。

## 兼容性说明

本次不涉及主版本协议变更；Rust / Go 等原生应用仍走各平台 artifact 发布链。
