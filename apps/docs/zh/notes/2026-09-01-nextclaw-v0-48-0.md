# 2026-09-01 · NextClaw v0.48.0

发布时间：2026-09-01
标签：`release` `projects` `desktop`

NextClaw v0.48.0 让项目从会话集合变成可以持续推进工作的空间。项目主页会汇总工作项、产物、上下文和 AI 运行状态；桌面端会话列表与消息发送也恢复正常。

## 新功能

- **项目工作项**：在项目中创建工作项，使用自定义状态推进，查看完整状态历史，标记关注项，并关联相关产物。概览、列表和看板会实时更新，删除的工作项也可以恢复。
- **项目进展总览**：项目主页会读取项目配置、文件、会话进展和项目 Skills，集中展示当前工作、产物、待关注事项与诊断信息。
- **API 与 CLI 使用同一份项目数据**：可以通过 `nextclaw projects observe` 和项目工作项命令读取或更新数据，自动化与桌面界面保持一致。
- **WASI 应用目录授权**：用户可以查看应用声明的目录权限，选择只读或读写文件夹，并随时替换或撤销授权。

## 改进与修复

- **桌面会话恢复正常**：修复会话摘要写入失败导致列表无法加载、消息看似发送但后台未保存的问题；重启桌面端后会话仍然可用。
- **Portable Action 更省内存**：并发调用共享 Runtime、Engine 和已加载 Component，每次调用只保留独立的运行状态。
- **Runtime 更新更一致**：NPM launcher 更新后会先获取匹配的 runtime bundle，避免新 launcher 与旧执行代码混用。
- **项目移动端布局**：文件预览不再挤压窄屏内容区域。

## 你需要做什么

升级到 v0.48.0 后即可继续使用。现有项目和会话不需要手动迁移，桌面更新不会删除已有会话数据。
