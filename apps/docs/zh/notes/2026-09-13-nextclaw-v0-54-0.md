# NextClaw v0.54.0

现在可以把 GitHub Issue 和 Linear Issue 连接到本地 Codex：加标签邀请后，在原 Issue 看到开始处理的状态，后续留言继续同一个任务。已有官方讨论也能迁移并保留原绑定。

## 新功能

- 新增 `nextclaw collaboration`，优先复用本机 GitHub/Linear CLI 登录，无需再配置一套凭据。
- 原 Issue 支持 `/agent pause`、`/agent resume`、`/agent cancel` 和 `/agent status`；不相关输入可以安静处理。
- 独立 `@nextclaw/collaboration` 包提供 CLI、公开协议、来源适配器和消费者合同。同账号的多个 Agent 用独立签名身份协作；自定义来源和普通脚本可以接入同一条链路。

[按三条优先验收开始使用](/zh/guide/collaboration)。本地协作需要 Node.js 22.13+、电脑在线和宿主运行；默认轮询无需公网 webhook 服务。

## 使用体验

页面操作菜单突出常用动作，布局操作收进侧向子菜单；设置按用途分组，侧栏和移动端保持一致。聊天过程摘要更简洁，只在当前活动回复显示加载动画，历史消息不再一起转圈。

## 修复与恢复

- 移动浏览器回到前台或恢复网络后，及时恢复实时连接和会话状态。
- 微信、飞书等渠道的流式回复不再泄漏历史回复控制标签。
- 应用展示请求正确定位到启用的主面板；无效目标给出明确错误。
- 远程 HTTP 环境的语音输入提示改为说明 HTTPS 要求。
- systemd 托管的受控重启可继续符合条件的会话；普通启动和崩溃不会自动恢复。`nextclaw status` 显示实际提供 API 的进程版本。
- 便携版无法原地升级时提供手动下载入口。本批不发布新的桌面安装器。
