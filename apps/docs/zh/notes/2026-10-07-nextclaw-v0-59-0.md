# NextClaw v0.59.0

本次正式版把近期 beta 中的会话管理改进带到 stable 通道，让重要讨论和定时任务的历史结果更容易找回。

## 会话置顶更持久

置顶保存在实例中，刷新页面、重启实例或换浏览器后仍然有效。置顶会话优先于普通会话分页，较旧的重要讨论也能出现在前面。已有浏览器置顶会自动迁移，不会覆盖已保存的取消置顶操作；保存失败时恢复之前的状态并提示错误。

CLI 同步支持 `nextclaw sessions pin <key>` 和 `nextclaw sessions unpin <key>`。

## 定时任务会话独立查看

会话列表新增“定时任务”视图，集中查看任务创建的专属会话，支持搜索、分页和视图选择持久化。手机端从顶部视图菜单进入。绑定到已有普通会话的任务保留该会话原有分类，任务配置仍在定时任务管理页维护。

## 长会话日志更紧凑

新产生的相邻流式增量会合并记录，减少会话日志占用。旧日志可以先用 `nextclaw sessions compact-journal <会话 ID>` 预览整理收益；普通升级不会自动改写旧日志。

应用或恢复前须停止所有使用同一 `NEXTCLAW_HOME` 的实例。确认后使用 `--apply --writers-stopped`，命令会保留备份并验证回放；恢复条件与完整用法见 [CLI 命令](/zh/guide/commands)。

## 聊天与面板细节

- 异步提问保留在助手消息原来的位置，避免打乱阅读顺序。
- 用户消息中的普通换行在发送后和重新打开会话时正确显示。
- Panel App 从宿主标签的更多操作中刷新，无需关闭应用，保留应用数据和授权。

## 安装或升级

```bash
npm install -g nextclaw@latest
```

已有配置和会话继续沿用。本次发布包含 stable NPM 与 Runtime 更新通道；桌面安装包按独立版本发布。
