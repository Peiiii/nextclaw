# NextClaw v0.53.0

发布时间：2026-09-11

标签：工作台、会话、自我管理、移动端、可靠性

NextClaw v0.53.0 把更多对象带进同一个工作台：会话、文件、应用与对象快照可以在主区域、右侧栏或浮窗中打开，并在切换呈现方式时保留内容和阅读位置。这一版也补上受控重启后的会话恢复，减少运行时维护对正在进行工作的打断。

## 新功能

- 在统一工作台中打开会话、文件、应用和对象快照；支持主区域、右侧栏与浮窗，并可固定支持的资源。
- 通过 NextClaw Resource Protocol 发现技能、定时任务、收件箱交付、Agent、项目和应用等真实对象；`nextclaw resources list` 与 `resolve` 使用同一套对象 URI 与只读快照。
- 受控重启后自动继续所有符合条件的活跃会话，不恢复或重放已经中断的工具进程。

## 会话与移动端体验

- 现有会话可以在浮窗或全局右侧栏中打开，并与主会话共享草稿和内容状态。
- 移动端会话列表使用更紧凑的标题栏、按需搜索和适合触控的操作；窄容器中的消息信息更简洁。
- 回复完成后根据实际主题生成简短会话标题，同时保留用户手动设置的名称。
- 子会话显示各自的运行状态，工作区概览与标签页也会汇总活动状态。

## 可靠性

- Resident timer 到达 dead-letter 边界后会停止继续写入，并隔离过大的 inbox，避免耗尽宿主内存或磁盘 I/O。
- 重启恢复只领取一次交接；已完成任务和普通失败不会被误判为需要恢复。

## 能力边界

重启恢复目前适用于支持本地运行时 API 的后台服务和前台宿主，不包含桌面与系统 supervisor 退出、崩溃恢复或任意排队任务的持久调度。完整说明见[重启之后，接着做事](/zh/blog/2026-09-11-self-management-restart-continuity)。
