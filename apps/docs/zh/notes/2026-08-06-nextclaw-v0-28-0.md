# 2026-08-06 · NextClaw v0.28.0

发布时间：2026-08-06
标签：`release` `npm` `minor`

NextClaw v0.28.0 让后台工作完成后的交付更连续。另一个会话里的回复完成时，你会收到轻量通知；定时任务、后台 Agent 和长期监测生成的重要内容，则可以进入收件箱长期保存、阅读和继续讨论。

![后台会话完成后，NextClaw 在右上角显示可点击的结果通知](/release-notes/nextclaw-v0.28.0-background-results-cn.png)

## 功能

- 其他会话里的 AI 最终回复完成后，右上角会显示可点击通知。通知带有会话标题和纯文本摘要，点击即可回到对应会话。
- AI 可以把 Markdown 或静态 HTML 报告主动送到收件箱。定时简报、调研结果、推荐清单和监测结论不再依赖用户一直停留在原会话。
- 收件箱提供未读、全部和已归档视图，并支持标记已读或未读、归档、恢复和删除。

![后台 Agent 生成的每日 AI 与科技简报在收件箱阅读窗中展示](/release-notes/nextclaw-v0.28.0-ai-delivery-html-cn.png)

## 增强

- 多条未读送达内容共用一个阅读窗，可以在其中前后切换，不会同时叠出多个弹窗。
- 关闭阅读窗或选择“稍后阅读”会保留未读状态，但同一项不会反复自动弹出。没有未读内容时，收件箱默认展示全部历史记录。
- 点击“继续聊”会创建或复用关联会话，并把送达报告作为上下文提供给 AI，无需重新粘贴全文。
- 通知中的 Markdown 标记会被清理为易读摘要；原始会话回复保持不变。

## 默认行为与兼容性

- 收件箱 HTML 面向自包含静态报告。内联样式可以展示，脚本、表单、弹窗、远程资源和网络请求默认被隔离。
- 现有配置、会话和文件不需要迁移。已有 NPM 安装可以通过 stable 更新通道升级，也可以重新安装 `nextclaw@latest`。
- 本次发布不包含新的桌面安装包。
