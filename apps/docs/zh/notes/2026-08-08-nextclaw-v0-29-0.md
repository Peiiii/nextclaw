# 2026-08-08 · NextClaw v0.29.0

发布时间：2026-08-08
标签：`release` `npm` `minor`

NextClaw v0.29.0 重点提升长任务与真实工作区协作的连续性。Native Agent 会在上下文接近窗口边界时自动压缩较早内容，保留摘要和最近的用户原文，并在同一次任务里继续执行；中断或失败的回复也可以直接续跑。

## 功能

- **长任务自动压缩上下文**：压缩预算会同时考虑系统指令、工具、会话内容和输出预留；上下文指示器会显示完整占用与自动压缩线。
- **编辑与继续运行**：可以编辑最近一条用户消息后重新执行，也可以让中断或失败的助手回复从原位置继续，不再额外生成一条回复。
- **工作区文件进入聊天**：新任务可先打开项目文件，再把文件、目录或选中文本片段作为结构化引用加入消息；AI 能读取引用内容，发送后也能返回源文件。
- **模型目录与 Exa 搜索**：Provider 设置支持获取和刷新可用聊天模型，Kimi 加入模型目录发现；搜索设置新增 Exa，并支持自定义 Base URL。

## 增强

- 会话草稿按会话独立保存，切换或刷新后仍可恢复。
- 收件箱阅读、全局通知、Agent 管理、定时任务和聊天界面进一步统一；通知可直接关闭，外部链接可以正常打开。
- 新增“炭夜”深色主题，并改善聊天输入、命令图标、Panel App 滚动恢复和消息时间线稳定性。

## 修复

- 修复压缩事件在刷新后跑到消息末尾、继续运行状态不同步，以及进程重启后残留错误运行状态的问题。
- 修复全新安装无法正确创建工作区模板的问题；默认免费试用模型仍可在无需 API Key 的情况下直接开始聊天。
- 修复 Codex/NARP stdio 图片附件退化为纯文本、聊天错误重复显示和部分消息顺序异常。

## 默认行为与兼容性

- 已有 Agent、Provider、模型和工作区配置保持不变，不需要迁移。
- 配置过小的 Agent 上下文窗口现在会在保存时明确拒绝，避免运行后静默失败。
