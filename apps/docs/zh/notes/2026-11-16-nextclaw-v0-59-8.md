# NextClaw v0.59.8

本版修复 [Issue #73](https://github.com/Peiiii/nextclaw/issues/73) 新反馈的两项可用性回归：旧窗口工具被归档恢复状态拦截，以及新窗口处理大工具结果时出现 `contentItems.filter is not a function`。

## 旧会话可以继续使用工具

历史已归档或摘要不完整时，不再封禁普通工具，也不要求统一再次确认。Agent 可以继续处理当前明确的请求；只有依赖缺失的旧条件或旧操作结果时，才查历史或提出具体澄清。旧检查点保存的只读恢复提示也会在读取时更新，无需删除会话或手动修改文件。

## 大工具结果不再导致下一轮崩溃

修正工具结果预览的结构，避免将内容数组变成字符串。旧版本已经生成的异常预览字段也能兼容读取；原始会话正文不被改写。

存储真正无法写入时，当前运行仍会停止并报告错误，避免继续生成仅存在于内存的内容。原 0.59.1 首次 journal 写入异常的触发原因仍在调查，Issue 保持打开；本版不能找回从未保存的内容。

CLI 可使用 `npm install -g nextclaw@latest` 升级；桌面端使用本版更新。详情见[长任务与上下文压缩](/zh/guide/chat#长任务与上下文压缩)。
