# 2026-08-12 · NextClaw v0.32.0

发布时间：2026-08-12
标签：`release` `npm` `minor`

NextClaw v0.32.0 让 Apps 从工作区里的开发能力，变成用户可以发现、安装和长期使用的产品能力。首个官方组合应用“个人空间”把待办、Markdown 笔记、收藏和日历放进同一个轻量入口；应用更新时，个人数据仍保存在稳定目录中。

## 功能

- **Mini App 市场与完整生命周期**：可以在 Apps 中搜索、查看、安装、启用、打开、更新、回滚和卸载应用包。
- **个人空间**：首发待办、Markdown 笔记、收藏和日历四个独立入口，共享同一个本地数据服务。
- **组合应用包**：同一个 `.napp` 可以只包含 Panel、只包含 Service，或同时包含多个 Panel 与 Service；安装后由现有运行时直接承载。
- **统一系统对象引用**：收件箱报告、定时任务、文件和文件夹可以通过 `@` 面板分类浏览、搜索并带入会话上下文。

## 增强

- Apps 页面增加内置市场、已安装状态、权限确认、包级管理和窄面板布局；安装后可直接打开四个个人空间入口。
- 会话列表的时间/项目切换更紧凑，文件 Explorer 会记住开关状态，并与从外部打开的文件保持选中同步。
- Marketplace 技能更新遇到本地修改时会先提示冲突，只有确认后才覆盖。

## 修复

- 设置页完成运行时更新后，会由稳定 launcher 拉起新版本，页面版本、内核版本和实际进程保持一致。
- 应用安装和更新采用原子事务并校验完整包内容；失败不会留下半安装状态。
- 远程包下载增加体积预算，日历订阅限制不安全网络目标，卸载时会清理运行时授权残留。

## 默认行为与兼容性

- 应用代码按版本不可变保存，应用数据位于稳定目录；回滚、升级、卸载后重装都不会隐式删除个人数据。
- 内置应用默认可用但不会自动启用或授权 Service；首次启用仍由用户确认。
- 既有 Panel App、Service App 和 `.napp` v1 包继续可用；新的组合能力使用 `.napp` schema v2。
- 日历优先作为本地与订阅视图使用，不替代系统日历；笔记保持 Markdown 文件，收藏保持轻量列表。
