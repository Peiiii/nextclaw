# 2026-08-27 · NextClaw v0.44.1

发布时间：2026-08-27
标签：`release` `npm` `patch`

NextClaw v0.44.1 让会话中的定时任务和用量信息更容易查看，也让切换页面和阅读长回复时的位置更稳定。

## 功能

- **在会话中管理定时任务**：可以启用、暂停、立即运行、查看详情或删除定时任务。较长的任务内容会保持紧凑，不会撑开工作区。
- **查看模型调用与 Token 用量**：会话工作台会显示 Agent 轮次、模型调用次数、已报告调用次数和按模型统计的 Token 用量。

## 增强

- **切换后回到原来的阅读位置**：在工作区、会话和常用页面之间切换后，会回到此前的位置。Markdown 文件在切换文件以及源码和预览之间往返时也会保留滚动位置。
- **大量会话打开更快**：会话列表使用分页、排序和预取来减少卡顿；即使历史和工具调用很多，也可以继续浏览全部会话。

## 修复

- **上下文压缩提示显示在正确位置**：长回复仍在恢复时，提示只会在能够定位到正确回复位置后显示，不再堆叠到会话末尾。
