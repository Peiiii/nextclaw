# 2026-08-29 · NextClaw v0.45.1

发布时间：2026-08-29
标签：`release` `npm` `patch`

NextClaw v0.45.1 修复了 v0.45.0 的可移植 Service App 发布缺陷。更新后，「日常小工具箱」和其他 WebAssembly Component 应用会随 Runtime 获得对应平台的原生运行器。

## 修复

- **补齐跨平台运行器**：Stable Runtime 现在会在 Linux x64、Windows x64、macOS arm64 和 macOS x64 上构建并打包对应的原生运行器；缺少运行器时，发布会在上传前直接失败。
- **保留 Unix 执行权限**：Runtime ZIP 会保存文件权限，更新器在安装时恢复权限。由旧版更新器安装的新 Runtime 也会在启动时自动修复运行器的执行权限，不再需要手工执行 `chmod`。
- **把真实应用调用纳入发布验证**：发布验证不再只检查版本号，还会确认公开 Runtime 中的运行器存在且可执行，并实际调用一次内置可移植 Service App。

## 你需要做什么

正常更新到 v0.45.1 即可。更新完成后，重新启用「日常小工具箱」；此前因缺少 `nextclaw-wasmtime-runner` 而失败的 Linux 安装无需手工修补文件。
