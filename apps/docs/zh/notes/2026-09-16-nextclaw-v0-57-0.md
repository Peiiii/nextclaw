# NextClaw v0.57.0

这次更新让新任务页更像长期搭档的起点。你可以直接说近况、梳理一个想法或开始做一件事，也可以回到相关的最近会话；项目、Agent 和运行方式仍在输入框下方随时可切换。

![NextClaw 新任务页提供近况、想法、行动和最近会话入口](/release-notes/nextclaw-companion-welcome-cn.png)

## 更自然地开始和继续

- 新任务页提供完整的开放式建议，输入草稿后自动让出空间，减少界面层次。
- 相关最近会话会出现在起点附近，方便继续尚未结束的工作。
- 会话标题在消息可靠收到后立即并行生成，使用当前选择的模型，同时保护手动命名和更新较晚的输入。

## 更安静、更统一的工作台

- 新增“素笺”和“纸墨”主题；旧默认主题以“素白”保留。所有主题统一隐藏自己的头像，让消息阅读更简洁。
- 应用市场成为应用页的独立标签，保留搜索与浏览位置，并提供页内详情、已安装应用定位和更清楚的失败反馈。
- 聊天标题栏、弹窗、操作菜单、工作区面板、文件预览和侧栏控件采用更一致的间距、配色与键盘反馈。

## 连续阅读与输入

- 展开思考和工具详情时保持阅读位置；较长内容限制在半屏内滚动，并用边缘渐隐提示还有内容。
- Markdown 预览支持可动画展开的 `details` 区块、本地文件类型图标和 LaTeX 公式提示。
- 修复中文输入法发送后草稿重新出现、已经位于底部仍显示向下箭头等问题。
- 移动端报告阅读器使用全屏布局；“继续聊天”会回到来源会话并插入报告引用。

本版本同步发布 NPM、Runtime 与五平台桌面端。现有配置和本地数据无需迁移。
