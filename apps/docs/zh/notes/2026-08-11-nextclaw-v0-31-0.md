# 2026-08-11 · NextClaw v0.31.0

发布时间：2026-08-11
标签：`release` `npm` `minor`

NextClaw v0.31.0 把会话工作区从“打开一个文件”扩展为可以持续管理项目资料的工作界面。目录树和文件预览能够同时保留，常用文件操作不再需要离开当前任务；消息连接恢复、历史日志读取和启动阶段编辑也更稳。

![项目文件 Explorer 和 Markdown 预览同时打开](/product-screenshots/nextclaw-workspace-explorer-cn.png)

## 功能

- **共享项目文件 Explorer**：目录树和文件预览可以同时显示；连续打开文件时，每个文件进入自己的标签页。
- **完整的项目文件操作**：支持新建文件与文件夹、上传多个文件、下载、重命名、删除、复制路径，以及把文件或文件夹添加到聊天。
- **可调整并记忆的侧栏**：拖动分隔线即可调整 Explorer 宽度，刷新后仍会保留；只有可用空间不足时才使用覆盖式侧栏。
- **并行只读工具**：Native 会话同一轮中的只读文件、图片、网页和记忆查询可以并行执行；写入、命令和未声明安全的工具仍保持独占，结果继续按原调用位置回填。

## 增强

- 项目根目录空白处和文件夹都提供符合代码编辑器习惯的右键菜单；文件夹不会再显示含义不清的“打开”。
- 新建项目会自动滚动到输入位置，面包屑在空间不足时保持单行并优先保留当前文件。
- 文件和会话文本的划选操作会在选区完成后稳定出现，并避免与拖拽侧栏等操作互相干扰。

## 修复

- Web Chat 的空闲 SSE 连接会主动保活；短暂断流可以补齐会话并重连，持续失败仍会明确提示。
- 启动恢复改为逐会话、逐行扫描历史日志，降低大型 journal 的峰值内存和 OOM 风险。
- NCP 尚未就绪时会暂时禁用消息编辑与继续运行，服务可用后自动恢复，避免保存请求无响应。

## 默认行为与兼容性

- 文件新建、上传、重命名和删除都限制在当前项目根目录内；同名上传默认不覆盖，删除前会再次确认。
- 原有文件预览和“添加到聊天”入口继续可用，不需要迁移工作区配置。
- 不可靠的 Agent 内 `gateway.restart` 已移除；需要重启时，从外部终端运行顶层 `nextclaw restart`。`nextclaw gateway` 只负责启动前台 gateway。
