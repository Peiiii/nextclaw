# 2026-08-26 · NextClaw v0.44.0

发布时间：2026-08-26
标签：`release` `npm` `minor`

NextClaw v0.44.0 改善了长文预览、会话侧栏和运行中插话体验，并把产品活跃统计收敛为不使用稳定设备标识的匿名汇总。

## 功能

- **在 Markdown 预览中浏览目录**：打开包含标题的 Markdown 文件时，可以从路径栏查看完整标题层级，并直接跳到对应章节。阅读长文档时不再需要反复滚动寻找位置。
- **查看会话与项目的悬浮信息**：在侧栏悬停会话或项目即可集中查看所属项目、子会话和定时任务等信息。数量和展开图标只在需要时出现，列表保持简洁。

## 增强

- **会话标题展示更完整**：操作按钮只在悬停时预留空间，平时可以看到更长的会话标题。
- **直接插话与排队插话保持一致**：两种插话方式使用相同的状态与消息呈现。任务完成后仍可从消息打开更多操作，插话也不会被误显示为普通消息。
- **桌面端 beta 更新检查更全面**：使用 beta 渠道时会同时检查预览版和正式版，并提示其中版本更新的可用更新。

## 修复

- **过期的队列错误会自动消失**：排队消息已经开始运行后再次插话，界面会刷新当前队列并清除旧错误，不再提示找不到已经执行的队列项。

## 默认行为与兼容性

- **匿名活跃汇总默认开启**：NextClaw 只为当天、本周和本月分别生成一次性收据，用于汇总活跃与成功使用趋势。它不会上传或保存稳定安装标识、账号、令牌、IP、User-Agent、消息内容或工具参数；可以继续在隐私设置中查看本机投递状态。
- 本次更新保持向后兼容，现有会话、项目与更新渠道配置无需迁移。
