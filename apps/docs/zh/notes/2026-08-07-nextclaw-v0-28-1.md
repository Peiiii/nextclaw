# 2026-08-07 · NextClaw v0.28.1

发布时间：2026-08-07
标签：`release` `npm` `patch`

NextClaw v0.28.1 缩短了从安装到第一次对话的路径。全新安装会直接准备好 OpenCode Zen 免费试用模型，无需先申请或填写 API Key；聊天输入、侧栏导航和消息显示也更加清楚稳定。

## 功能

- 全新安装默认启用 `OpenCode Zen Free Trial`，并选择 `big-pickle` 作为初始模型。打开任务后可以直接发送第一条消息。
- 模型选择器提供当前验证可用的七个免费试用模型。已有用户的其他提供商、模型和 API Key 配置保持不变。

## 增强

- 欢迎页和聊天输入工具栏更简洁，技能、模型、图片附件、内嵌 token 与富文本选区的操作反馈更加一致。
- 会话侧栏在时间、项目和其他页面之间切换时保持稳定，不再残留错误的会话选中状态；添加项目操作也更容易识别。
- 会话列表中的思考、工具调用、运行失败和意外中断预览会跟随界面语言显示。

## 修复

- 修复并发消息完成时聊天记录偶尔重叠或重复显示的问题，并隐藏静默回复遗留的异常文本。
- 输入框上方的会话内容使用更自然的边缘渐隐；全局完成通知在悬停时保持清晰不透明。

## 默认行为与兼容性

- 升级不需要迁移已有配置。OpenCode Zen 免费试用通过公共网关提供，模型、额度和可用时间可能变化；请勿发送敏感或机密信息。
- 已有 NPM 安装可以通过 stable 更新通道升级，也可以重新安装 `nextclaw@latest`。
