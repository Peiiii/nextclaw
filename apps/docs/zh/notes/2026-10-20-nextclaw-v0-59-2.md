# NextClaw v0.59.2

> 发布状态：NPM 包已发布，但 Windows 实装验证发现目录同步问题，此版本未推广至 Runtime 更新通道。请使用已修复此问题的 [v0.59.3](./2026-10-20-nextclaw-v0-59-3)。

本次修复改善长会话的上下文压缩可靠性，以及大历史和超大消息的加载速度。

## 摘要失败时保留恢复路径

摘要为空、提前结束或超出预算时，NextClaw 不会把它当作完整历史。如果当前上下文仍能容纳，会延后压缩；必须缩减时，会保存恢复检查点并保留原始记录。

恢复期间，Agent 可以读取本会话历史并询问缺失的业务条件。明确确认这些条件前，其它工具暂停执行，减少在执行结果不清楚时重复操作。普通聊天或 Agent 自称恢复不会解除限制；渠道中的确认格式见[会话管理](/zh/guide/sessions)。

## 大历史按需读取

打开会话只读取有界页面。大消息显示预览，原文可以逐片读取，不必一次载入整个文件。运行上下文和闲置会话缓存也设置了容量上限。

旧历史首次打开或索引需要重建时，会显示准备进度，可以停止并稍后重试。首次准备仍需要扫描原始记录，大量细碎事件可能耗时较长；完成后正常分页无需重新扫描全部历史。

## 升级与兼容

```bash
npm install -g nextclaw@latest
```

已有配置和原始会话记录保留。本次仅完成 NPM 发布，Runtime 推广被 Windows 校验阻止。升级前可备份数据目录；旧版不能直接继续写入使用新恢复语义的会话，回退需要先由当前版本恢复成完整快照。本次不发布新的桌面安装包。
