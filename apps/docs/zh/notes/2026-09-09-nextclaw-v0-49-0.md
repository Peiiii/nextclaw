# NextClaw v0.49.0

发布时间：2026-09-09

标签：语音输入、CLI、模型、会话、移动端

NextClaw v0.49.0 为聊天加入可控的语音输入，为模型提供商、模型和网页搜索提供对象级 CLI，并改善大型会话的加载、恢复和工具记录显示。

## 新功能

- 聊天支持点击录音；桌面端还可以启用按住说话快捷键。转录文字会出现在当前光标位置，录音结束后保留在草稿中，不会自动发送。
- `nextclaw` CLI 现在可以添加和管理模型提供商、发现与配置模型、测试连接、完成受支持提供商的授权、选择默认模型，以及配置网页搜索。

## 体验改进

- 会话列表和大型会话打开得更快，实时状态变化不再反复刷新整页列表。
- 模型选择器会优先显示收藏和最近使用的模型，其余模型按提供商分组。
- 手机聊天隐藏用户消息右侧头像，为正文留出更多空间；页面从后台或断网恢复时会主动重建实时连接。

## 修复内容

- 任务结束后，聊天页不再因为旧列表状态继续显示“正在思考”。
- 多轮工具调用在刷新后不再出现重复工具消息或持续等待动画。
- 命令执行成功后，工具卡片会正确显示 `stdout`、`stderr` 等终端输出。
- “已处理”状态会保留并显示实际耗时，刷新页面后仍然可见。

## 你需要做什么

正常升级即可。首次使用语音输入时，请按系统提示授予麦克风权限；桌面按住说话快捷键为可选设置。
