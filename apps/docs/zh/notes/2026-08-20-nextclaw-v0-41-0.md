# 2026-08-20 · NextClaw v0.41.0

发布时间：2026-08-20
标签：`release` `npm` `minor`

NextClaw v0.41.0 增加了可控的产品活跃统计，并修复了桌面端 Service App 对系统 Node 的隐式依赖。

## 功能

- **隐私与统计设置**：在设置中选择是否分享最小化的产品活跃数据。该选项默认关闭，只有手动开启后才会上报。
- **区分真实用户与测试设备**：开启后可以将当前安装标记为外部用户、团队 / 自用或 QA 测试，避免团队和测试流量进入外部用户指标。
- **连续但克制的安装身份**：未登录安装使用随机匿名标识；登录后可以按账号归并统计，不需要把个人内容作为活跃数据发送。

## 修复

- Desktop 中声明 `node` 或 `node.exe` 的 Service App 现在使用 NextClaw 自带的 Node runtime，不再要求 Windows、macOS 或 Linux 额外安装系统 Node。
- 内置“个人空间”的收藏和日历会沿用同一个本地数据目录；升级后可直接继续读取已有内容，无需迁移。
- Service App 启动失败时返回结构化错误，不再把 HTML、裸 500 或内部 endpoint 当作应用内容展示。

Rust、Go 等原生 Service App 仍按各自平台 artifact 启动；显式使用 `python3`、`git` 等系统命令的应用也不会被改写。
