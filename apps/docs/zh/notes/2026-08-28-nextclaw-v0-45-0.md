# 2026-08-28 · NextClaw v0.45.0

发布时间：2026-08-28
标签：`release` `npm` `minor`

NextClaw v0.45.0 新增了可移植的 Service App 运行方式。开发者可以把 Rust 业务逻辑编译为 WebAssembly Component，再交给 NextClaw 在不同桌面平台上运行。

## 功能

- **一次构建，多平台运行**：NextClaw 会使用随产品提供的原生运行器加载 WebAssembly Component。在 macOS、Windows 和 Linux 上安装应用时，不需要为每个平台各自准备一套应用逻辑。
- **从普通小工具开始体验**：内置的「日常小工具箱」包含今日清单、灵感便签、专注小钟和联系人整理。它们分别展示数据保存、后台常驻事件、模块协作、面板授权，以及 Agent 调用应用能力。

## 如何开始

如果你想开发这类应用，可以先了解 [Portable Runtime](/zh/developers/portable-runtime)，再按 [开发可移植 Service App](/zh/developers/portable-service-apps) 完成第一个 Rust + WebAssembly Component 应用。

`nextclaw app check`、`nextclaw app dev` 和 `nextclaw app call` 已支持这条开发与调试链路。

## 当前范围

这项能力目前处于实验阶段：官方 Guest 开发路径覆盖 Rust；Secret、文件和 Blob、长任务与流式能力，以及运行不受信任代码所需的生产级资源隔离仍在完善中。
