# NextClaw v0.55.0

这次更新让 NextClaw 更清楚自己安装在哪里、数据如何保存和当前怎样运行，也让你在本地协作中获得更连续、安静、可掌控的体验。

## 新功能

- 原生 Agent 会先查询当前安装、存储、身份、运行时和会话事实，再回答自管理问题，减少把默认值误当成当前状态的情况。
- 本地协作新增可选的 GitHub webhook relay：校验签名后接收事件，保留持久任务绑定并报告连接健康；需要时可以明确切回轮询。

## 会话与侧栏体验

- 发送消息时为回复预留阅读空间，浏览历史时保持当前位置；思考过程、工具组、详情以及置顶/日期分组均支持平滑展开收起，并尊重“减少动态效果”设置。
- 延迟加载的过程详情立即显示加载反馈，失败后可在原位置重试，同时保留用户主动收起的选择。
- 会话搜索、项目创建、菜单、标签和侧栏交互统一为更紧凑、更清晰的布局与悬停、按下、键盘焦点反馈。

## 修复与恢复

- 新会话在回复完成后会用本轮模型生成真正的会话标题；问候等简单对话也不再长期停留在首条消息截取标题，用户手动标题继续受到保护。
- 开启网页密码保护时，CLI 自重启和运行版本检查可通过本地自管理认证继续工作，无需索要浏览器密码或关闭保护。

本版本同时发布 NPM、Runtime 与桌面更新。现有配置和本地数据无需迁移。
