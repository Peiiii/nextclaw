# 2026-08-29 · NextClaw v0.45.3

发布时间：2026-08-29
标签：`release` `npm` `patch`

NextClaw v0.45.3 修复了旧实例升级后，Agent 任务可能在第 20 次工具调用后突然中止的问题，同时加快岛屿主题的背景加载。长时间运行的任务会继续执行；进入 Island 页面时，背景会更早出现，刷新后也不再重复下载整张图片。

## 修复

- **长工具链不再被旧值提前中止**：旧实例配置中可能保留的 `20` 次上限不再参与 Agent 运行。NextClaw 的原生 Agent 统一使用 1000 次工具调用安全预算。
- **移除无效配置入口**：设置页、Agent 详情和配置 API 不再显示或返回工具调用上限，避免用户修改一个不应由实例配置控制的运行时保护值。
- **保留极端任务保护**：达到固定安全预算时，NextClaw 仍会明确终止任务，防止异常工具循环持续消耗资源。
- **岛屿主题背景更快出现**：已选择岛屿主题时，NextClaw 会在界面启动阶段提前加载背景，减少先看到空白纸面再补上画面的等待。
- **刷新复用背景缓存**：背景在保持 1536×1024 清晰度的同时，从约 164 KB 降到约 83 KB；正常刷新和再次打开页面会复用已下载文件。其它主题不会请求它。

## 你需要做什么

更新到 v0.45.3 并重启 NextClaw。旧配置文件无需迁移或手工删除字段；已经选择岛屿主题的用户也不需要重新设置主题。
