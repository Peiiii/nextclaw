# NextClaw v0.59.6

本版完整交付 [Issue #73](https://github.com/Peiiii/nextclaw/issues/73) 的修复，包含稳定 NPM、Runtime 更新通道与桌面安装包。

## 会话保存失败时停止运行

继承 0.59.5 的修复：会话写入失败时停止受影响的运行、明确报告错误并清空待运行输入，保留首次底层原因，避免反复刷屏。权限或 I/O 读取错误不再被误当成会话不存在。已保存的历史保留；从未成功写入的内容无法由本次修复找回。

## 补齐旧桌面宿主的历史读取资源

Runtime 包现在包含对应平台的 libSQL 原生资源，供尚无内置 SQLite 的旧桌面宿主读取和准备历史索引。桌面安装与冷启动升级均经过自动验收。

CLI 使用 `npm install -g nextclaw@latest` 升级。存储故障的处理参见[会话记录无法保存时](/zh/guide/chat#会话记录无法保存时)。
