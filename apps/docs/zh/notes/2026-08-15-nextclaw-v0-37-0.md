# 2026-08-15 · NextClaw v0.37.0

发布时间：2026-08-15
标签：`release` `npm` `minor`

NextClaw v0.37.0 让长任务和复杂会话更容易观察与继续。会话工作台现在会汇总 Token 用量和缓存命中率，也能直接创建继承当前上下文的子会话；命令执行期间会持续显示耗时。CLI、Web Chat 和内嵌浏览器同时补齐了几处会打断工作流的交互与恢复问题。

## 功能

- **查看会话 Token 用量**：会话工作台会按模型显示输入、输出、缓存输入、总量和缓存命中率，帮助你判断长会话的上下文消耗。
- **从当前会话创建子会话**：子会话管理页新增创建入口，新会话会继承当前上下文，适合把并行工作拆开处理。
- **查看命令执行耗时**：命令运行时会持续显示已用时间；成功、失败或取消后会保留最终耗时，刷新页面后仍能恢复。

## 增强

- **CLI 运行中继续输入**：Agent 仍在执行时可以继续提交输入，后续消息会进入既有队列，不必等待当前运行结束。

## 修复

- Web Chat 在网络中断后会恢复流式会话，并继续同步服务端状态，减少重连后界面停在旧状态的情况。
- 内嵌浏览器的标签关闭按钮与紧凑标签操作更稳定，点击区域和覆盖层不会再互相干扰。

## 默认行为与兼容性

- Token 统计沿用各模型已经提供的 usage 数据；只有模型返回缓存输入信息时，界面才会显示对应缓存命中率。
- 运行中的 CLI 输入仍按顺序处理，不会打断当前正在执行的动作。
