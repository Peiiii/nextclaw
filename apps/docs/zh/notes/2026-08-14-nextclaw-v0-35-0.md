# 2026-08-14 · NextClaw v0.35.0

发布时间：2026-08-14
标签：`release` `npm` `minor`

NextClaw v0.35.0 把 Apps 从“可以安装的包”推进为可以长期使用的个人软件。应用代码、安装版本和个人实例数据现在拥有各自的生命周期；更新失败不会先切断正在使用的版本，卸载也不会顺手删除个人数据。

## 功能

- **独立 App Instance**：每个应用实例拥有 data、config、state、cache、tmp 和 logs 分类目录。Package、工作区 Service 和开发态 Service 使用同一套存储合同。
- **先探测、后更新**：候选版本会先完成完整性、NextClaw 版本、数据 schema 和 Service 启动探测，全部通过后才成为当前版本。
- **可恢复的卸载**：卸载默认只移除代码，保留实例数据；同一发布者重新安装后可以继续使用，其他发布者不能接管。

## 增强

- Apps 页面显示真实的数据目录、占用空间、runtime profile 和隔离等级。
- 原生 Service App 会明确标注为当前用户完整权限，不再以“无额外权限”弱化风险。
- 安装版本增加内容完整性校验和跨进程操作锁，避免并发安装、更新、回滚或卸载互相覆盖。
- Marketplace 会归一化包内真实能力；社区原生 Service App 可以保持未公开，但不能直接进入公开目录。

## 修复

- 开发态 Service 的数据不再跟随临时目录消失，而是按应用和源码位置稳定保存。
- Service action 的风险等级提高后，旧授权不再自动覆盖新的高风险调用。
- 旧应用数据迁移失败时保持旧布局可用，不会留下半切换状态。

## 默认行为与兼容性

- 既有 `.napp` 和 schema v1 应用继续可用；第一次读取旧数据时会执行一次受控迁移。
- 没有受支持迁移合同的数据 schema 变化会在更新前被阻止，避免旧代码静默读取不兼容数据。
- Package 目录的只读属性用于防止意外修改；原生进程仍按当前用户权限运行，NextClaw 不把它描述为操作系统沙箱。
