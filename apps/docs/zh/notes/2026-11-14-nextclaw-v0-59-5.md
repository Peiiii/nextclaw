# NextClaw v0.59.5

本版修复会话日志写入失败后仍继续运行的问题，对应 [Issue #73](https://github.com/Peiiii/nextclaw/issues/73)。

## 保存失败时明确停下来

会话记录无法保存时，受影响的运行会停止，界面会收到明确的存储错误，未执行的排队输入会清空。其它正常会话仍可工作。首次底层错误及文件系统诊断会保留，相同故障不再持续刷屏。

修正磁盘空间、目录权限或文件访问问题后，重启 NextClaw，再重新发送未完成的请求。已有保存记录会被保留；这次修复不能找回从未成功写入的内容。

## 区分无法读取与不存在

已有会话因为权限或 I/O 故障无法读取时，会明确报告错误，不再把它误当成不存在的会话。

本次同时提供桌面安装包与稳定更新通道。CLI 可运行 `npm install -g nextclaw@latest` 升级。详见[会话记录无法保存时](/zh/guide/chat#会话记录无法保存时)。
