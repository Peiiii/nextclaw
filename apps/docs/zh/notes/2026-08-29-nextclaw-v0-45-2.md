# 2026-08-29 · NextClaw v0.45.2

发布时间：2026-08-29
标签：`release` `npm` `patch`

NextClaw v0.45.2 继续修复可移植 Service App 在正式安装环境中的启动问题。更新后，较旧的 Linux 发行版也能运行「日常小工具箱」；如果 NPM 安装包里没有当前平台的完整 Runtime，NextClaw 会自动下载并切换到对应的正式 Runtime。

## 修复

- **兼容更多 Linux 系统**：Linux x64 runner 改为静态链接，不再依赖构建机器上的较新 glibc。此前出现 `GLIBC_2.33` 或 `GLIBC_2.34 not found` 的服务器可直接更新使用。
- **自动补齐缺失的 Runtime**：首次安装或升级后，如果当前 Runtime 缺少 runner，NextClaw 会从签名更新通道下载完整的同版本 Runtime；完整的已安装 Runtime 不会再被不完整的 NPM 内置副本覆盖。
- **runner 失败不再带崩主服务**：NextClaw 会接住 runner 启动和通信错误并返回结构化失败信息，避免子进程退出造成宿主进程 `EPIPE` 崩溃和反向代理 502。
- **发布前验证真实启用链路**：跨平台发布验证会启动正式 Runtime，启用内置可移植应用，检查 Action、Resident、Provider 和组合调用，并执行一次真实 Action。
- **恢复 Node 26 干净安装验证**：更新 SQLite 原生依赖，并在发布流程中保留安装脚本，防止跳过原生依赖后得到误报成功。

## 你需要做什么

更新到 v0.45.2 并重启 NextClaw，然后重新启用「日常小工具箱」。不需要手工复制 runner、安装新版 glibc 或修改文件权限。
