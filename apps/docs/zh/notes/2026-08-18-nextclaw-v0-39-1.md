# 2026-08-18 · NextClaw v0.39.1

发布时间：2026-08-18
标签：`release` `npm` `patch`

NextClaw v0.39.1 修复了原生 Service App 在 Linux 上安装后丢失执行权限的问题。

## 修复

- 安装器现在会为当前平台已验证的包内 Service 启动文件保留执行能力，同时继续把安装目录冻结为只读。
- 使用 Rust、Go 或 C++ 构建的 Linux Service App 可以直接启用和调用，不再因 `spawn EACCES` 失败。

## 默认行为与兼容性

- Node.js 等系统命令、绝对路径和普通资源文件的权限行为不变。
- 现有 App 包无需重新设计 manifest；重新安装后即可应用修复。
