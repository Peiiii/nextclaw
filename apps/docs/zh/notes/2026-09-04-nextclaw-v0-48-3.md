# NextClaw v0.48.3

发布时间：2026-09-04

标签：启动、会话、项目、PWA

NextClaw v0.48.3 缩短了历史会话较多时的启动等待，修正了静默回复和 PWA 链接行为，并收拢了项目数据与项目操作入口。升级后，项目与任务数据会自动迁移，不需要手工处理。

## 体验改进

- 启动时不再扫描全部历史会话。历史越多，启动改善越明显；如果上次会话意外中断，仍会正常恢复。
- 项目注册信息与工作项统一保存到本地数据库，旧的 `projects.json` 会自动、完整地迁移。
- 项目移除入口收进项目行的“更多”菜单，减少误操作，也让项目列表更清爽。
- 项目资料来源更明确：项目工作区只展示主动关联的产物，Skills 来自 `.agents/skills`，长期约定来自项目根目录的 `AGENTS.md`。产物列表同时改进了去重、分页和搜索。

## 修复内容

- `<noreply/>` 现在只有在回复内容完全等于该标记时才会静默；包含说明文字的正常回复不会再被误隐藏。
- PWA 不再接管 Panel App 的“在新标签页打开”，链接会按用户选择在浏览器新标签页中打开。

## 兼容性调整

- 旧的 Project Markers 与项目观察入口已移除，包括 `.nextclaw/project.yaml`、项目观察接口和 `nextclaw projects observe`。项目上下文现在使用上面列出的明确来源。

## 你需要做什么

正常升级即可。首次使用新版时，已有项目数据会自动迁移，无需重新添加项目或手工转换文件。
