# NextClaw v0.59.4

本版修复长会话压缩的结果反馈和恢复推进问题，保留已有配置与原始会话记录。

## 失败原因可见、可保留

手动执行 `/compact` 后，如果摘要不可用、供应商连接失败或没有安装新检查点，会显示失败及具体原因。失败记录会先保存，再返回结果；刷新或重新打开会话后仍能查看。上一次成功的检查点不会被失败结果覆盖，修正供应商连接后可以再次压缩。

## 让长会话继续推进

消息数量、内容结构或硬预算要求回收上下文时，摘要不可用仍可保存带来源证据的恢复检查点。已覆盖的旧历史不会继续被算作活跃结构压力，减少反复压缩同一段历史的请求。

原始历史仍可读取。恢复期间，Agent 需要先读取原文或明确澄清必要条件，再继续有副作用的操作。只有软 token 压力时，系统继续延后不可用摘要，避免每轮重复请求。

通过 stable Runtime 更新通道升级，或运行 `npm install -g nextclaw@latest`。更多说明见[长任务与上下文压缩](/zh/guide/chat#长任务与上下文压缩)。本次不包含新的桌面安装包。
