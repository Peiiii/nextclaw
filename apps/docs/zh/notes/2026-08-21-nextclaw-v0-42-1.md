# 2026-08-21 · NextClaw v0.42.1

发布时间：2026-08-21
标签：`release` `npm` `patch`

NextClaw v0.42.1 修复桌面端内置服务应用的运行时兼容问题。收藏、日历等内置应用不再依赖用户单独安装的系统 Node.js；它们会使用 NextClaw 随桌面端提供的运行时启动。

## 修复

- **内置服务应用可在无系统 Node.js 的桌面环境运行**：收藏和日历等内置应用会使用 NextClaw 内置运行时，避免 Windows 或 Linux 环境差异导致请求失败。
- **失败响应保持可识别**：服务应用请求即使发生未预期异常，也会返回结构化错误，而不是让界面收到无法解析的服务器响应。

## 验证

稳定发布流程现在会在 Linux 与 Windows 的真实 Electron 宿主中执行收藏和日历请求，并隔离系统 `PATH`，持续验证该路径不依赖外部 Node.js。

## 兼容性说明

本次为补丁更新，不改变应用协议或用户数据格式。
