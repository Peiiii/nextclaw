# 2026-08-10 · NextClaw v0.30.0

发布时间：2026-08-10
标签：`release` `npm` `minor`

NextClaw v0.30.0 更适合放在 VPS、NAS 或个人服务器上长期运行。未启用的消息渠道不再常驻独立进程，需要授权或启用时才会启动；聊天也加入了更精确的历史消息片段引用，并改善图片、Mermaid 图表和新增模型的查看与操作。

## 功能

- **消息渠道按需运行**：未启用的微信、飞书、QQ、Discord 等渠道不会启动独立进程；运行中启用或禁用渠道会自动创建或回收对应运行时，不需要重启 NextClaw。
- **更低的空闲内存**：在 ARM64 Linux、2 vCPU / 2 GiB 限制和无活跃任务的空配置基准中，三轮平均 working set 从旧版本约 865～885 MiB 降至 164.94 MiB，下降约 81%。不同架构和活跃任务的占用会随实际工作变化。
- **引用历史消息片段**：可以划选用户或 AI 历史消息中的一段文字，作为结构化引用加入输入框；发送后仍保留紧凑引用，AI 收到的是选中时的精确快照。

## 增强

- 图片与 Mermaid 图表采用统一的全屏预览，支持适应窗口、缩放、拖拽、复位，以及复制图片或 Mermaid 源码。
- 新模型提醒固定在模型选择器底部；打开模型目录后，可以搜索、按提供商筛选、逐项添加，或者明确忽略本批提醒。
- 右侧快捷栏移除低频的服务应用默认入口；服务应用仍可从应用页面访问并按需固定。

## 修复

- 修复结构化引用的删除按钮在部分界面无法显示的问题；鼠标悬停或键盘聚焦时均可稳定操作，标签宽度不会跳动。
- 文件预览和会话消息的划选浮层会在松开选择后稳定出现，并自动避让视口边界。

## 默认行为与兼容性

- 已有 `enabled: true` 的消息渠道会继续正常启动；未启用或没有配置的渠道默认保持停止，不需要迁移现有配置。
- 启用渠道、运行 Agent、浏览器、MCP 或本地模型时，内存仍会按实际工作增加。ARM64 空配置数字不是所有 VPS 的固定承诺。
