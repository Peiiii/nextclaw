# NextClaw v0.49.1

发布时间：2026-09-09

标签：Markdown、LaTeX、公式、聊天

NextClaw v0.49.1 为聊天消息加入 LaTeX 公式排版，并改善公式流式生成时的显示。

## 新功能

- 行内公式可以写成 `$E = mc^2$`；独立公式可以用单独成行的 `$$` 包围。
- 支持分数、根号、求和、积分、矩阵等 KaTeX 语法，较宽的独立公式可以横向滚动。

## 体验改进

- 独立公式尚未生成完整时会显示中性省略号，闭合后再排版，不会在生成过程中闪现红色解析错误。
- 行内代码、普通代码块、转义美元符号和 Skill 引用继续保持原有行为。

## 你需要做什么

正常升级即可。发送或生成 Markdown 时，使用 `$...$` 编写行内公式，使用单独成行的 `$$` 编写独立公式。
