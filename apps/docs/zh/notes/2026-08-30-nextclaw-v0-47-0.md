# 2026-08-30 · NextClaw v0.47.0

发布时间：2026-08-30
标签：`release` `apps` `wasm` `runtime`

NextClaw v0.47.0 把 Portable Service Apps 从“能运行 Rust/WASM Component”推进成一套可开发、可授权、可观测、可分发的应用运行平台。应用仍以单个 `.napp` 分发，默认自包含；需要额外能力时，由 NextClaw 在宿主侧明确授权和执行。

## 完整的应用能力

- **数据与文件**：应用可使用宿主管理的 KV、SQLite 和受控目录；目录授权支持只读/读写、撤权和路径越界阻断。
- **网络与 Secret**：HTTP 访问遵循域名白名单；Secret 只在调用时注入，不写入应用包、配置回显或日志。
- **长期工作**：支持可取消的后台 Job、进度事件、超时隔离、流式结果，以及 Panel 关闭后继续运行的 Resident Service 与事件重试。
- **AI 与 Agent**：应用可声明模型或 Agent 插槽，经用户绑定后从 Component 发起调用；未授权、取消和超时都有稳定错误语义。
- **组件组合**：Provider 能以版本化能力合同供其它应用调用；默认仍推荐自包含应用，外部依赖会在安装和启用前明确标识。

## 同一个应用，三个入口

Panel、Agent 和 `nextclaw app invoke` 现在调用同一个已安装实例、同一份数据和同一套权限。CLI 还提供依赖配置、Secret 绑定、验收状态与证据导出入口，AI 可以完成可代理的安装和配置步骤。

## 从创建到发布

Rust 开发者可以从模板创建应用，完成 doctor、build、check、test、dev、call、pack、install 和 enable 的完整链路。内置参考应用覆盖普通工具、HTTP + Secret、Provider 组合、Resident 事件和持久化场景，并保留完整源码与 smoke fixture。

## 可验证，而不是只宣称可用

本版本为运行、数据、文件、网络、Secret、任务、流、AI、组件组合、生命周期、资源边界、开发体验、分发和文档定义了 22 个稳定验收编号。产品、CLI 和发布流程消费同一个合同；证据绑定当前版本、平台和场景指纹，旧证据不会被误算为当前通过。
