# 2026-08-18 · NextClaw v0.39.0

发布时间：2026-08-18
标签：`release` `npm` `minor`

NextClaw v0.39.0 补齐了原生 App 的跨平台发布链路。开发者可以为同一个 App 版本提供一个或多个平台构建，用户安装时只会下载与当前系统匹配的文件。应用市场也会直接显示支持的操作系统，安装前就能判断是否可用。

## 功能

- **为同一 App 发布多个平台构建**：一个版本可以只支持一个平台，也可以同时提供 macOS、Linux 和 Windows 构建，不再需要拆成多个 App。
- **只安装当前平台需要的文件**：NextClaw 会识别系统、架构和 Linux ABI，选择精确匹配的 artifact，并在下载后校验完整性。
- **在应用市场查看平台支持**：App 卡片和详情页会显示支持的平台，通用 App 则继续显示为全部平台可用。

## 增强

- 开发者可以使用 `nextclaw app pack --target` 生成平台 artifact，再通过统一的校验和发布命令提交完整平台集合。
- 如果最新版本不支持当前设备，安装器会选择最新的兼容版本；显式选择不兼容版本时会在下载前给出错误。
- NextClaw 的静态界面资源采用长期缓存，重复访问和启动时可以减少不必要的资源传输。

## 修复

- “关闭思考”选项会在不同模型能力声明下保持稳定，不再被可用推理等级覆盖。
- OpenAI Responses 请求会使用正确的工具结构，减少函数工具在发送前发生格式不兼容的情况。
- 空闲的 NCP 流会更快建立，降低刚开始交互时的等待。

## 默认行为与兼容性

- 现有通用 App 无需修改，仍按全部平台可用的方式安装。
- 原生平台构建必须与 manifest 声明完全一致；缺少、多出或重复 artifact 都会在发布前被阻止。
- Linux 构建会区分 GNU 与 musl，避免只按 CPU 架构匹配却无法运行。
