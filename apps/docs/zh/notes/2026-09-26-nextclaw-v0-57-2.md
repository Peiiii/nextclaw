# NextClaw v0.57.2

通过局域网 IP 或普通 HTTP 地址访问 NextClaw 时，聊天消息现在可以正常发送。此前，浏览器可能在发送前报 `crypto.randomUUID is not a function`，导致消息未发到服务端。

修复覆盖发送按钮、快捷键发送和菜单预设消息。消息接收确认与幂等重试继续保留：同一次发送在重试时仍使用原消息身份，避免重复提交。

升级后刷新聊天页面即可使用，现有配置与会话无需迁移。本版本提供 NPM 和 Runtime 更新。
