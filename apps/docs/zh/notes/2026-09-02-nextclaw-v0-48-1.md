# NextClaw v0.48.1

发布时间：2026-09-02  
标签：Windows、桌面端、会话恢复

NextClaw v0.48.1 修复了 Windows 桌面端升级后的启动和会话恢复问题。如果你从 v0.44 左右或其他旧版本直接升级到 v0.48.0 后遇到会话列表加载失败、无法发送消息，或原有会话仍不可见，本次更新会恢复运行时启动，并从已有的本地历史中恢复会话列表和消息。

## 修复内容

- 修复旧版 Windows 桌面外壳应用 v0.48.0 更新后，运行时因兼容资源缺失而无法启动的问题。
- 恢复升级后缺失的会话列表条目和已有消息。
- 保留用户已经删除的会话，不会把它们重新显示出来。
- 新消息继续写入同一份本地历史，重启后仍可读取。

## 你需要做什么

升级到 v0.48.1 并重启桌面端即可。无需删除本地数据、重新安装或手工导入会话。
