# NextClaw v0.48.1

发布时间：2026-09-02  
标签：Windows、桌面端、会话恢复

NextClaw v0.48.1 修复了 Windows 桌面端升级后的会话恢复问题。如果你从 v0.47.0 或更早版本升级后，在 v0.48.0 中仍看不到原有会话，本次更新会在启动时从已有的本地历史中恢复会话列表和消息。

## 修复内容

- 恢复升级后缺失的会话列表条目和已有消息。
- 保留用户已经删除的会话，不会把它们重新显示出来。
- 新消息继续写入同一份本地历史，重启后仍可读取。

## 你需要做什么

升级到 v0.48.1 并重启桌面端即可。无需删除本地数据、重新安装或手工导入会话。
