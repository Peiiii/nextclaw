# 2026-07-28 · NextClaw v0.27.5

发布时间：2026-07-28
标签：`release` `npm` `patch`

NextClaw v0.27.5 是一次 NPM stable patch 更新。全新会话会记住每个 Agent Runtime 最近使用的模型；手动压缩上下文时会立即显示进度；实时连接恢复后也会补回遗漏消息。

## 增强

- 在全新会话中切换 Agent Runtime 时，会自动恢复用户最近为该 Runtime 选择的模型；不同 Runtime 的模型偏好互不覆盖。
- 手动压缩上下文后，当前会话会立即显示进行中反馈，并在完成或失败后正确清理。

## 修复

- 发送的消息会立即出现在当前会话中；实时连接中断并恢复后，会自动补回期间遗漏的内容。

## 默认行为与兼容性

- 已安装 `nextclaw@0.27.4` 的用户可以通过 stable 更新通道升级，也可以重新安装 `nextclaw@latest`。
- 本次更新不需要迁移配置、会话或文件。
- 本次 patch 不包含新的桌面安装包。
