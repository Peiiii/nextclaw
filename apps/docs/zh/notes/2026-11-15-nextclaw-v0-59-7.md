# NextClaw v0.59.7

本版修复会话保存保护中的可用性退化，并补全底层错误诊断。[Issue #73](https://github.com/Peiiii/nextclaw/issues/73) 原反馈机器的首次触发仍在调查，保持打开。

## 已保存正文后的摘要错误不再锁住会话

正文已经保存成功后，会话列表摘要或预览更新失败会单独记录，不再让整个会话永久拒绝新输入。冷启动扫描中，单个会话的读取错误也不会阻断其它正常会话。

## 存储恢复后继续发送，无需重启

真正无法保存时，当前运行仍会停止并明确报错。已接收但未执行的输入保留在当前进程中。修复磁盘空间、权限或文件访问问题后，在原会话继续发送即可：系统等待旧运行退出、核对历史并确认恢复写入，然后继续处理队列和新输入。

已开始执行的失败请求不会自动重跑。排队输入只保留到当前进程退出；本版不能找回从未保存的内容。请保留原会话文件。

## 诊断保留底层原因

日志保留原始错误链、系统错误码、操作路径、失败阶段和回滚结果。日志文件暂时不可写时，不再反向中断聊天；日志访问恢复后继续写入。

CLI 使用 `npm install -g nextclaw@latest` 升级。详情见[会话记录无法保存时](/zh/guide/chat#会话记录无法保存时)。
