# 2026-07-29 · NextClaw v0.27.7

发布时间：2026-07-29
桌面端提供时间：2026-07-31
标签：`release` `npm` `desktop` `patch`

NextClaw v0.27.7 已作为 NPM stable patch 和 NextClaw Desktop 0.0.236 提供。你现在可以从聊天输入框的 `@` 菜单引用已登记项目，让 Agent 获得项目名称、路径和目录概览，而不改变当前会话的工作目录。此次更新还增强了 Codex 长命令与会话恢复的连续性，并收紧了 Marketplace skill 的卸载边界。

## 功能

- 在聊天输入框输入 `@`，进入“项目”后可以选择已登记项目，并把它作为本次消息的显式上下文。
- 项目引用会携带项目名称、规范路径和受限目录概览；选择项目不会切换当前会话的工作目录。
- 只有仍在项目注册表中的目录可以被物化为项目上下文，失效或未登记路径会返回可观察状态。

## 修复

- Codex 长命令持续产生输出时会被视为活跃，不再因为缺少聊天文本更新而被误判为空闲超时。
- Codex 会话在真正超时后会保留原有 thread 身份；下一轮会恢复同一个 thread，而不会静默创建替代会话。
- Codex 会话默认使用完整本地执行权限和无审批策略，避免在审批交互尚不可用时继承只读配置并阻断文件或命令操作。
- 停止当前回复并开始执行某条排队消息时，该消息会立即从输入框队列移除，不再短暂重复显示。
- Marketplace 只能卸载 workspace skills 目录下由它管理的直属 skill，点目录、父目录和路径形式的越界目标会被拒绝。

## 默认行为与兼容性

- 已安装 `nextclaw@0.27.6` 的用户可以通过 stable 更新通道升级，也可以重新安装 `nextclaw@latest`。
- 本次更新不需要迁移配置、会话或文件。
- Codex 的完整本地执行权限是当前产品默认；请只在你信任的工作区和任务中运行 Agent。
- NextClaw Desktop 0.0.236 为 macOS、Windows 和 Linux 打包 runtime 0.27.7；桌面更新兼容性最低版本继续保持 launcher 0.0.141。
- Desktop 0.0.236 同时包含 runtime 0.27.6 引入的 Agent Runtime 上下文、富内容、Mermaid 全屏预览与排队消息改进。
