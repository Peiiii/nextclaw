# NextClaw v0.57.3

正常发送消息时，输入框内不再出现“正在确认消息是否已接收…”卡片。消息正文不会重复显示，输入区也不会被确认卡片撑高。

草稿保护和发送异常后的恢复能力继续保留。升级后发送一条消息，即可看到更稳定的输入区。

本次桌面更新搭载已发布的 Runtime 0.57.3，提供 macOS、Windows 和 Linux 安装包及更新通道。此前 v0.57.2 对普通 HTTP 地址下消息发送的修复也包含在内，详情见[上一版说明](./2026-09-26-nextclaw-v0-57-2)。现有配置与会话无需迁移。
