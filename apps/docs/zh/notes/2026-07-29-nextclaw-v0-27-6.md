# 2026-07-29 · NextClaw v0.27.6

发布时间：2026-07-29
标签：`release` `npm` `patch`

NextClaw v0.27.6 是一次 NPM stable patch 更新。Codex 与 Claude Code Agent Runtime 会在保留原生指令的同时，获得 NextClaw 产品说明、工作区上下文和 skill 信息；富内容更容易查看和复用；聊天中的排队消息也会等到真正开始执行后再进入会话记录。

## 功能

- Codex 与 Claude Code Agent Runtime 会保留各自原生系统指令，同时获得相关的 NextClaw 产品说明、工作区上下文和 skill 信息。
- Runtime 上下文注入默认开启，可以通过 `nextclaw agents runtime config` 按 runtime 查询或修改。

## 增强

- Panel App 与 HTML 内容可以在首次执行脚本时，通过只读的 `window.nextclaw.params` 获取结构化运行参数。
- 聊天中的 Mermaid 图表支持全屏查看，并可通过关闭按钮、点击遮罩或 Escape 键退出。
- 当比较、流程、层级或数值关系更适合视觉表达时，Agent 会更主动地选择紧凑表格或 Mermaid 图示；简单问题仍保持简洁回答。

## 修复

- AI 正在回复时追加的消息会继续留在待发队列，直到真正开始执行后才进入会话记录，不再在聊天中重复出现。

## 默认行为与兼容性

- 已安装 `nextclaw@0.27.5` 的用户可以通过 stable 更新通道升级，也可以重新安装 `nextclaw@latest`。
- 本次更新不需要迁移配置、会话或文件。
- 关闭或恢复 Agent Runtime 上下文注入后，需要重启受影响的服务才能让新设置生效。
- 本次 patch 不包含新的桌面安装包。
