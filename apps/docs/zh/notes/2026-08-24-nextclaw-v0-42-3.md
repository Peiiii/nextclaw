# 2026-08-24 · NextClaw v0.42.3

发布时间：2026-08-24
标签：`release` `npm` `desktop` `patch`

NextClaw v0.42.3 让长会话在摘要输出被截断时仍能继续，并补齐持续关注、会话历史可靠性和 Desktop 原生 SQLite 支持。

## 功能

- **持续关注**：Agent 可以绑定会持续刷新的 Context，订阅外部事件，并在会话时间线中接收可见事件卡片。订阅关系、读取位置和待投递事件会在重启后恢复。
- **无界面执行**：新增实验性的 `nextclaw exec` 命令与 Harness SDK，可从脚本启动 Agent、Session 和 Run。
- **复制会话 ID**：会话头部、列表、子会话列表和工作区 tab 的更多操作中都可以复制对应 ID。

## 增强

- **更小的固有上下文**：技能与工具目录减少重复内容，空会话更晚触发压缩。
- **运行中插话更清楚**：通过 Cmd/Ctrl+Enter 插入的消息会立即显示等待或排队状态。
- **Windows 外部链接**：Desktop 中的网页链接改由系统默认浏览器打开。

## 修复

- **上下文压缩不再因摘要截断卡死**：NextClaw 会先判断已生成的关键前缀是否可用，再有限缩小输入重试；仍无法得到合格摘要时，会保留近期原文作为确定性恢复出口。
- **会话历史更可靠**：会话目录迁移到 SQLite，并可从旧 journal、metadata 和 JSON 索引恢复；临时文件锁、历史 projection 和多 runtime 访问也有对应恢复路径。
- **Desktop 启动就绪判断**：正式安装包包含匹配 Electron 的 SQLite 原生模块，只有 NCP Agent 真正 ready 后才会报告启动成功。
- **Windows 宿主诊断**：Desktop 异常退出后会保留本地诊断和恢复记录，便于定位启动问题。

## 兼容性

本次为补丁更新。旧会话目录会在使用时自动迁移；原始会话 journal 保留不变。
