# NextClaw v0.59.3

本版整合长会话的压缩与加载改进，并修复 Windows 创建、导入会话时的 `EPERM`。0.59.2 的 Runtime 推广被 Windows 验证阻止；从上一版 Runtime 升级，会一起获得以下改进。

## 摘要失败时保留恢复路径

摘要为空、提前结束或超出预算时，不会被当作完整历史。现有上下文仍能容纳时延后压缩；必须缩减时，先保存恢复检查点并保留原始记录。

恢复期间，Agent 可以读取本会话历史并询问缺失的业务条件。明确确认这些条件前，其它工具暂停执行，减少执行结果不清楚时的重复操作。普通聊天或 Agent 自称恢复不会解除限制；渠道确认方式见[会话管理](/zh/guide/sessions)。

## 大历史按需加载

打开会话只读取有界页面。大消息显示预览，原文可以逐片读取；运行上下文和闲置会话缓存也有容量上限。

旧历史首次打开或索引需要重建时，会显示准备进度，可以停止并稍后重试。首次准备仍需扫描原始记录，大量细碎事件可能耗时较长；准备完成后的正常分页无需重新扫描全部历史。

## Windows 与升级

修复 Windows 上会话创建、快照导入及恢复时的文件系统同步适配。原始记录和恢复意图文件仍执行落盘，普通文件写入错误会明确返回。

```bash
npm install -g nextclaw@latest
```

本版通过 stable NPM 和 Runtime 更新通道交付，保留已有配置及原始会话记录。旧版不能直接继续写入使用新恢复语义的会话；回退需先由当前版本恢复成完整快照。本次不包含新的桌面安装包。
