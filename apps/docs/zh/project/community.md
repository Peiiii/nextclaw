# 社区

如果你想跟进项目、反馈问题、阅读长文或观察公开进展，这里是统一入口。

## 主要入口

- GitHub 仓库：[Peiiii/nextclaw](https://github.com/Peiiii/nextclaw)
- 报告 Bug：[Bug Report](https://github.com/Peiiii/nextclaw/issues/new?template=bug_report.yml)
- 提出功能或改进建议：[Idea / Feature Proposal](https://github.com/Peiiii/nextclaw/issues/new?template=feature_request.yml)
- 查看可认领任务：[help wanted](https://github.com/Peiiii/nextclaw/issues?q=is%3Aissue%20is%3Aopen%20label%3A%22help%20wanted%22)
- 贡献流程：[CONTRIBUTING.md](https://github.com/Peiiii/nextclaw/blob/master/CONTRIBUTING.md)
- 更新笔记：[产品更新笔记](/zh/notes/)
- 博客：[博客](/zh/blog/)
- 路线图：[路线图](/zh/project/roadmap)
- 公开项目脉搏：[Project Pulse](/zh/project/project-pulse)

建议和 Bug 统一通过 GitHub Issue 提交。Roadmap 是维护者规划，不是可直接认领的任务列表；只有带 `help wanted` 且经维护者明确确认或 assignment 的 Issue 才可以开始实现。

## 适合什么时候来这里

- 你想提 Issue 或跟进仓库动态
- 你想看最近有什么值得关注的更新
- 你想理解某个设计判断背后的原因
