# NextClaw 产品愿景

**NextClaw，你的长期个人智能搭档。**

NextClaw 以做好用户的长期搭档为根本使命，致力于成为一个主动参与、持续自我改进的长期智能伙伴。

这份愿景描述我们希望实现的产品形态，并不表示所有能力都已提供。版本范围和阶段安排请参阅 [路线图](/zh/project/roadmap)。

## 理解你在意的事情

我们希望 NextClaw 能持续理解你的目标、长中短期计划、偏好、处境和当前状态，把眼前的任务放回这些背景中理解。

你可以请它处理一项工作，也可以与它讨论一个尚未想清楚的问题，梳理计划、跟进进展，或在情况变化时一起调整安排。一次任务结束后，搭档的角色仍然持续。

这种理解需要能够更新，也需要允许你纠正。你始终决定自己的目标、节奏，以及希望它参与的范围。

## 在合适的时候主动参与

NextClaw 应当能够回应你的请求，也能依据已有背景和相关变化，判断何时值得主动询问、提醒、提出建议或在授权范围内采取行动。

例如，某项变化可能影响你正在推进的计划，它可以提出来与你讨论。没有需要你关注的事情时，保持安静也是合适的选择。

它也应能主动分析已有信息，发现目标与安排之间的冲突，整理几种选择的利弊，或者带着一个值得讨论的问题来找你。即使没有新的外部变化，新的有用认识也值得交流。帮你想清楚、提前规划或知道一件重要的事，都可以是完整的帮助，不要求每次都变成执行任务。

主动参与的价值在于是否对你有帮助。频繁发消息、扩大权限或收集更多数据，本身都不能证明它更会做搭档。

## 持续改进，更好地做好你的搭档

NextClaw 应当能够从经验、结果和你的反馈中发现不足，修正对你的理解，改善参与时机和工作方法，减少重复错误。

它可以主动发现改进机会，不必等你逐次指出问题。这种改进不要求你同时成长，也不服务于它自身的独立利益；目的始终是更好地做好你的搭档。

我们希望这些改进可观察、可纠正，必要时可回退，让你能够理解并掌控影响自己的变化。

## 能够实际帮上忙

长期搭档需要能够完成实际工作。NextClaw 将继续建设以下能力来支持这份职责。

### 统一入口与能力编排

让你通过自然语言和一致的操作方式，调用软件、连接服务、使用工具并完成多步工作，减少反复切换和解释背景的负担。

适合结构化操作的功能会尽量提供 `nextclaw` 命令行入口，让用户、开发者、脚本、CI 和 Agent 使用同一套产品能力；视觉操作仍可通过界面完成。

### 自感知与自治

让 NextClaw 了解自身能力、运行状态、连接情况、执行结果和失败原因，并在授权范围内完成必要的配置、扩展管理、诊断和恢复。

这些能力帮助它可靠工作，也让你能够了解它在做什么。是否应主动参与，还需要结合你的目标和处境判断。

### 扩展生态与数字资源

通过插件、技能和服务连接，按需要扩展搭档能做的事情；使用文件、本地系统、互联网与云资源，帮助你取得信息并交付结果。

稳定的协议、运行时和 SDK 支持这些能力的组合与复用。既有 NCP 基础设施继续为产品提供支撑。

### 容易开始，也容易长期使用

帮助你在首次使用时了解能交给搭档什么，提供必要背景并管理授权；减少长期使用中的配置和维护负担。

## 与个人操作层的关系

“AI 时代的个人操作层”仍是 NextClaw 的重要发展方向：连接软件、互联网、系统、服务与云计算，让搭档能够采取实际行动。

它是做好搭档的支撑形态。判断产品是否进步，最终要看 NextClaw 是否更理解你、更可靠、参与得更合适，能否更好地支持你在意的事情。
