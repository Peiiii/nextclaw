# NextClaw 路线图

NextClaw 的发展方向是成为主动参与、持续自我改进的长期智能伙伴，以做好用户的搭档为根本使命。详见 [产品愿景](/zh/project/vision)。

**1.0 的目标：交付一个懂用户、会主动帮忙、能持续自我改进的长期智能搭档。**

以下是通往 1.0 的四阶段功能规划，尚未完成整体验收，发布日期未定。表中的功能会复用现有记忆、定时任务、会话、技能和结果交付能力逐步建设，不表示全部需要从零开发，也不表示现在已经全部可用。已发布功能请查看 [更新笔记](/zh/project/release-notes)。

## 第一阶段：理解用户与目标

让搭档持续了解你的背景、目标和近况；换一个会话，仍能根据最新信息提供帮助。

| 规划功能 | 完成后你可以怎样使用 |
| --- | --- |
| 搭档身份与持续参与设置 | 决定它可以主动参与什么、使用哪些资料、执行哪些操作，并随时关闭主动参与 |
| 自动整理用户信息 | 在正常交流中逐步建立背景、偏好和近况，区分你确认的事实和仍需确认的理解 |
| 查看、纠正与管理记忆时效 | 查看它怎样理解你，纠正误解或要求停止使用某条信息；临时状态到期后重新确认 |
| 个人目标与分阶段计划 | 管理长期目标、阶段计划和近期行动，调整优先级与进展；目标可以独立于项目存在 |
| 跨会话与后台使用相关背景 | 新会话和后台分析都能使用最新、相关且在授权范围内的背景，并解释建议依据 |

## 第二阶段：主动分析、规划与交流

没有新的请求时，它也能在合适的时机分析已有信息，告知值得知道的变化，或主动找你讨论一个问题。

| 规划功能 | 完成后你可以怎样使用 |
| --- | --- |
| 自主识别关注事项与关注清单 | 从目标、近况和未决问题中建立持续关注，查看原因、最近结果和后续安排，也能暂停或结束 |
| 后台主动分析与规划 | 主动发现目标与安排的冲突、比较选择并提出建议；即使没有新的外部变化，也能带来有用的新认识 |
| 参与时机与节奏控制 | 设置安静时段、频率与预算；没有新价值时保持安静，避免重复提醒，并可暂停主动参与 |
| 主动发起话题并接续交流 | 直接接着聊、稍后再聊、忽略本次，或要求以后不主动提这个话题；尚未决定的事情可以继续讨论 |
| 建议转执行与结果跟进 | 在你采纳或已有授权允许时完成具体工作，交付产物，并更新相关计划、进展与关注事项 |

例如，它发现你每周安排的事情超过可用时间，整理两种调整方式后主动来聊优先级。帮你想清楚、提前规划或了解重要信息，本身就是帮助，不要求每次讨论都变成执行任务。

## 第三阶段：持续自我改进

让经验与反馈影响下一次协作，减少重复错误；这种自我改进始终服务于做好你的搭档。

| 规划功能 | 完成后你可以怎样使用 |
| --- | --- |
| 结果与反馈触发自动复盘 | 从执行失败、结果偏差和你的纠正中发现可改进的地方，无需每次额外要求复盘 |
| 经验分类与后续应用 | 分别修正用户理解、参与偏好或工作方法，在后续适用的情境中体现变化 |
| 改进记录与效果查看 | 查看改了什么、为什么改、何时应用、结果如何；没有效果证据时明确显示待验证 |
| 经验纠正、禁用与撤销 | 纠正错误经验、停用不合适的策略或撤销改动，同时保留你之后做的新修改 |

## 第四阶段：容易开始，能够长期使用

| 规划功能 | 完成后你可以怎样使用 |
| --- | --- |
| 搭档启用引导与能力状态 | 按引导提供必要背景、确认目标与参与范围；查看当前入口支持什么、后台是否运行及暂停原因 |
| 中断恢复与升级 | 重启、连接中断和升级后保留理解、计划、关注和改进状态；失败明确可见，恢复后不重复通知或执行 |

状态保存、停止与权限控制随每个阶段一起完成；第四阶段检验它们在持续使用中是否可靠。各运行方式和渠道的支持范围以实际验证结果为准，不承诺同时具备完整的 1.0 能力。

## 怎样判断达到 1.0

四阶段功能完成后，还需通过以下核心案例及连续试用。当前这些是验收要求，不是已通过的结果。

| 核心案例 | 要证明的结果 |
| --- | --- |
| 换会话、改计划后仍然懂你 | 能使用相关背景，纠正后使用新信息，不再依据已停止使用或过期的事实提供建议 |
| 没有新指令也能主动帮忙 | 既能自主分析已有信息并找你讨论，也能告知相关变化、按需执行；没有新价值时不打扰 |
| 从一次问题中改善后续表现 | 一次真实反馈或错误带来可检查的改进，在另一次相关情境中有效，并能撤销 |
| 中断后仍能可靠继续 | 停止、撤权、重启和升级后状态正确，没有假成功或重复执行 |

## 1.0 之后

根据实际使用反馈，逐步扩大数据来源、可执行服务、运行方式和设备覆盖，提升主动判断与改进质量。插件、技能、SDK 与生态建设继续支撑搭档能做的事情，具体顺序和日期另行更新。
