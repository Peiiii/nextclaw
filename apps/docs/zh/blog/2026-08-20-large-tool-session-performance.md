# 从 6.94 秒到最快 1.13 秒：NextClaw 重载大型会话提速约 6 倍

发布时间：2026-08-20

标签：`会话` `性能` `工具调用`

NextClaw v0.40.0 改进了大型工具会话的重载速度。

面对一份约 44.5MB、单条消息包含 500 次工具调用的压力会话，最新消息可见时间从约 **6.94 秒**降到 **1.13–1.73 秒**，最快提速约 **6 倍**。

## 当前结果

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 最新消息可见时间 | 约 6.94s | 1.13–1.73s |
| 首屏历史响应 | 12.96MB | 261.85KB |
| 首屏工具对象 | 约 1450 个 | 20 个摘要 |
| 历史请求 | 首字节约 2.16s | 并发场景约 219–281ms |
| 4.39MB 完整工具详情 | 阻塞首屏 | 展开后约 433ms 加载 |

首屏响应缩小约 **98%**。即使会话中积累了大量命令、文件操作和工具结果，用户也能先看到最新进度，再决定是否展开完整处理过程。

## 更快，但没有少数据

这次优化没有删除或截断工具记录。

NextClaw 会先展示工具调用次数、工具类型和最终回复。用户展开某条处理过程时，再加载这条消息的完整参数与结果；加载一次后，折叠再打开不会重复请求。

一条消息包含 500 次工具调用时，界面每批展示 40 项。用户仍然可以继续查看全部记录，但页面不需要一次渲染几百张复杂卡片。

## 重载会话不该越用越慢

Agent 用得越久，留下的工具调用、参数和执行结果就越多。这些记录是任务连续性的一部分，不应该成为重新打开会话的负担。

NextClaw v0.40.0 可以同时做到两件事：

- 先快速回到任务的最新进度；
- 需要核查时，仍能看到完整执行过程。

普通小会话继续一次加载完整内容，只有真正超大的工具历史才会按需读取，不会给日常会话增加额外步骤。

## 能力边界

这里的数字来自约 44.5MB、500 次工具调用的本地压力会话，不代表所有设备、磁盘和网络环境都会得到完全相同的耗时。会话规模、运行环境与并发请求仍会影响实际速度。

压力数据与生成工具会继续保留，用于监控首屏速度、响应体积和大型工具列表的浏览体验。
