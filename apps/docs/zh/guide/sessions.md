# 会话管理

大历史按页加载，不需要先读完整会话。历史索引需要重建时，会话显示准备进度；可以停止，稍后重试，原始记录会保留。大消息显示预览，可通过原文入口逐片读取完整内容。

上下文摘要失败或提前结束时，如果现有上下文仍能容纳，NextClaw 会延后压缩。必须缩减上下文时，会先保存恢复检查点并保留原始历史。恢复期间，Agent 可以读取本会话历史、询问缺失的业务条件；明确确认这些条件之前，不能执行其它工具。在渠道会话中，请针对待回答的澄清问题回复 `确认续做：` 加具体条件；普通聊天或 Agent 自称完成不会解除恢复限制。

会话用于保存一项任务的目标、消息、工具活动、工作目录和结果。完整说明已经合并到[任务与会话](/zh/guide/chat)。

原生运行时会在每次模型请求的上下文末尾临时附加当前 UTC 时间、宿主时区和 UTC 偏移，帮助 Agent 感知此刻。普通对话、工具执行后的继续调用和运行时重试都会刷新时间。这段信息不写入聊天记录或对话历史，也不改写前面的稳定上下文；宿主时区不一定是你所在的时区。

会话历史会保存在本地 journal 和 SQLite 会话目录中。升级时 NextClaw 会从已有 journal 和元数据重建会话列表；即使旧列表索引不完整，只要会话事实仍在，也会自动恢复，不需要手动导入。

会话较多时，侧栏会优先显示置顶会话，再按活动时间排列，并在接近列表底部时提前加载下一页；置顶、搜索、排序和总数由本地会话目录处理，因此更早的会话仍可继续浏览和搜索。

切换到“定时任务”视图可单独查看定时任务创建的会话。筛选在分页前执行，搜索和置顶仍有效；绑定已有普通会话的任务保留原会话分类。完整操作见[任务与会话](/zh/guide/chat)。
