# 会话工作区

## Markdown 折叠区块

聊天和 Markdown 文件预览支持 GitHub 风格的折叠区块，点击标题可平滑展开或收起。添加 `open` 属性可默认展开，也支持嵌套；标题显示纯文本，正文可包含列表、代码块和公式。正文前后保留空行：

```markdown
<details>
<summary>查看详细说明</summary>

这里放补充内容。

</details>
```

脚本、事件属性和不安全的 HTML 会被过滤。

## 文档属性

文档属性展开和收起时使用平滑过渡，并尊重系统的“减少动态效果”偏好。

Markdown 文件开头以 `---` 包围的 YAML front matter 会单独显示为紧凑的“文档属性”区，减少顶部留白和字段间距，可点击标题折叠或展开。属性不会混入正文目录；复杂字段保留 YAML 表达，无法解析时显示原始内容。切换到源码仍可查看完整文件。聊天中的完整 Markdown 文档也使用相同展示。

会话工作区把当前任务涉及的项目、文件和后续工作放在会话旁边。处理本地资料、代码项目或生成应用时，这里通常比聊天正文更接近最终结果。

## 项目文件

选择工作目录后，项目文件 Explorer 会和文件预览同时留在工作区。你可以连续打开不同文件，每个文件进入自己的标签页，不需要在“目录页”和“预览页”之间来回切换。

Explorer 的主要操作和常见代码编辑器保持一致：

- 顶部可以新建文件、新建文件夹、刷新和折叠目录。
- 在文件夹或目录空白处右键，可以新建、上传、粘贴或执行对应范围的文件操作。
- 文件和文件夹可以重命名、删除、复制路径；删除前会再次确认。
- Agent 生成的文件可以直接下载，也可以从操作菜单添加到当前聊天。
- 侧栏宽度可以拖动调整并自动记住；空间不足时才切换为覆盖式侧栏。

支持的预览包括 Markdown、代码、HTML、常见文档、表格和演示文稿。查看渲染后的 Markdown 文件时，可以用路径栏右侧的目录按钮浏览标题结构，并直接跳转到对应章节。HTML 可以在源码与渲染结果之间切换，代码修改可以查看差异。

## 打开的文件

打开的文件会保留在当前工作区，方便你在对话、源码和结果之间切换。再次打开同一个文件、在 Markdown 的源码与预览之间切换，或先查看另一个文件再返回时，阅读位置会保留。让 Agent 修改某个文件时，完成后直接重新打开并检查实际内容。窄屏时可以用预览顶部的 Explorer 按钮临时展开目录，选中新文件后继续留在预览上下文中。

要让 Agent 在当前消息中使用某个文件，可以从文件操作菜单选择“添加到聊天”。查看文本文件时，也可以先选中一段内容，只把相关片段加入消息。文件、目录和选中内容都会作为可见引用出现在输入框中；更多用法见[任务与会话](/zh/guide/chat#把文件和选中内容加入消息)。

## 子任务

复杂工作可以拆成子任务。例如一项调研可以分别收集来源、清洗数据和撰写摘要。子任务应有独立目标和交付物，主会话负责汇总与验收。

## 会话定时任务

与当前工作相关的定时任务可以在工作区中查看。周期运行前，先确认它使用的工作目录、指令和发送渠道没有过期。

## 使用建议

- 任务开始前确认目录，不要把整个用户主目录当成默认工作区。
- 批量修改前先要求列出计划和影响文件。
- 约定独立输出目录，保留源文件。
- 结果完成后检查实际文件，不只看聊天摘要。

## 视图布局与导航

### 移动端使用

手机底部导航可直接进入对话、收件箱、技能、Agent、设置和应用。在对话列表顶部打开视图菜单，可以切换项目视图或进入定时任务。从项目分组打开详情后，返回会回到进入前的对话页面；切换项目详情标签后仍保留返回位置。

输入栏较宽时显示当前模型和思考档位；在手机或较窄的会话面板中使用紧凑图标，点击可查看当前选项并切换。消息下方的复制、编辑和更多操作保持紧凑排列。手机文字输入区初始为一行，随内容自动增高，较长内容在输入区内滚动。设置按用途分组；较长的表单和详情弹窗可以在窗口内滚动。手机预览顶部使用紧凑标题栏，点标题可切换标签、前进后退及打开应用操作；隐藏视图后仍可从原入口继续查看。

手机收件箱详情使用单行顶栏，提供返回、标题、继续聊和最右侧的更多操作，正文占用剩余空间。桌面仍可在底部“继续聊”；标记已读或未读、归档和删除收在“更多”菜单中。

自动弹出的报告在手机上铺满屏幕。标题栏与底部操作栏保持紧凑，正文独立滚动；“稍后阅读、标记已读、收件箱、继续聊”均保留可见文字，不必猜测图标含义。

点击“继续聊”会回到推送报告的原会话，并在输入框中添加该报告的 @ 引用，保留已有草稿，不会自动发送。只有报告没有来源会话或原会话已删除时，才打开新对话。

模型与思考菜单、工作台标签和文件路径栏使用紧凑尺寸。消息处理结束后，汇总统一显示“已处理”和实际耗时；展开可查看具体工具结果或错误。

会话工作台和全局浏览区使用[同一套视图操作](/zh/guide/doc-browser#统一的视图操作)：可悬浮、收起、最大化，并保留标签与导航历史。“隐藏视图组”不再清空工作台，下次从原入口打开时继续查看。

文件标签菜单可选择“移动到全局右侧栏”，来源会话、工作目录和差异预览随文件一起保留，切换主会话不会改变相对路径的解析位置。子会话标签也可以移动到全局侧栏或单独悬浮；其他绑定当前会话的工具随整个工作台移动。
