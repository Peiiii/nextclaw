# 会话工作区

会话工作区把当前任务涉及的项目、文件和后续工作放在会话旁边。处理本地资料、代码项目或生成应用时，这里通常比聊天正文更接近最终结果。

## 项目文件

选择工作目录后，项目文件 Explorer 会和文件预览同时留在工作区。你可以连续打开不同文件，每个文件进入自己的标签页，不需要在“目录页”和“预览页”之间来回切换。

Explorer 的主要操作和常见代码编辑器保持一致：

- 顶部可以新建文件、新建文件夹、刷新和折叠目录。
- 在文件夹或目录空白处右键，可以新建、上传、粘贴或执行对应范围的文件操作。
- 文件和文件夹可以重命名、删除、复制路径；删除前会再次确认。
- Agent 生成的文件可以直接下载，也可以从操作菜单添加到当前聊天。
- 侧栏宽度可以拖动调整并自动记住；空间不足时才切换为覆盖式侧栏。

支持的预览包括 Markdown、代码、HTML、常见文档、表格和演示文稿。HTML 可以在源码与渲染结果之间切换，代码修改可以查看差异。

## 打开的文件

打开的文件会保留在当前工作区，方便你在对话、源码和结果之间切换。让 Agent 修改某个文件时，完成后直接重新打开并检查实际内容。窄屏时可以用预览顶部的 Explorer 按钮临时展开目录，选中新文件后继续留在预览上下文中。

要让 Agent 在当前消息中使用某个文件，可以从文件操作菜单选择“添加到聊天”。查看文本文件时，也可以先选中一段内容，只把相关片段加入消息。文件、目录和选中内容都会作为可见引用出现在输入框中；更多用法见[任务与会话](/zh/guide/chat#把文件和选中内容加入消息)。

## 子任务

复杂工作可以拆成子任务。例如一项调研可以分别收集来源、清洗数据和撰写摘要。子任务应有独立目标和交付物，主会话负责汇总与验收。

## 会话定时任务

与当前工作相关的定时任务可以在工作区中查看。周期运行前，先确认它使用的工作目录、指令和发送渠道没有过期。

## 使用建议

- 任务开始前确认目录，不要把整个用户主目录当成默认工作区。
- 批量修改前先要求列出计划和影响文件。
- 约定独立输出目录，保留源文件。
- 结果完成后检查实际文件，不只看聊天摘要。
