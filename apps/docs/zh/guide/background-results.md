# 后台结果与主动送达

你不需要一直停留在同一个会话里等待结果。NextClaw 会根据结果的用途，用轻量通知或收件箱把后台工作交还给你。

## 两种接收方式

### 会话完成通知

当另一个会话里的 AI 回复完成时，右上角会出现一条可点击通知。通知包含会话标题和清理过的纯文本摘要，不会直接暴露 Markdown 标记；点击后会回到对应会话。

![后台会话完成后，NextClaw 在右上角显示可点击的结果通知](/product-screenshots/nextclaw-background-session-notification-cn.png)

这种通知适合告诉你“刚才等待的回复已经完成”。当前正在查看的会话不会重复提醒，通知也不会成为长期记录。

### 收件箱主动送达

当定时任务、后台 Agent 或长期监测生成了一份值得保留的报告时，AI 可以把 Markdown 或静态 HTML 内容送到收件箱。即使你当时没有打开 NextClaw，内容也会保留，等下次进入界面时再呈现。

![后台 Agent 生成的每日 AI 与科技简报在收件箱阅读窗中展示](/product-screenshots/nextclaw-ai-delivery-html-cn.png)

收件箱适合周报、调研、推荐清单、监测结论和需要后续讨论的文档。你可以标记已读或未读、归档、删除，也可以从报告直接继续聊。

![在 NextClaw 收件箱集中查看和管理 AI 主动送达的报告](/product-screenshots/nextclaw-inbox-page-cn.png)

## 什么时候使用哪一种

| 你的情况 | NextClaw 的处理方式 |
| --- | --- |
| 切到其他会话，等待当前任务回复完成 | 弹出会话完成通知，点击返回原会话 |
| 定时生成一份日报、周报或调研结果 | 送到收件箱，长期保留并显示未读状态 |
| 后台监测发现值得关注的变化 | 送到收件箱，稍后查看或继续聊 |
| 结果只是当前会话中的普通回答 | 留在当前会话，不额外弹出通知 |

## 未读与弹窗规则

- 新送达内容会在界面可见时打开一个阅读窗；多项内容在同一个窗口中切换，不会叠出多个弹窗。
- 关闭阅读窗或选择“稍后阅读”不会标记已读，但同一项不会反复自动弹出。
- 主动打开、标记已读或继续聊时，内容才会进入已读状态。
- 收件箱有未读内容时默认显示“未读”；没有未读内容时默认显示“全部”，因此历史报告不会被空列表隐藏。

## HTML 报告的边界

收件箱支持自包含的静态 HTML 报告。内联样式可以正常展示，但脚本、表单、弹窗、远程资源和外部网络请求会被隔离。需要运行 JavaScript 或连接外部服务的交互页面，更适合使用可信文件预览或 Panel App。

## 从结果继续工作

点击“继续聊”后，NextClaw 会创建或复用一个关联会话，并把送达内容作为上下文提供给 AI。你可以直接追问结论、要求改写报告，或把建议拆成下一步任务，不需要重新粘贴全文。
