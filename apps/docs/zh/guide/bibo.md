# Bibo 托管个人搭档

关闭有未保存修改的文件标签时，可以选择「保存并关闭」「放弃修改」或「取消」。保存失败会保留标签和草稿，便于重试；保存过程中无法关闭标签。任务、日程、文件和项目删除使用确认弹窗，失败后可在弹窗中重试；删除项目会保留所属任务。

[Bibo](https://app.bibo.bot/) 是独立网页服务，底层使用 NextClaw Agent。你无需安装 NextClaw：用邮箱验证码注册，登录后从一件具体的事开始对话。

登录后默认进入概览，查看近期日程、进行中的任务、收件箱消息和最近笔记。对话是独立入口，支持创建、切换、重命名和删除多个会话；右侧工作区可与对话并排打开文件。Bibo 默认逐步显示回答；页面显示“正在保存”时请稍候，保存完成的回答才会进入会话记录。生成过程中可以停止；如果连接中断或保存失败，原输入会留在输入框供重试。长对话只滚动消息区，输入区保持可见。

收件箱收集 Bibo 送达的提醒、待决定事项以及 NextClaw Agent 送达内容，可标记已读、处理并跳转来源。日程默认显示月历，可切换日／周视图；每个日期显示安排摘要，选日期查看完整列表，支持新建、编辑与删除。任务支持项目、优先级、开始／截止时间、子任务，以及待开始／进行中／已完成／已取消四种状态；可按名称和描述搜索，切换列表与看板。笔记适合快速记录；文件模块提供可折叠目录树、多标签编辑以及移动和重命名。笔记与 Bibo 产物也保存在同一个文件空间中。手机可在文件目录或笔记列表与正文之间切换，桌面支持并排浏览。Bibo 可通过统一的结构化能力按需查找和操作这些内容，无需为每个动作常驻一个工具。

文件的搜索和新建位于左侧目录栏，正文顶部可切换编辑/预览和保存；点击「更多」移动、重命名或删除。发生版本冲突时草稿保留，可选择读取最新版本或用当前草稿覆盖，两者都会先确认；覆盖期间若再次出现远端修改，仍会阻止保存。手机从顶部返回目录或笔记列表。对话旁的工作区通过顶部文件选择器切换内容。日程详情在桌面月历旁展开，手机可返回完整月历；任务详情的字段独立滚动，保存操作保持可见。

每个账号有独立的运行环境。个人空间可在网页里清空。收件箱不代表已连接你的外部邮箱；外部邮箱和日历账号、网页搜索、后台定时任务及主动通知尚未作为托管服务提供。Bibo 当前的压缩空间快照上限为 32 MiB；达到限制时会明确告知保存失败。

当前每小时最多 12 次对话，每次最多 4000 字；每个账号每天最多 30 次模型调用，首发服务每天最多 200 次模型调用。账号使用 NextClaw 平台身份服务，模型调用由 Bibo 单独提供免费试用额度。Bibo 暂不提供离线定时执行或主动通知；请核对重要结果。

使用和数据说明见 [Bibo 帮助页](https://app.bibo.bot/help.html)。本地优先工作台仍可按[安装指南](/zh/guide/install)使用 NextClaw。

点击「新对话」会先打开空白页，不会在列表中新增空会话；发送第一条消息时才创建会话。会话右侧的更多菜单提供重命名与删除。左下角账号菜单集中提供介绍、帮助、退出和清空操作；桌面侧栏的收起/展开按钮位于顶部。新建文件、笔记和项目，以及文件改名/移动，使用命名弹窗；操作失败会保留输入并在弹窗内提示。手机导航使用侧边抽屉。
