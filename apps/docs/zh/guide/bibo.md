# Bibo 托管个人搭档

长会话的上下文预算与自动压缩由底层 NextClaw 管理。Bibo 不再用 128 KiB 的请求大小提前截断正常会话；生成失败会区分模型请求过大、用量限制、上下文整理失败或超时。未保存的本轮不会显示为保存成功。向维护者反馈时提供会话链接和大致发生时间即可，维护者可通过服务端历史日志排查，无需依赖浏览器现场。

官网、应用和帮助页在浏览器标签页使用同款紫色 Bibo 图标，便于在多个网页之间找到 Bibo。

首次打开应用时，登录注册入口会展示 Bibo 的紫色搭档形象。桌面端可在同一面板中看到形象与账号表单；手机端先输入邮箱，点「继续」后再填写验证码和密码。已有账号先切换到「登录」，点「继续」后输入密码，即可回到原来的对话和个人空间。验证码发送成功或失败会在表单内分别提示；需要更换邮箱时可返回修改，已输入的邮箱会保留。

概览顶部欢迎语旁展示官网的紫色大眼睛搭档和「日常，多一个我。」。形象仅作展示，不可点击，也不随摘要操作产生反馈。下方事项摘要为独立入口，可前往收件箱、任务或开始对话；手机上形象会缩小，保留内容和操作空间。

工作台的表单、菜单和提示采用统一的文字层级，输入框在手机上保持可读字号。任务、项目、日程、文件及收件箱操作成功后，直接显示更新后的内容，不重复弹出成功提示。错误保留在相关输入、编辑器或弹窗内，便于修正或重试，不会自动消失。

文件编辑器原位显示「未保存／保存中／已保存」；保存期间继续输入的新内容仍会标记为未保存。完成任务后保留撤销入口，复制在按钮原位反馈。完整任务表单保存到当前筛选之外时，会提示已保存并提供查看入口；日程保存后显示对应日期。

各模块使用独立地址：`/chat`、`/tasks`、`/calendar`、`/notes`、`/files`、`/inbox`，概览位于 `/`；已有对话可通过 `/chat/会话ID` 直接打开。刷新、前进和后退保留当前位置。

打开已有对话后可以直接发送消息。页面读取个人空间时不会把它误判成正在处理上一条消息；如果上一条回答确实仍在生成，则需等它结束或停止后再发送。

新任务默认只需填写名称，其他属性通过「添加详情」展开；列表左侧可直接完成或重新打开任务，并可撤销刚才的状态修改。任务超出可见区域时可滚动列表；悬停或聚焦任务行显示更多操作，触控设备常显，可从中删除任务并确认。圆圈、半月、勾选和横线分别表示待开始、进行中、已完成和已取消。「全部」普通列表将完成和取消任务收进可展开的「已结束」区域；搜索结果和「已完成」范围直接展示匹配任务，加载更多入口保持可见。列表在标题下方补充进行中／取消状态，看板不重复列标题已有的状态。辅助信息保留项目、高优先级、截止时间和子任务进度，不重复显示低优先级；详情仍可查看和修改全部属性。「今天」显示今天截止及已逾期的未完成任务，「接下来」显示明天起截止的未完成任务；没有截止日期的任务在「全部」中查看。搜索、项目管理及列表／看板切换位于「筛选与视图」。

完整任务详情与日程编辑在弹窗中进行；日历空白日期双击即可新增。关闭编辑窗保留草稿，明确点击「取消」放弃草稿；保存失败会在窗口内显示错误。文件目录树收起后，正文使用完整宽度；编辑区顶部的目录图标可重新展开目录。

手机月历同时显示完整月份和选中当天的安排，日期下方的数字表示安排数量。笔记支持名称搜索；文件和笔记编辑器支持 Cmd/Ctrl+S 保存。收件箱默认显示待处理条目，可切换未读或全部。

收件箱列表采用两行布局：第一行显示标题，右侧的圆点表示未读，对勾表示已处理，已读但未处理的条目不显示标记；第二行显示正文预览和靠右的简短时间。当天显示“刚刚”“几分钟前”或“几小时前”，随后显示“昨天”、最近一周的星期或更早的日期，跨年时包含年份。时间每分钟更新。长标题和预览以省略号收尾，打开消息可读全文。没有可预览的正文时省略预览，不重复显示与标题相同的开头标题。

桌面收件箱采用紧凑消息列表与居中的正文阅读区，列表分别显示标题、摘要、状态和日期。标记已读、处理和查看来源位于详情顶部，阅读长文时保持可见。手机可从顶部返回消息列表。正文开头与消息标题完全相同的一级或二级标题仅在阅读时去重，保存的原文不变。

手机打开或关闭导航抽屉时不会自动弹出图标提示；键盘可用 Tab 进入抽屉、按 Escape 关闭，并回到打开菜单的按钮。

模块与会话支持浏览器前进、后退和直接打开链接。切换模块再返回对话会保留当前会话与未发送草稿；后退到新对话会恢复空白编辑器。会话链接也可在新标签页打开。未发送草稿不保证刷新后保留。

打开已删除或不存在的对话链接时，会明确提示失效，不会跳转到另一段对话。可从会话列表选择其他对话，或点击「新对话」继续。

右侧工作区记住打开状态和所选文件；刷新后重新读取已保存正文。关闭再打开保留当前未保存的编辑，刷新前仍需保存。读取失败会显示错误并提供重试，晚到的读取结果不会重新打开你已关闭的工作区。

可以在对话中说“创建一份报告，并在右侧预览”。Bibo 保存文件并发出展示请求后，工作区会自动打开该文件；Markdown 和 HTML 可直接预览，也可切换源码编辑。展示已有文件同样可用。只展示当前账号个人空间中已保存的文件；停止生成或保存失败不会自动打开本轮产物。手机也支持自动打开、关闭和重新查看。

长会话标题在顶部单行省略，保留新对话和工作区操作；会话菜单的重命名窗口可查看完整标题。任务、收件箱及笔记列表中的长名称最多显示两行，打开详情或编辑器可查看完整内容。

关闭有未保存修改的文件标签时，可以选择「保存并关闭」「放弃修改」或「取消」。保存失败会保留标签和草稿，便于重试；保存过程中无法关闭标签。任务、日程、文件和项目删除使用确认弹窗，失败后可在弹窗中重试；删除项目会保留所属任务。

[Bibo](https://app.bibo.bot/) 是独立网页服务，底层使用 NextClaw Agent。你无需安装 NextClaw：用邮箱验证码注册，登录后从一件具体的事开始对话。

登录后默认进入概览，查看近期日程、进行中的任务、收件箱消息和最近笔记。顶部简报会按当前事项进入收件箱、任务或对话；各卡片中的真实条目可直达对应内容。对话是独立入口，支持创建、切换、重命名和删除多个会话；右侧工作区可与对话并排打开文件。Bibo 默认逐步显示回答；页面显示“正在保存”时请稍候，保存完成的回答才会进入会话记录。生成过程中可以停止；如果连接中断或保存失败，原输入会留在输入框供重试。长对话只滚动消息区，输入区保持可见。

手机点击左上角菜单，可在紧凑导航抽屉中切换各模块、打开最近对话或进入账号菜单；最近对话较多时可单独滚动列表。对话输入区只保留操作与即时状态，配额、错误和冲突信息会在需要处理时显示。

向上阅读历史消息时，消息区底部显示圆形向下箭头；点击可回到最新消息，按钮随之收起。

输入框右下角在发送箭头、停止方块和等待状态之间切换。回复期间可准备下一条草稿，但不会并发发送；停止请求处理中不能重复停止，保存阶段不可取消。输入框会随多行内容增高，到上限后内部滚动。失败时原消息会恢复到空输入框；已有新草稿时保留它，并提供「重试消息」，重试也不会清空新草稿。未发送草稿不保证刷新后保留。

收件箱收集 Bibo 送达的提醒、待决定事项以及 NextClaw Agent 送达内容，可标记已读、处理并跳转来源。来源已删除或无法访问时，消息详情会保留并明确提示，可稍后重试。日程默认显示月历，可切换日／周视图；每个日期显示安排摘要，点击日期格的空白处也能选中当天并查看完整列表，支持新建、编辑与删除。选中日期的日程卡片将开始与结束时间显示为连续时段，说明最多显示两行；点击卡片可查看完整内容。任务支持项目、优先级、开始／截止时间、子任务，以及待开始／进行中／已完成／已取消四种状态；列表和看板直接显示项目及状态，可按名称和描述搜索。任务和收件箱超过一页时，可在各自列表底部继续加载。笔记适合快速记录；文件模块提供可折叠目录树、多标签编辑以及移动和重命名。笔记与 Bibo 产物也保存在同一个文件空间中。手机可在文件目录或笔记列表与正文之间切换，桌面支持并排浏览。Bibo 可通过统一的结构化能力按需查找和操作这些内容，无需为每个动作常驻一个工具。

文件的搜索和新建位于左侧目录栏，目录树和打开的标签用一致的图标区分文件夹、笔记、AI 产物及常见文档类型；正文顶部可切换编辑/预览和保存；点击「更多」移动、重命名或删除。笔记列表按最近编辑排序，文件目录仍按路径展示；内容较多时可在各自列表内加载更多。发生版本冲突时草稿保留，可选择读取最新版本或用当前草稿覆盖，两者都会先确认；覆盖期间若再次出现远端修改，仍会阻止保存。手机从顶部返回目录或笔记列表。对话旁的工作区通过顶部文件选择器切换内容。日程详情在桌面月历旁展开，手机可返回完整月历；任务详情的字段独立滚动，保存操作保持可见。

文件目录支持方向键浏览：上下移动，右方向键展开或进入子目录，左方向键收起或返回父目录；Home／End 到首尾节点，Enter 打开文件。目录宽度可拖动调整，聚焦分隔线后也可用左右方向键调整。打开多份文件时，当前标签会自动滚入可见区域；切换标签和收起目录不会丢失未保存的内容。

Markdown 文件和笔记默认以「预览」打开。选择「编辑」后可直接在排版正文中写作，修改标题、列表、待办和表格单元格；「更多格式」提供插入链接、HTTPS 图片、表格、公式和代码块，以及表格增删行列。代码块支持语言选择与语法高亮，公式可点击修改，Mermaid 代码下方显示图表预览。工具栏支持撤销、重做和查找替换，也可使用 Cmd/Ctrl+B、I、F 和 S。手机将撤销和重做收在「更多格式」中。

需要精确修改 Markdown 时，从文件操作菜单选择「源码」，可查看完整文本和语法高亮。仅切换模式不会改写文件；正文编辑后，Markdown 的空白、列表标记或链接写法可能规范化。文档属性、HTML 原文和脚注保留为原文结构，可在源码中精确调整。保存格式仍是 Markdown。

编辑与预览切换保留本文件的选区和撤销历史。底部明确显示未保存、保存中、已保存或失败；保存失败可重试，版本冲突会保留草稿并要求明确选择。未保存的文件草稿按账号备份在当前浏览器标签页，刷新后可恢复；关闭标签页会结束这份临时备份，请先保存。若浏览器无法备份，会显示提示，不能把草稿备份视为已经保存到服务器。

任务列表顶部可直接输入名称并按 Enter 连续添加；点击旁边的更多图标，用同一份草稿补充说明、子任务及项目、日期等属性。在今天或接下来范围新建时默认归入相应日期。月历可双击日期格空白处新建当天日程，日／周视图可点击半小时时段。改开始时间时结束时间保留原时长，也可快捷选择 30／60／90 分钟；结束时间早于开始时会提示并阻止保存。

待办页保存成功后会立即更新列表，输入框可继续添加；保存失败保留草稿供重试。刷新或运行环境重启后，已保存的待办仍会保留。已有空间首次升级时可能需要一次装载等待；通过对话创建待办仍需要等待 Bibo 理解和执行。

展开空文件夹时，目录中会显示「文件夹为空」，可直接从该文件夹的操作按钮新建内容。

文件或笔记列表读取失败时，会显示错误和重试操作，不会把失败显示成空目录。搜索失败会保留关键词，可在目录内重试搜索。

概览、收件箱、任务和日程读取失败时也会显示错误和重试操作，不会把失败显示成空数据。日程保留月份切换，当前月份无法读取时可重试或切换月份。

对话双方的消息、文件预览和收件箱正文使用与 NextClaw 共用的 Markdown 阅读组件，并采用一致的正文、标题比例和区块间距，支持六级标题、圆点列表、有序编号、嵌套列表、任务复选框、表格与脚注。收件箱列表预览提取可读摘要；表格长文本自动换行，宽表格和代码可以在正文内横向滚动。代码块显示语言和语法高亮，可单独复制。

公式支持 `$…$`、`$$…$$`、`\(…\)` 和 `\[…\]`。标记为 `mermaid` 的代码块显示图表，可展开、缩放、按 Escape 关闭，并切换查看源码；生成中不完整的公式和图表会等待后续内容，最终无效图表显示提示并保留源码。图片只加载 HTTPS 地址，可展开预览，加载失败显示替代文字；外部图片由浏览器从来源网址加载。危险协议和远端文件 URI 不会跳转。

可让 Bibo 生成并保存文档、HTML／SVG 或 Markdown 图表产物。对话双方消息、收件箱正文和文件预览中的系统文件链接、个人空间相对或绝对路径链接，以及本地 `file:` URI，均可打开相应的文件视图。例如 `[搭档启动卡.md](/data/workspace/搭档启动卡.md)` 会显示为文件链接；只有属于当前账号且已保存到个人空间的文件才会打开，否则工作区会提示错误。产物默认预览，也可切换编辑并保存，文件模块看到的是同一份内容。改名或移动文件不会破坏基于文件 ID 的引用；路径链接则应使用文件的新路径。未保存的编辑在工作区关闭后仍保留到本次页面会话结束。手机关闭工作区即可回到对话。文件链接也可在独立网页打开及刷新，已删除或无法访问的引用会提示错误。HTML／SVG 预览禁止运行脚本；普通网站链接在浏览器新标签打开，不会嵌入右侧工作区。

回答和代码块的复制操作使用图标按钮，成功后短暂变成勾；复制失败时在按钮旁提示，可重试。桌面悬停可查看操作名称，手机保留更大的点击区域。全局完成提示位于顶部居中，可关闭；读取状态和表单错误显示在对应内容区域。

概览中的消息、笔记、日程和任务摘要使用统一的圆角入口；悬停时整行轻微反馈，标题和状态的位置保持稳定。点击摘要可进入对应模块，长标题不会挤掉状态或时间。

每个账号有独立的运行环境。个人空间可在网页里清空。收件箱不代表已连接你的外部邮箱；外部邮箱和日历账号、后台定时任务及主动通知尚未作为托管服务提供。Bibo 当前的结构化空间数据和压缩空间快照上限分别为 32 MiB；达到限制时会明确告知保存失败。

Bibo 支持 Exa 网络搜索。直接说“搜索 Cloudflare AI Search 的最新官方说明，并附来源链接”即可；无需自行配置密钥。Bibo 使用搜索返回的相关片段回答并引用来源，请打开链接核对重要信息。搜索词会发送给 Exa，完整会话不会交给搜索服务。

每个账号每 UTC 日最多 100 次搜索，全站每日最多 1000 次、每 UTC 月最多 10000 次，每次最多返回 10 个结果。一次问题可能需要多次搜索，失败请求也计入额度。搜索任务通常在搜索前、结果返回后各调用一次模型，均计入模型额度。额度用完或搜索不可用时，Bibo 会说明情况。

当前每小时最多 100 次对话，每次最多 4000 字；每个账号每天最多 250 次模型调用，首发服务每天最多 2000 次模型调用。账号使用 NextClaw 平台身份服务，模型调用由 Bibo 单独提供免费试用额度。额度已满时会在发送前提示，新对话不会因此产生空白会话，输入保留供之后重试。Bibo 暂不提供离线定时执行或主动通知；请核对重要结果。

使用和数据说明见 [Bibo 帮助页](https://app.bibo.bot/help.html)。本地优先工作台仍可按[安装指南](/zh/guide/install)使用 NextClaw。

点击「新对话」会先打开空白页，不会在列表中新增空会话；发送第一条消息时才创建会话。会话右侧的更多菜单提供重命名与删除。左下角账号菜单集中提供介绍、帮助、退出和清空操作；桌面侧栏的收起/展开按钮位于顶部。新建文件、笔记和项目，以及文件改名/移动，使用命名弹窗；操作失败会保留输入并在弹窗内提示。手机导航使用侧边抽屉。
