# 任务与会话

在 NextClaw 里，会话不是单纯的聊天记录，而是一项任务持续工作的容器。目标、消息、工具活动、工作目录、文件结果和后续修改都在这里延续。

## 新任务和继续任务

手机聊天界面隐藏你的消息头像，为消息内容留出更多空间；桌面端仍显示头像。

以下情况适合新建任务：

- 开始处理另一个项目或工作目录；
- 新目标与当前材料没有关系；
- 需要改用不同 Agent 或运行时；
- 希望把实验过程与长期工作隔开。

以下情况适合继续原会话：

- 修改刚生成的文件、图表或页面；
- 继续追问同一批资料；
- 根据当前结果增加下一步；
- 需要保留前面已经确认的口径和约束。

## 语音输入

第一次录音时会说明麦克风用途，请在浏览器弹出的权限提示中选择允许。若被拒绝，录音浮层会列出网站权限入口和当前系统的设置路径。修改权限后点击“检测麦克风并重试”；检查会立即释放临时采集的麦克风，再开始语音识别。无麦克风或设备无法读取时会显示对应提示。若系统要求重启，请先保留草稿再重开应用。

启动、录音和收尾使用同一紧凑横条，依次显示“准备录音”“正在聆听”“完成转写”；状态切换不改变横条尺寸，不会先弹出大面板。悬停启动状态文字可查看麦克风用途；只有出错需要操作指引时才展开说明。

首次使用和重试都会先检查麦克风。等待你操作授权弹窗时不会因弹窗失焦或语音服务连接计时而中断；切走页面或点击“保存并退出”仍会终止本次请求，之后再允许也不会自动开始录音。

浏览器有时无法区分网站拒绝与系统拒绝，因此权限提示会引导你检查两处。语音服务本身被禁用时会单独提示。

点击输入框旁的麦克风开始录音，按 Esc 或点击“保存并退出”结束。文字实时出现在开始录音时的光标或选区位置，下划线表示尚未确定、可能修正的片段；转写完成后下划线消失，消息不会自动发送。浮层显示录音状态和时长；Esc 快捷键仅在保存按钮的悬浮提示中说明，不提供撤销本次输入的叉号。保存退出时会等待句尾转写；若收尾失败，仍保留已经显示的文字。其余文字、引用和附件保持完整。每次最多录音 60 秒。

录音时开始打字、粘贴或移动输入框中的光标，会结束语音并保留当前可见文字，让你继续编辑；后续识别结果不会再覆盖它。录音时按 Enter 只结束语音，之后才能发送；按 Esc 保存并退出本次语音。

桌面宽屏可在设置 → 快捷键中的“语音输入”区域配置按住说话、松开结束，也可以修改或停用绑定。录音浮层最右侧的齿轮提供同一设置入口；录音中打开设置会先结束转写，关闭后不会自动重录。单字母键和 F6–F10 仅在输入框外触发；Ctrl 或 ⌘ 与 Alt/⌥ 组成的组合键也可在输入框内使用。常用编辑快捷键不会被覆盖，输入法组词时不触发。手机使用麦克风按钮，不显示快捷键绑定；系统占用的按键可能无法使用。

切换会话会取消录音，窗口失焦或切到后台也会停止采集。权限、网络或设备异常会在输入区说明原因；已确认的文字保留在草稿中，未确定的片段撤回。浏览器语音服务可能联网处理声音，不保证离线识别；浏览器、系统和服务可用性会影响支持情况。

## 会话类型

NextClaw 可以承载 Native、Codex、Claude Code、微信、飞书和定时任务等不同运行入口。它们的工具和交互方式可能不同，但都应围绕清楚的目标、工作目录和可检查结果使用。

## 会话列表

会话列表用于返回最近任务。名称应能说明正在做什么，避免长期保留大量“你好”“测试”之类无法辨认的会话。一个项目有多项工作时，可以按结果命名，例如“七月销售分析”“官网文案校对”“发版检查”。

在桌面端把指针停在会话上，可以查看它所属的项目、子会话数量和定时任务数量；停在项目上，可以查看项目路径、会话数量和关联的定时任务数量。项目行默认只保留名称，展开图标和操作会在停留时出现。

在会话工作区中，运行中的子会话会显示转圈状态。子会话管理页会标出具体正在运行的会话；概览和顶部“子会话”标签也会在任一子会话运行时显示相同提示，因此无需逐个打开确认。

## 复制会话 ID

在当前会话头部、会话列表中的会话项、会话工作区的子会话列表或顶部子会话 tab 中，打开“更多操作”，选择“复制会话 ID”，即可复制对应会话的完整 ID。草稿会话还没有稳定 ID，因此不会显示这项操作。

## 查看处理过程

回复中的思考和工具过程可折叠为“已处理”。运行记录包含开始与结束时间时，这里会显示处理耗时，刷新后仍可查看；没有时间记录的旧消息不会显示估算时长。

同一回复中的多轮工具调用会保留在这条回复里。刷新或重新打开会话不会重新执行工具；已经完成的回复不会因为读取历史而多出一条正在调用工具的消息。

“正在思考”跟随当前任务的运行状态。单条回复出现后，任务可能仍在继续执行；收到任务结束状态后，聊天页会结束生成提示。

## 把文件和选中内容加入消息

输入 `@` 可以引用当前项目中的文件、目录、项目或 Panel App。你也可以在会话工作区中打开文件，通过操作菜单选择“添加到聊天”；查看文本文件时，还可以选中一段内容后只把这段内容加入消息。

引用会显示在输入框中，并随当前消息一起发送。这样可以明确告诉 Agent 这次要读取哪些材料，同时保留返回源文件继续查看的入口。引用目录时，NextClaw 会把它作为本次任务的查找范围，不会把整个目录一次性塞进消息。

## 编辑后重新运行

如果刚才的问题写错了，或者遗漏了文件和约束，可以在最近一条可编辑的用户消息上选择“编辑消息”。修改内容并发送后，NextClaw 会从这条消息重新执行，而不是把修改内容追加成一条新的追问。

编辑重跑适合纠正当前分支；如果只是要基于现有结果增加下一步，直接发送新消息即可。

## 中断后继续运行

任务被手动停止、运行时中断或执行失败后，可恢复的助手回复会显示“继续运行”。点击后，NextClaw 会在原任务和原回复位置继续，不需要复制上一条要求，也不会额外创建一条无关回复。

“继续运行”只会出现在已经取消或失败、且当前运行时支持恢复的任务上。任务仍在运行时不会出现这个操作。

## 在 AI 运行时继续发消息

AI 正在回复时，直接发送的新消息会先排队，并在当前任务完成后继续处理。排队消息会显示在输入框上方，你可以编辑、删除，或选择立即插入当前任务。

在 macOS 上按 `Command + Enter`，或在 Windows / Linux 上按 `Ctrl + Enter`，可以直接把输入插入当前任务的下一个安全步骤。无论直接使用快捷键，还是先排队再选择插入，消息都会以同一种待处理气泡显示，并保留原有正文、附件和引用。当前正在生成的内容不会被截断；消息完成后也可以从“更多操作”查看运行来源。

## 查看运行来源

消息的“更多操作”中可以查看本次运行的触发信息，包括发起方、入口、来源会话与消息、来源模型、本次运行模型、工具调用、目标运行 ID，以及渠道、定时任务或观察任务保留的来源标识。助手消息还会同时显示 Token 用量和完成状态，便于从一次触发继续核对后续结果。

## 查看会话 Token 用量

打开会话工作台后，可以查看当前会话已记录的 Agent 轮次、模型调用次数、已报告用量的调用次数，以及输入、输出、缓存输入和总 Token。按模型的明细会显示该模型参与的轮次和调用次数，方便判断一次任务是在少量长调用中完成，还是经过了多次工具循环。

缓存读取占比只计算输入 Token：缓存读取 Token 除以全部输入 Token。输出 Token 单独显示，不会计入这个比例；只有模型返回缓存用量时才会显示。

只有用户直接发起的后台回复会显示全局完成提醒。Agent 自主委派、定时任务、观察任务和其它自动运行会保留在对应会话中，但不会额外弹出完成提醒。

## 长任务与上下文压缩

Native Agent 会在长任务接近上下文边界时自动压缩较早内容，并在同一次任务中继续执行。消息流会显示正在压缩和压缩完成的状态；压缩后的上下文会保留摘要与最近的用户原文，避免模型在恢复后抓不住当前目标。

输入框旁的上下文窗口指示器会把系统与工具、会话内容、输出预留和自动压缩线分开显示。这里的百分比表示完整模型输入的预计占用，不只是聊天消息长度。

你也可以通过 `/compact` 主动整理较早上下文。无论自动还是手动压缩，关键路径、最终口径、不可修改范围和交付标准仍建议写在当前任务中，避免重要约束只存在于很早的一条消息里。

## 数学公式

聊天消息与会话工作台中的 Markdown 文件预览都支持 `$...$`、`$$...$$`，以及行内 `\(...\)` 和独立公式 `\[...\]`。例如 `\(E = mc^2\)`；独立公式可以写为：

```text
\[
\frac{1}{2}
\]
```

聊天消息支持 LaTeX 数学公式。行内公式使用 `$E = mc^2$`；独立公式将 `$$` 放在公式前后的单独一行：

```text
$$
\frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$
```

支持分数、根号、求和、积分和矩阵等 KaTeX 语法。较宽的独立公式可以横向滚动。生成中的 `$$` 独立公式先显示省略号，闭合后再排版；反斜杠定界符和行内公式闭合前保留普通文本。临时解析错误不会飘红，闭合后仍无效的公式在输出结束时显示错误标记。行内代码和普通代码块中的公式保持原文；若要显示美元符号，请写作 `\$`。

## 会话内可以继续扩展

- 打开[会话工作区](/zh/guide/workspace)查看项目与文件。
- 创建子任务，让不同 Agent 分别处理部分工作。
- 为当前会话安排定时任务。
- 引用 Panel App 或 Skill 继续工作。

第一次使用请从[创建第一个任务](/zh/guide/create-task)开始。
