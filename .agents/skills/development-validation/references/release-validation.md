# 发布与不可逆变更验证

仅在生产发布、迁移、凭证、更新渠道或其它不可逆变更时读取。

## 发布闭环

- 仅在后端/数据库变化需要时执行 migration。
- 对受影响的关键 API 或 UI 路径做线上 smoke。
- NPM 发布列出精确包和受影响的直接依赖包。
- 同一不可变产物应贯穿构建、部署和验证，并能读取 release identifier。
- 跳过项只说明与当前发布有关的关键缺口，不输出完整仪式清单。

## 无人值守部署

只有同时满足以下条件才能称为自动部署：

- 仓库 CI 是部署 owner，可在干净、非交互 runner 运行；
- 认证不读取 stdin、不依赖 TTY、密码提示或个人机器登录态；
- 优先使用短期、最小权限身份；否则使用有轮换 owner 的窄权限环境 secret；
- 凭证预检发生在远程 mutation 前，失败可观察；
- 验证路径纯读且可重试；
- 回滚使用已验证旧产物，不临时重建旧源码。

需要个人 CLI 登录或密码输入的路径必须标记为人工发布，不能包装成自动化。Cloudflare Pages 优先使用仓库 workflow 与环境级 token；本地 wrangler 只作为明确披露的人工应急路径。
