# 自适应方案思考

本参考只解决一个问题：为了得到当前约束下更好的方案，还需要投入多少思考与取证。它不是固定的“多方案评审”仪式。

## 选择方法

先判断阻碍可靠决策的主要不确定性，再选择最便宜、最直接的动作：

| 主要不确定性 | 优先动作 |
| --- | --- |
| 目标或完成边界不清 | 收敛最小完整结果、必要链路和非目标 |
| 当前状态或调用关系不清 | 定向读取与链路取证 |
| 根因不清 | 最小复现、边界回放或判别性实验 |
| 存在真实可行的竞争路径 | 比较最强替代方案与推荐方案 |
| 风险高、失败代价大 | 预演最可能的失败模式和恢复边界 |
| 是否完整不清 | 对照验收条件做缺口检查 |

一种动作已经足以改变或确认决策时，不叠加其它动作。只有多个候选都真实可行且取舍会改变用户结果、owner、复杂度、可逆性或验证成本时，才做多方案对比；候选数量由真实方案空间决定，不为凑数发明方案。

## 投入判断

综合判断额外思考的预期决策增益与成本：

- 决策增益：能否降低选错主链路、遗漏必要闭环、引入结构债或造成不可逆后果的概率；
- 成本：Token、延迟、工具调用、实验开销和协作上下文；
- 可逆性：越容易低成本撤销，越适合直接采用简单路径并快速验证；
- 熟悉度：现有 owner、惯例和证据越清楚，越不需要重复论证。

满足以下条件时使用快速路径：结果边界清楚、事实充分、单一现有 owner、路径可逆、已有惯例且验证直接。否则只升级与主要不确定性匹配的思考动作。

## 停止条件

当新增思考不再可能改变推荐方案、必要边界或验证方法，或者其预期增益低于 Token、延迟和复杂度成本时立即停止。输出所选方案、关键依据、被排除的最强替代路径（若存在）和仍需由验证关闭的风险，不输出无助于决策的完整思维过程。
