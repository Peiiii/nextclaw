# 省 Token 委派合同

仅当用户在当前任务同时明确说“开启省 Token 模式/省 Token 推进”和“使用子代理/委派”时生效。历史会话中的宽泛授权不继承；“提高效率”“节省 Token”“并行处理”不等于授权子代理。用户关闭、反对或任务结束即退出，其中用户反对后当前任务不得再次启用。

## 决策

默认保持单代理。根任务先形成最小证据包，只含目标、冻结边界、必要文件或证据、固定输出格式和完成条件。委派前同时估算模型 Token、上下文重载、通信、整合和失败恢复成本，只有预计总成本净节省为正才允许一次试验：

- Luna：边界固定的只读搜索、机械提取、清单核对或结果摘要；
- Terra：合同已经冻结、可独立完成的复杂子问题或审查。

新增或实质重写 Skill 属于高杠杆规则资产，默认由 Sol 级模型直接完成，或至少由 Sol 对最终文本、触发边界和验证证据作最终审定。Luna/Terra 仍可承担边界冻结后的普通执行，但同样必须证明净节省；不要仅因出现一句 Skill 需求就机械启动高成本 Agent，也不追溯重审此前已经完成的 Skill。

试验使用以下硬边界：

- 首次只启动一个子代理；在它完成并证明实际净节省前，不得再启动第二个；单任务累计最多两个，禁止子代理继续派生子代理；
- 默认不 fork 全量历史，只提供最小证据包；若子任务离不开完整上下文，就留在主代理；
- 不把同一大任务按文件数量切成多个并行 lane，不让多个代理编辑共享 WIP，也不把维护性返工、最终验证、Review、发布、部署或外部监控委派出去；
- 子代理只返回固定长度的结构化结论和证据路径，禁止回传大日志、完整 diff 或重复背景；
- 第一次出现上下文重载、结果重叠、合并冲突、失败返工或用户质疑成本，立即停止全部子代理并回到单代理，不能为了“摊薄前期成本”继续追加委派。

短小 L0-L1、共享 WIP 高频协作、秘密或生产操作、迁移、发布、破坏性动作、必须沿同一上下文完成的验证与 Review，以及无法证明节省的任务都留在主线。共享文件的修改、冲突裁决和最终验收由当前 owner 收口；子代理不能用摘要替代真实检查。

## 衡量

只报告可观测的总量、未缓存输入、缓存输入、输出、模型调用、工具轮次、参与 lane、覆盖率和警告，不猜测不可见成本。只能与同类型任务或固定基准比较；试验可把总 Token 降低 20% 作为观察目标，但不是承诺，不能牺牲完成度或证据。
