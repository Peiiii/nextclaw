# X 账号受众增长

## 职责与目标

本 Skill 负责确定目标读者、诊断增长瓶颈、选择行动和按反馈调整。成果是**新增相关关注者及有价值的持续互动**，不是关注别人、点赞或发帖的次数。用户提出的数量是行动范围时，不把它误作最终目标；已有账号定位、受众语言和产品事实优先于通用涨粉模板。

单篇帖子、回复的论点与文案由 `social-content` 负责；X 页面读取和结果核验沿调用入口的操作合同。用户指定真实浏览器或禁用某工具时，该选择贯穿任务，不把禁用工具当作备用路径。写入还须有用户授权及符合当时平台规则的途径；缺一时交付可直接使用的文案与目标链接，不把草稿报成已发布。

## 每轮先判断瓶颈

1. 回读账号简介、置顶帖、最近内容和可见互动，写清“哪类人关注后能持续获得什么”。简介和置顶内容无法兑现这个承诺时，先修正主页承接，再增加外部曝光。
2. 记录观察时间、现有关注者数，以及可见的帖文曝光、主页访问、有效回复和新关注者。不可见项记未知；没有前后基线时不声称转化率或增长效果。
3. 区分曝光不足、读者不匹配、内容没有兑现期待、主页无法说明关注理由。选当前证据最支持的一个瓶颈，而非同时堆发帖、评论和关注。

## 选择最有增量的行动

- **原创内容**：用可核对的产品实践、结果或工程判断回答目标读者正在关心的问题；热点只有与账号长期承诺相连才值得借。具体写法交给 `social-content`。
- **参与讨论**：选受众重合、仍有真实讨论且自己能补充证据或方法的帖子，准备让读者独立获益的回复；不写空泛附和、复制评论或强塞链接。不得把关键词搜索后的陌生帖变成自动回复名单。
- **选择性关注**：只推荐确实相关、值得建立联系的账号。关注/粉丝比例可作回关可能性的弱线索，须结合近期内容、真实互动与账号质量；不为了补数量批量关注，也不把回关当成必然结果。

按 [X 当前自动化规则](https://help.x.com/en/rules-and-policies/x-automation)核对动作：不自动点赞或主动自动关注；未经对方请求，不自动向陌生账号发送增长用回复；不把脚本化浏览器写入当作接口拒绝后的替代路径。AI 自动回复所需的平台事先批准未得到验证时，不执行。行动频率由内容价值、用户授权、账号正常状态和实际反馈决定，不靠随机间隔、身份或网络切换规避限制；出现限制或验证时停止写入。一次请求被拒只证明那次请求失败，原因未证实时不宣称账号被封。

## 执行、复盘与退出

每次拟定公开行动前写下：目标读者为何会看到、能从中得到什么、为什么可能继续关注。只有存在合规途径且实际执行时才回读具体帖子或账号关系，记录链接、时间和可见结果；按钮瞬时变化与请求成功提示不等于持久生效。

按同一账号、相近观察窗口比较新增**相关**关注者、有效讨论和可见的主页访问或点击。区分可观察变化与行动造成变化的推断；关注数、点赞数、原帖热度和单次低样本结果都不能单独证明增长。用反馈决定下一次只改一个主要假设。用户纠正目标或节奏时，同步修订已有自动任务，避免旧数量目标继续执行；没有用户要求时不擅自创建定时任务。

目标达成、没有值得做的行动或平台写入受限时结束本轮，并准确报告完成、未确认和待观察的部分。代表性反例：用户只要写一篇帖或只读一条 X 内容时，不触发本 Skill 的账号增长流程。
