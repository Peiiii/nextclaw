# Bibo 设计体系

`@nextclaw/bibo-ui` 是 Bibo 网页的专用 React 组件库。它在构建时打包进网页，不提供在线服务，也不持有聊天或账号状态。

## 设计变量

`src/styles/bibo-theme.css` 是颜色、间距、圆角、字体和焦点反馈的唯一来源。页面布局可以定义自己的容器尺寸，但同级按钮、消息、输入区不能另写一套颜色和状态。修改 token 时一起检查桌面、窄屏、默认、悬停、焦点、禁用状态。

## 组件合同

| 组件 | 拥有的行为 | 不拥有的行为 |
| --- | --- | --- |
| `BiboButton` | 语义化按钮、主操作/次操作/危险操作的外观和焦点反馈 | 网络请求、导航目标、业务确认 |
| `BiboMessage` | 用户/搭档消息、Markdown 安全展示、复制入口 | 会话顺序、保存判定、剪贴板写入 |
| `BiboComposer` | 输入框、Enter 发送、Shift+Enter 换行、发送/停止操作状态 | 草稿持久化、流解析、模型调用 |

组件从包根入口导入。新增组件须有稳定视觉或交互语义，并有真实第二个使用场景或明显独立的行为边界；页面一次性的布局放在应用内。用户文案通过应用的 copy 配置传入组件，组件库不依赖 Zustand、Cloudflare 或 NextClaw 服务端。

验证：`pnpm -C packages/bibo-ui tsc`，随后运行 `pnpm -C apps/bibo-hosted smoke:client`，在真实页面检查长消息、窄屏与交互反馈。组件库改动不得跳过应用端验收。
