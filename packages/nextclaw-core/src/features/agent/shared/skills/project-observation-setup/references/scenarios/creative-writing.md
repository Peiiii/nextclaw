# 创作与内容生产场景映射

本 reference 只解释如何把 `general-work` 映射到小说、文章、脚本和其它内容创作，不定义另一套 Workflow。

| 通用节点 | 创作中的常见含义 | 可观察证据示例 |
| --- | --- | --- |
| `exploration` | 澄清本次创作目标、受众、主题与约束 | 目标说明、素材梳理、讨论结论 |
| `planning` | 组织本次工作的结构、重点与推进方式 | 提纲、内容计划 |
| `design` | 设计叙事、表达、论证或信息结构 | 结构稿、人物或论证设计 |
| `proposal-review` | 在正式产出前检查结构和方向 | 结构评审、方向确认 |
| `execution` | 起草、改写、编辑或制作内容 | 稿件、素材与修订记录 |
| `verification` | AI 检查连贯性、事实、约束和完成度 | 自检结论、校对记录 |
| `acceptance` | 向用户展示结果并等待最终确认 | 预览、开放 request Marker |

不要把 Workflow 固化成“写一章”的专用步骤；工作项也可能是讨论一个方向、修改一段内容、设计结构或审阅已有稿件。节点表达工作性质，不限制具体创作对象。AI 自检通过仍不等于用户接受定稿。
